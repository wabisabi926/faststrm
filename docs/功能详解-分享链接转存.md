# 功能详解 - 分享链接转存

## 概述

Fast Strm 支持解析 115 分享链接，浏览分享内容，一键转存到你的网盘并自动生成 STRM。

## 使用入口

在任意页面顶部有一个全局输入框（placeholder: "粘贴 115 分享链接"）：

1. 粘贴 115 分享链接
2. 点击「查看」或按回车
3. 弹出分享详情对话框

[📸 此处需截图：顶部分享链接输入框]

## 支持的链接格式

- 完整 URL：`https://115.com/s/swxxxxxx?password=yyyy`
- 短链接：`https://115cdn.com/s/swxxxxxx`
- 纯分享码：`swxxxxxx`
- 带提取码：`swxxxxxx-yyyy`

## 分享详情对话框

### 浏览分享内容

- 表格展示当前层级文件/文件夹
- 点击文件夹进入子目录
- 面包屑导航可回跳上层
- 显示分享标题和创建时间

[📸 此处需截图：分享详情对话框]

### 选择并转存

1. 勾选要转存的文件/文件夹（支持多选）
2. 点击底部「保存到我的网盘」
3. 在弹出的目录选择器中选择目标网盘目录
4. 确认后开始转存

### 转存后自动生成 STRM

转存成功后，faststrm 会：
1. 反查目标目录路径
2. 匹配已配置的任务（同账号 + 路径前缀匹配）
3. 扫描转存后的文件
4. 为视频文件生成 STRM
5. 返回生成数量

> **前提**：必须已配置对应的同步任务，且任务路径包含转存目标目录。否则只转存不生成 STRM。

## 转存流程

```
用户勾选文件 → 点击保存
  ↓
弹出目录选择器
  ↓
用户选择目标 cid
  ↓
POST /api/115/share { action: "receive", fileIds, toPid }
  ↓
115 API 转存到网盘
  ↓
反查 toPid 路径
  ↓
匹配 Task（同账号 + originPath 前缀）
  ↓
扫描 toPid 目录的视频文件
  ↓
生成 STRM（{strmPrefix}/{targetPath}/{fileName}）
  ↓
返回结果（strmGenerated + generatedCount）
  ↓
Toast 提示：保存成功并生成了 N 个 strm
```

## 当前限制

| 限制 | 说明 |
|------|------|
| 无分页 UI | 后端支持分页，前端默认 limit=32，无「加载更多」 |
| 无递归转存 | 勾选文件夹时，转存整个文件夹但 STRM 生成只扫描一层 |
| 无批量全选 | 需逐个勾选 |
| 路径反查不完整 | `getPathByCid` 仅取当前层，无法向上回溯（已知缺陷） |
| 不写入 filePathDb | 转存生成的 STRM 不记录到 DB，无法增量更新 |
| 分享链接不持久化 | 刷新页面后丢失 |

> 这些限制将在后续版本优化，详见 [配置项参考](配置项参考)。

- 显示你的 115 网盘目录树
- 支持下钻和面包屑回跳
- 选择目标目录后确认

## API 接口

分享功能基于 `/api/115/share` 路由，支持 5 种 action：

| action | 用途 | 必需参数 |
|--------|------|----------|
| `parse` | 解析链接 | `url` |
| `info` | 获取分享信息 | `url` 或 `shareCode` + `account` |
| `list` | 列目录 | `url` 或 `shareCode` + `cid` + `account` |
| `download_url` | 获取直链 | `url` 或 `shareCode` + `fileId` + `account` |
| `receive` | 转存 | `url` 或 `shareCode` + `fileIds` + `toPid` + `account` |

> `download_url` action 后端已实现，但前端 UI 未接入（未来可能用于预览）。
