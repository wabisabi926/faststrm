# 配置项参考

完整列出 `settings.json` 中所有配置字段。通过 Web UI 的「设置」页面修改，或直接编辑文件（需重启容器）。

## 顶层结构

```json
{
  "user-agent": "",
  "internalToken": "",
  "strmExtensions": [],
  "downloadExtensions": [],
  "mediaMountPath": [],
  "strmPrefix": "",
  "enablePathEncoding": false,
  "enable302": false,
  "removeExtraFiles": false,
  "download": {},
  "strm": {},
  "emby": {},
  "telegram": {},
  "lifeMonitor": {}
}
```

## 全局设置

| 字段 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `user-agent` | string | - | 115 API 请求 UA |
| `internalToken` | string | 自动生成 | 内部 API 验证 token，首次启动自动生成 |
| `strmExtensions` | string[] | 16 种音视频 | 转 STRM 的扩展名 |
| `downloadExtensions` | string[] | srt/ass/sub/nfo/jpg/png | 直接下载的扩展名 |
| `mediaMountPath` | string[] | 自动同步 | 媒体挂载路径（SSOT 自动维护，勿手改） |
| `strmPrefix` | string | - | STRM 前缀，不含账号名 |
| `enablePathEncoding` | boolean | false | 是否启用 URL 路径编码 |
| `enable302` | boolean | false | 是否在 strmPrefix 后拼 `/api/strm`（302 模式） |
| `removeExtraFiles` | boolean | false | 是否自动删除远端不存在的本地 STRM |

### download 子项

| 字段 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `linkMaxPerSecond` | number | - | 每秒最大链接数 |
| `linkMaxConcurrent` | number | - | 最大并发链接数 |
| `downloadMaxConcurrent` | number | - | 最大并发下载数 |

### strm 子项（STRM 路由策略）

| 字段 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `forceProxyUaTokens` | string[] | `["Infuse","VidHub","SenPlayer","SenPlayerHD"]` | 强制走代理的 UA 关键字列表（seek/302 兼容性差的客户端） |
| `accountProxyConcurrencyLimit` | number | `8` | 单账号并发代理上限，超阈值自动降级 redirect |
| `redirectCheckTimeoutMs` | number | `5000` | HEAD 可达性预检超时(ms) |

#### strm 配置示例

```json
{
  "strm": {
    "forceProxyUaTokens": ["Infuse", "VidHub", "SenPlayer", "PotPlayer", "MPC-HC"],
    "accountProxyConcurrencyLimit": 10,
    "redirectCheckTimeoutMs": 8000
  }
}
```

> 这些配置在请求时实时读取，修改后无需重启容器。详见 [STRM 路由策略](功能详解-STRM路由策略)。

## emby 子项

| 字段 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `url` | string | - | Emby 服务器地址 |
| `apiKey` | string | - | Emby API Key（加密存储） |
| `notifyMediaAdded` | boolean | false | 入库通知 |
| `notifyMediaRemoved` | boolean | false | 删除通知 |
| `notifyPlayback` | boolean | false | 播放通知 |
| `playbackShowProgress` | boolean | false | 播放通知显示进度 |
| `playbackShowOverview` | boolean | false | 播放通知显示简介 |
| `webhookAuth` | string | - | Webhook 鉴权令牌 |
| `libraryId` | string | - | 媒体库 ID |
| `syncDeleteEnabled` | boolean | false | 启用删除同步 |
| `syncDeletePathMappings` | array | - | 删除同步路径映射 |
| `syncDeleteNotify` | boolean | false | 删除同步时发 TG 通知 |
| `syncDeleteDryRun` | boolean | false | 试运行模式（只日志不删） |

### syncDeletePathMappings 格式

```json
[
  {
    "embyPath": "/app/data/strm/电影",
    "cloudPath": "/电影",
    "account": "我的115"
  }
]
```

- `embyPath`：Emby 中的 STRM 路径前缀
- `cloudPath`：115 网盘对应路径
- `account`：可选，留空时遍历所有 115 账号删 DB

## telegram 子项

| 字段 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `botToken` | string | - | TG Bot Token（加密存储） |
| `chatId` | string | - | 接收通知的 Chat ID |
| `webhookUrl` | string | - | Webhook 模式 URL |
| `enabled` | boolean | false | 是否启用 TG 通知 |
| `allowedUsers` | number[] | - | 允许交互的用户 ID 列表 |
| `accountAlerts` | object | - | 账户状态通知配置（v0.8.2 新增） |

### accountAlerts 格式

```json
{
  "enabled": true,
  "onError": true,
  "onRecover": true
}
```

| 字段 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `enabled` | boolean | false | 启用账户状态通知 |
| `onError` | boolean | true | 账号异常时发送 TG 通知 |
| `onRecover` | boolean | true | 账号恢复时发送 TG 通知 |

> 与「账号管理」页面的「更新 Cookie」按钮形成闭环：账号异常 → TG 推送 → 扫码更新 → 自动重检 → 恢复通知。

## lifeMonitor 子项

| 字段 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `enabled` | boolean | false | 启用生活监控 |
| `accounts` | string[] | - | 监控的账号列表 |
| `pollInterval` | number | 30 | 轮询间隔（秒，最小 5） |
| `pathMappings` | array | - | 路径映射 |
| `removeEmptyDirs` | boolean | true | 清理空目录 |
| `eventTypes` | object | - | 各类事件开关 |
| `strmPrefix` | string | - | 监控专用前缀（缺省用全局） |
| `enablePathEncoding` | boolean | false | 路径编码（缺省用全局） |
| `enable302` | boolean | false | 302 模式（缺省用全局） |
| `minFileSize` | number | 0 | 小于此值跳过（字节） |
| `firstPullMode` | string | `latest` | 首拉模式：latest/all/last |
| `moveMediaMode` | string | `recreate` | 移动模式：recreate/local_move |

### pathMappings 格式

```json
[
  {
    "account": "我的115",
    "cloudPath": "/电影",
    "localPath": "/app/data/strm/电影"
  }
]
```

### eventTypes 格式

```json
{
  "create": true,
  "remove": true,
  "rename": true,
  "move": true
}
```

## STRM 扩展名默认值

```
mp4, mkv, avi, mov, rmvb, webm, flv, m3u8, mp3, flac, wav, aac, ogg, m4a, ts, m2ts
```

## 下载扩展名默认值

```
srt, ass, sub, nfo, jpg, png
```
