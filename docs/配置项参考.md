# 配置项参考

完整列出 settings.json 中所有配置字段。通过 Web UI 的「设置」页面修改，或直接编辑文件（需重启容器）。

## 顶层结构

```json
{
  "user-agent": "",
  "internalToken": "",
  "strmExtensions": [],
  "downloadExtensions": [],
  "mediaMountPath": [],
  "strmPrefix": "",
  "enablePathEncoding": true,
  "enable302": true,
  "removeExtraFiles": true,
  "download": {},
  "strm": {},
  "emby": {},
  "telegram": {},
  "lifeMonitor": {}
}
```

## 全局设置

| 字段 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `user-agent` | string | - | 115 API 请求 UA |
| `internalToken` | string | 自动生成 | 内部 API 验证 token |
| `strmExtensions` | string[] | **16 种音视频 + iso** | 转 STRM 的扩展名（v1.1.1+ 移除 bdmv/vob/ifo/rar/zip/7z，只留 iso 作为原盘格式） |
| `downloadExtensions` | string[] | srt/ass/sub/nfo/jpg/png | 直接下载的扩展名 |
| `mediaMountPath` | string[] | 自动同步 | 媒体挂载路径 |
| `strmPrefix` | string | - | STRM 前缀 |
| `enablePathEncoding` | boolean | **true**（v1.1.1+）/ false（老版本） | 是否启用 URL 路径编码 |
| `enable302` | boolean | **true**（v1.1.1+）/ false（老版本） | 302 重定向模式（STRM 核心路由，不开等于没装） |
| `removeExtraFiles` | boolean | **true**（v1.1.1+）/ false（老版本） | 自动删除远端不存在的本地 STRM |

### download 子项

| 字段 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `linkMaxPerSecond` | number | - | 每秒最大链接数 |
| `linkMaxConcurrent` | number | - | 最大并发链接数 |
| `downloadMaxConcurrent` | number | - | 最大并发下载数 |
| `strmMaxConcurrent` | number | 20 | STRM 文件写入并发数（v0.9.2 新增） |
| `autoDownloadMetadata` | boolean | true | 自动下载媒体元数据（v0.9.2 新增） |

### strm 子项（STRM 路由策略）

| 字段 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `forceProxyUaTokens` | string[] | Infuse,VidHub,SenPlayer | 强制走代理的 UA 关键字 |
| `accountProxyConcurrencyLimit` | number | 8 | 单账号并发代理上限 |
| `redirectCheckTimeoutMs` | number | 5000 | HEAD 预检超时(ms) |
| `strmUrlTemplate` | string | - | STRM URL 自定义模板（空=默认拼接；支持 {prefix} {account} {pickcode} {filename} {ext} {stem}） |
| `strmFilenameTemplate` | string | `{stem}.strm`（iso 为 `{stem}.iso.strm`） | STRM 文件名模板（支持 {filename} {stem} {ext}） |
| `enableTokenSigning` | boolean | **false**（v1.1.1 新增） | STRM URL HMAC-SHA256 签名开关（防被盗链；默认关闭） |
| `tokenSecret` | string | 自动生成（开关开启后首次启动） | HMAC 签名 secret（空=未生成；开启开关后自动生成 32-byte） |

### emby 子项（Emby 通知 / 刷库 / 删除同步）

| 字段 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `url` | string | - | Emby Server 地址（含端口） |
| `apiKey` | string | - | Emby API Key（设置→高级→插件→密钥） |
| `notifyMediaAdded` | boolean | **true**（v1.1.1+）/ false（老版本） | 入库通知 |
| `notifyMediaRemoved` | boolean | **true**（v1.1.1+）/ false（老版本） | 删除通知 |
| `notifyPlayback` | boolean | **true**（v1.1.1+）/ false（老版本） | 播放通知（开始/暂停/结束） |
| `playbackShowProgress` | boolean | **true**（v1.1.1+）/ false（老版本） | 播放通知包含进度百分比 |
| `playbackShowOverview` | boolean | false | 播放通知包含媒体简介 |
| `webhookAuth` | string | - | Webhook 可选鉴权 token |
| `libraryId` | string | - | 媒体库 ID（留空自动匹配） |
| `refreshOnCreate` | boolean | **true**（v1.1.1+）/ false（老版本） | STRM 创建后自动刷库 |
| `refreshOnDelete` | boolean | **true**（v1.1.1+）/ false（老版本） | STRM 删除后自动刷库 |
| `debounceSeconds` | number | 10 | 刷库防抖秒数（多次事件合并为一次刷库） |
| `syncDeleteEnabled` | boolean | false | 启用 Emby 删除同步 |
| `syncDeleteDryRun` | boolean | false | 试运行模式（只记日志不删除） |
| `syncDeleteNotify` | boolean | false | 删除同步 TG 通知 |
| `syncDeleteDeleteSymlink` | boolean | false | 是否删除本地 STRM 软链接本身 |
| `syncDeleteRemoveVersions` | boolean | false | 多版本删除（按 title 模糊匹配清理所有版本） |
| `syncDeleteSource` | boolean | false | 同步删除 115 网盘源文件（敏感操作） |

## lifeMonitor 子项

| 字段 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `enabled` | boolean | false | 启用生活监控 |
| `accounts` | string[] | - | 监控的账号列表 |
| `pollInterval` | number | 10 | 轮询间隔（秒，v0.9.7 从 30 调整为 10） |
| `pathMappings` | array | - | 路径映射 |
| `enableDedup` | boolean | true | 启用事件去重（v0.9.2 新增） |
| `dedupWindowHours` | number | 24 | 去重窗口（小时，v0.9.2 新增） |
| `enableRateLimit` | boolean | true | 启用 API 冷却（v0.9.2 新增） |
| `rateLimitMs` | number | 1000 | API 调用最小间隔（v0.9.2 新增） |
| `maxRetries` | number | 3 | 拉取失败最大重试次数（v0.9.2 新增） |
| `retryDelayMs` | number | 1000 | 重试间隔（v0.9.2 新增） |

## STRM 扩展名默认值（v1.1.1 清理）

```
mp4, mkv, avi, mov, rmvb, webm, flv, m3u8, mp3, flac, wav, aac, ogg, m4a, ts, m2ts, iso
```

> v1.1.1 移除 bdmv / vob / ifo / rar / zip / 7z（现实中不存在这些格式的主流片源）。iso 作为蓝光原盘唯一保留。

## ISO 原盘 STRM 格式（v1.1.1 支持）

对于 `.iso` 文件，生成的 STRM 文件名自动双扩展名：

```
电影.iso  →  电影.iso.strm
```

> 文件名模板可通过 `strmFilenameTemplate` 自定义（`{stem}` 会保留 `.iso` 后缀）。

## 下载扩展名默认值

```
srt, ass, sub, nfo, jpg, png
```
