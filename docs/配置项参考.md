# 配置项参考

完整列出 settings.json 中所有配置字段。通过 Web UI 的「设置」页面修改，或直接编辑文件（需重启容器）。

## 顶层结构

```json
{
  "user-agent": "",
  "internalToken": "",
  "strmExtensions": [],
  "downloadExtensions": [],
  "mediaMountPath": [],
  "strmPrefix": "",
  "enablePathEncoding": false,
  "enable302": false,
  "removeExtraFiles": false,
  "download": {},
  "strm": {},
  "emby": {},
  "telegram": {},
  "lifeMonitor": {}
}
```

## 全局设置

| 字段 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `user-agent` | string | - | 115 API 请求 UA |
| `internalToken` | string | 自动生成 | 内部 API 验证 token |
| `strmExtensions` | string[] | 16 种音视频 | 转 STRM 的扩展名 |
| `downloadExtensions` | string[] | srt/ass/sub/nfo/jpg/png | 直接下载的扩展名 |
| `mediaMountPath` | string[] | 自动同步 | 媒体挂载路径 |
| `strmPrefix` | string | - | STRM 前缀 |
| `enablePathEncoding` | boolean | false | 是否启用 URL 路径编码 |
| `enable302` | boolean | false | 302 模式 |
| `removeExtraFiles` | boolean | false | 自动删除远端不存在的本地 STRM |

### download 子项

| 字段 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `linkMaxPerSecond` | number | - | 每秒最大链接数 |
| `linkMaxConcurrent` | number | - | 最大并发链接数 |
| `downloadMaxConcurrent` | number | - | 最大并发下载数 |
| `strmMaxConcurrent` | number | 20 | STRM 文件写入并发数（v0.9.2 新增） |
| `autoDownloadMetadata` | boolean | true | 自动下载媒体元数据（v0.9.2 新增） |

### strm 子项（STRM 路由策略）

| 字段 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `forceProxyUaTokens` | string[] | Infuse,VidHub,SenPlayer | 强制走代理的 UA 关键字 |
| `accountProxyConcurrencyLimit` | number | 8 | 单账号并发代理上限 |
| `redirectCheckTimeoutMs` | number | 5000 | HEAD 预检超时(ms) |

## lifeMonitor 子项

| 字段 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `enabled` | boolean | false | 启用生活监控 |
| `accounts` | string[] | - | 监控的账号列表 |
| `pollInterval` | number | 10 | 轮询间隔（秒，v0.9.7 从 30 调整为 10） |
| `pathMappings` | array | - | 路径映射 |
| `enableDedup` | boolean | true | 启用事件去重（v0.9.2 新增） |
| `dedupWindowHours` | number | 24 | 去重窗口（小时，v0.9.2 新增） |
| `enableRateLimit` | boolean | true | 启用 API 冷却（v0.9.2 新增） |
| `rateLimitMs` | number | 1000 | API 调用最小间隔（v0.9.2 新增） |
| `maxRetries` | number | 3 | 拉取失败最大重试次数（v0.9.2 新增） |
| `retryDelayMs` | number | 1000 | 重试间隔（v0.9.2 新增） |

## STRM 扩展名默认值

```
mp4, mkv, avi, mov, rmvb, webm, flv, m3u8, mp3, flac, wav, aac, ogg, m4a, ts, m2ts
```

## 下载扩展名默认值

```
srt, ass, sub, nfo, jpg, png
```
