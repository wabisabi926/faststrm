# FastStrm 变更日志

## v0.9.8 (2026-08-21)

### 修复

- 修复生活事件监控 SSL 证书验证失败（域名 web.api.115.com → webapi.115.com）
- 修复事件处理字段名不匹配（Category → FileCategory, Size → FileSize）
- 修复任务开始按钮无响应（前端未绑定 onClick + 字段名不一致）
- 修复 STRM 清理页面 totalStale/totalMissing 显示 undefined
- 修复 Telegram 通知 info 类型消息报 invalid data 错误
- 修复账户页面加载时序问题，敏感字段脱敏处理

### 新增

- 新增 Emby 通知默认勾选选项
- 新增 openlist 账户 Deep Check 真实连接测试
- 新增 STRM 清理缓存过期检查（1小时自动回退）
- 新增 Webhook 未配置时的 Debug 日志提示

### 优化

- 优化 Emby 路径选择器添加 Tooltip 提示
- 优化 STRM 前缀输入框 placeholder 说明
- 修复测试用例 findField 搜索范围精确限定

## v0.9.7 (2026-08-21)

### 修复

- 修复生活事件监控无法连接 115 服务器的问题（SSL 证书错误）
- 修复部分文件事件无法解析路径、导致监控中断的问题
- 修复扫码登录偶发失败的问题

### 新增

- 新增事件路径自动解析，即使接口不返回路径也能正确处理
- 新增 API 域名自动切换，遇到网络异常时自动切换备用线路
- 新增事件过滤，浏览、标星等操作不再触发通知

### 优化

- 事件轮询间隔默认从 30 秒缩短到 10 秒，事件更及时
- 整体请求失败率降低，监控更稳定
