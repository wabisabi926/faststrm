# 飞牛 (fNOS) 版本打包与部署说明

FastStrm 提供原生 **飞牛应用中心 (fNOS)** `.fpk` 包，可直接上传到飞牛 NAS 的应用市场，开箱即用。

---

## 🔁 两种获取方式

| 方式 | 场景 | 说明 |
|------|------|------|
| **A. 从 Release 直接下载**（推荐） | 终端用户，不想自己构建 | GitHub Releases 页面自动产出 `faststrm-{amd64\|arm64}-{version}.fpk` |
| **B. 本地 / Linux 主机手动打包** | 开发者，或想定制后打包 | `./scripts/build-fnos.sh all` |

---

## A. 使用 Release 上的 .fpk 安装

1. 进入项目 Release 页面：
   ```
   https://github.com/wabisabi926/faststrm/releases
   ```
2. 根据飞牛 NAS 架构下载对应文件：

   | 机型 | 架构 | 下载文件 |
   |------|------|---------|
   | 飞牛 X86 机型 (x86_64) | amd64 | `faststrm-amd64-0.9.1.fpk` |
   | 飞牛 ARM 机型 (飞牛 mini 等) | arm64 | `faststrm-arm64-0.9.1.fpk` |

3. 登录飞牛 Web 管理端 → **应用中心** → 右上角 **手动安装** → 上传 `.fpk` 文件。
4. 安装完成后在「我的应用」里点 **FastStrm** 图标即可打开 Web UI。

> 访问地址：`http://<飞牛NAS-IP>:8090`  
> 默认账号密码：**admin / admin**（首次登录请立即修改）

## B. 本地手动打包（Linux / WSL）

### 1. 环境要求

| 依赖 | 最低版本 | 安装方法 |
|------|---------|---------|
| **Go** | 1.25+ | `go version`；[官方下载](https://go.dev/dl/) |
| **fnpack** | 1.2.1 | 飞牛官方打包工具（Linux 版） |
| **bash** | 任意现代版本 | 大部分系统自带；Windows 建议 WSL |

fnpack 安装：
```bash
curl -fSL https://static2.fnnas.com/fnpack/fnpack-1.2.1-linux-amd64 -o /usr/local/bin/fnpack
chmod +x /usr/local/bin/fnpack
fnpack help
```

### 2. 准备工作

前端静态资源需要先构建并嵌入到 Go 二进制：
```bash
# 如果 internal/web/spa/index.html 不存在，先构建前端
cd frontend
npm install
npm run build
cd ..
cp -r frontend/dist/* internal/web/spa/
```

### 3. 一键打包

```bash
# 打包当前架构 (默认 amd64)
./scripts/build-fnos.sh

# 同时打 amd64 + arm64
./scripts/build-fnos.sh all
```

产物会出现在 `dist/` 目录：
```
dist/
├── faststrm-amd64-0.9.1.fpk            # 可直接上传飞牛应用中心
├── faststrm-arm64-0.9.1.fpk
├── faststrm-amd64-0.9.1/               # 解压后的应用目录 (方便定制)
│   ├── manifest                        # 应用元信息
│   ├── app/
│   │   ├── faststrm                    # Go 单二进制
│   │   ├── entrypoint.sh               # 入口脚本
│   │   └── .config/                    # 默认配置模板 (首次安装自动拷贝)
│   └── cmd/
│       ├── main                        # fNOS 启动入口
│       ├── install_callback            # 安装后回调
│       ├── uninstall_init              # 卸载前回调 (停进程)
│       ├── upgrade_init                # 升级前回调
│       └── upgrade_callback            # 升级后回调
└── faststrm-arm64-0.9.1/
```

### 4. 手动定制后再打包

如果你想改启动参数、配置默认值、加脚本：

1. 先打一次包，得到 `dist/faststrm-{arch}-{version}/` 解压目录
2. 修改其中的文件（例如 `cmd/main` 的启动参数、`app/.config/.settings.json` 的默认值）
3. 重新打成 `.fpk`：
   ```bash
   cd dist/faststrm-amd64-0.9.1
   fnpack build
   # 生成 faststrm.fpk，重命名成自己想要的名字即可
   ```

## 📂 飞牛应用运行时目录结构

安装到飞牛后，应用根目录一般位于飞牛系统的应用分区内（`manifest.appname = faststrm`）。主要文件/目录如下：

```
<APP_ROOT>/
├── manifest                # 应用元信息 (只读)
├── app/
│   ├── faststrm            # Go 主二进制
│   ├── entrypoint.sh       # 入口脚本
│   └── .config/            # 默认配置模板 (首次启动复制到 config/)
├── cmd/
│   └── main                # 启动脚本
├── config/                 # 用户配置目录 (持久化，升级不丢失)
│   ├── .config.json        # 管理员账号密码 (已哈希)
│   ├── .account.json       # 115 账号
│   ├── .tasks.json         # 扫描任务
│   ├── .settings.json      # 全局设置 (strmPrefix / Emby / TG / Life 监控等)
│   ├── .jwt_secret         # JWT 密钥 (首次启动自动生成)
│   └── .salt               # 密码哈希盐 (首次启动自动生成)
├── data/                   # 数据目录 (持久化)
│   ├── strm/               # 默认 STRM 导出目录
│   ├── faststrm.sqlite*    # SQLite 数据库 (路径映射缓存等)
│   └── logs/               # 其他日志
├── logs/faststrm.log       # 主进程 stdout/stderr 日志
└── faststrm.pid            # 进程 PID 文件
```

### 环境变量

`cmd/main` 启动脚本会优先读取 fNOS 透传的环境变量，允许飞牛在应用模板层面做重定向：

| 环境变量 | 默认值 | 作用 |
|---------|--------|------|
| `FNOS_APP_CONFIG_DIR` | `<APP_ROOT>/config` | 用户配置目录（升级不覆盖） |
| `FNOS_APP_DATA_DIR` | `<APP_ROOT>/data` | 数据导出目录（STRM/SQLite） |
| `FNOS_APP_LOG_DIR` | `<APP_ROOT>/logs` | 日志目录 |
| `TZ` | `Asia/Shanghai` | 时区 |
| `DEFAULT_CONFIG_DIR` | 同上 `FNOS_APP_CONFIG_DIR` | Go 程序 InitApp() 的根目录 |

> 小提示：升级应用时，`config/` 和 `data/` 目录由飞牛系统保留（不会被 .fpk 覆盖），所有账号、任务、设置在升级后都会保留。

## 🔧 常见排错

### Q1. 安装后 8090 端口打不开

- 先确认应用状态：在飞牛「我的应用」里查看是否已**运行**
- 如果显示已停止，检查应用日志：SSH 登录飞牛 NAS 后
  ```bash
  # 找到应用安装目录（以下为示例路径，按实际调整）
  cd /app/faststrm 或 /mnt/apps/faststrm
  tail -n 100 logs/faststrm.log
  cat faststrm.pid
  ```
- 常见原因：端口 8090 被其他应用占用 → 可通过飞牛的应用配置 UI 修改 `service_port`（需要改 manifest 并重新打包）

### Q2. 飞牛打包脚本 `build-fnos.sh` 失败

| 错误 | 解决 |
|------|------|
| `fnpack not found in PATH` | 按上方说明下载安装 fnpack 1.2.1 |
| `internal/web/spa/index.html 未找到` | 先构建前端：`cd frontend && npm i && npm run build && cp -r dist/* ../internal/web/spa/` |
| `manifest arch=x, expected x86_64` | 用错了 manifest 架构，保持 `deploy/fnos/faststrm-amd64/manifest` 不变即可 |
| `MISMATCH: go.mod requires go >= 1.25.0` | 本机 Go 版本太低，升级到 Go 1.25+ |
| `go mod download` 超时/断流 | 国内机器加代理：`export GOPROXY=https://goproxy.cn,direct` |

### Q3. 想改默认端口 / 应用名

修改对应架构目录下的 `manifest` 文件后重新打包：

```ini
# deploy/fnos/faststrm-amd64/manifest
service_port=8090         # 修改端口
display_name=FastStrm     # 修改显示名
```

> 注意：如果改了 `service_port`，请同步确保飞牛防火墙和反向代理放行新端口。

## 🔁 CI 自动化 (Release)

每次向 GitHub 推送 `v*` 标签时，`.github/workflows/release.yml` 会自动做三件事：

1. **Docker Release**：构建 `linux/amd64 + linux/arm64` 镜像并推送到 `docker.io/wabisabi926/faststrm`
2. **fNOS Release**：
   - `actions/setup-go@v5` 安装 Go 1.25
   - `curl` 下载 `fnpack-1.2.1-linux-amd64` 到 Runner PATH
   - 执行 `./scripts/build-fnos.sh all` → 产出 amd64 + arm64 两个 .fpk
   - `gh release upload` 把 `.fpk` 和解压后的 `.zip` 上传到 Release Assets
3. **GitHub Release**：生成 release notes，关联最新 tag

这样终端用户在 Release 页面能一次性下载：
- 🐳 Docker Hub Image: `wabisabi926/faststrm:v0.9.1` + `latest`
- 🛠️ 飞牛 fNOS: `faststrm-amd64-0.9.1.fpk` / `faststrm-arm64-0.9.1.fpk`
- 📁 飞牛解压包 (可定制): `faststrm-amd64-0.9.1.zip` / `faststrm-arm64-0.9.1.zip`
