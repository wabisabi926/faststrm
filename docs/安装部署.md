# 安装部署

## Docker 部署（推荐）

### docker-compose

```yaml
version: "3"
services:
  faststrm:
    image: wabisabi926/faststrm:latest
    container_name: faststrm
    ports:
      - "3000:3000"
      - "8081:8081"
    volumes:
      - ./config:/app/config
      - ./data:/app/data
      - ./logs:/app/logs
      - /path/to/your/strm:/app/data/strm  # STRM 文件输出目录
    environment:
      - TZ=Asia/Shanghai
    restart: unless-stopped
```

### docker run

```bash
docker run -d \
  --name faststrm \
  -p 3000:3000 \
  -v ./config:/app/config \
  -v ./data:/app/data \
  -v ./logs:/app/logs \
  -v /path/to/your/strm:/app/data/strm \
  -e TZ=Asia/Shanghai \
  --restart unless-stopped \
  wabisabi926/faststrm:latest
```

## 端口说明

| 端口 | 用途 |
|------|------|
| 3000 | Web UI + STRM 路由 API（`/api/strm`） |

## 配置目录

容器启动后，配置文件位于 `./config/` 目录：

| 文件 | 用途 | 敏感字段加密 |
|------|------|-------------|
| `config.json` | 登录凭据（用户名/密码） | 密码 SHA-256 |
| `settings.json` | 全局设置 | apiKey/botToken 用 AES-256-GCM |
| `account.json` | 115/OpenList 账号 | cookie/token 用 AES-256-GCM |
| `tasks.json` | 同步任务定义 | - |
| `filePathDb.sqlite` | 文件路径数据库 | - |
| `lifeMonitorState.json` | 生活监控断点 | - |
| `lifeIdPathCache.json` | cid→path 缓存 | - |

数据目录 `./data/`：

| 文件/目录 | 用途 |
|-----------|------|
| `.trash/` | STRM 回收站（7 天保留） |
| `syncDelHistory.json` | Emby 删除同步历史 |
| `lifeEventLog.jsonl` | 生活事件生命周期日志 |

> **首次启动**会从内置默认模板自动生成配置文件，无需手动创建。

## 版本升级

```bash
docker-compose pull
docker-compose up -d
```

配置文件向后兼容，无需手动迁移。

## 构建架构

GitHub Actions 自动构建以下平台：
- `linux/amd64`（x86_64）
- `linux/arm64`（Apple Silicon / 树莓派 4 / CoreELEC）

镜像标签：
- `latest` - 最新版本
- `v0.8.2` - 指定版本（推荐生产用）

## 反向代理建议

如需公网访问，建议在前面加 Nginx/Caddy：

```nginx
server {
    listen 443 ssl;
    server_name strm.yourdomain.com;

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```
