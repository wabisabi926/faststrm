# 安装部署

## Docker 部署（推荐）

### docker-compose

```yaml
version: "3.9"
services:
  faststrm:
    image: wabisabi926/faststrm:latest
    container_name: faststrm
    ports:
      - "8090:8090"
    volumes:
      - ./config:/app/config
      - ./data:/app/data
      - /path/to/your/strm:/app/data/strm  # STRM 文件输出目录
    environment:
      - TZ=Asia/Shanghai
      - APP_ENV=prod
      - SERVER_HOST=0.0.0.0
      - SERVER_PORT=8090
    restart: unless-stopped
```

```bash
docker-compose up -d
```

### docker run

```bash
docker run -d \
  --name faststrm \
  -p 8090:8090 \
  -v ./config:/app/config \
  -v ./data:/app/data \
  -v /path/to/your/strm:/app/data/strm \
  -e TZ=Asia/Shanghai \
  -e APP_ENV=prod \
  -e SERVER_HOST=0.0.0.0 \
  -e SERVER_PORT=8090 \
  --restart unless-stopped \
  wabisabi926/faststrm:latest
```

## 端口说明

| 端口 | 用途 |
|------|------|
| 8090 | Web UI + API + STRM 路由（单端口，前端 SPA 和 API 同源） |

> 💡 仅需暴露 8090 端口。Go 单二进制直接托管前端和后端，无需额外端口。

## 配置目录

`./config/`：

| 文件 | 用途 | 敏感字段加密 |
|------|------|-------------|
| `config.json` | 登录凭据（用户名/密码） | 密码 salt+SHA-256 |
| `settings.json` | 全局设置 | apiKey/botToken 用 AES-256-GCM |
| `account.json` | 115/OpenList 账号 | cookie/token 用 AES-256-GCM |
| `tasks.json` | 同步任务定义 | - |
| `filePathDb.sqlite` | 文件路径数据库 | - |
| `lifeMonitorState.json` | 生活监控断点 | - |

数据目录 `./data/`：

| 文件/目录 | 用途 |
|-----------|------|
| `syncDelHistory.json` | Emby 删除同步历史（最多 200 条） |
| `lifeEventLog.jsonl` | 生活事件生命周期日志 |
| `logs/` | 应用运行日志 |

> **首次启动**会从内置 `.config/` 默认模板自动复制生成配置文件，目标文件已存在则不覆盖。默认账号 `admin/admin` 会在首次启动时自动哈希加密保存。

## 首次登录

1. 浏览器打开 `http://localhost:8090`
2. 默认账号 `admin` / 密码 `admin`
3. 登录后请立即在设置页修改密码

## 构建架构

FastStrm v0.9.1 采用纯 Go 架构，**不再依赖 Node.js 和 Nginx**：

| 组件 | 技术栈 |
|------|--------|
| 后端 | Go + go-zero，单二进制运行 |
| 前端 | Vite + React SPA，通过 `go:embed` 嵌入二进制 |
| 数据库 | SQLite（本地嵌入式） |
| 配置存储 | JSON 文件加密存储 |
| 容器基础 | `alpine:3.19`，无 Node.js/Nginx |

GitHub Actions 自动构建以下平台：
- `linux/amd64`（x86_64）
- `linux/arm64`（Apple Silicon / 树莓派 4 / CoreELEC）
- `windows/amd64`（Windows 服务器）
- `darwin/arm64`（macOS Apple Silicon）

镜像标签：
- `latest` - 最新版本
- `v0.9.1` - 指定版本（推荐生产用）

## 反向代理建议

如需公网访问，建议在前面加 Nginx/Caddy：

```nginx
server {
    listen 443 ssl;
    server_name strm.yourdomain.com;

    location / {
        proxy_pass http://127.0.0.1:8090;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

> 💡 STRM 路由需要正确传递客户端 IP（用于局域网代理判断），务必配置 `X-Forwarded-For` 头。
