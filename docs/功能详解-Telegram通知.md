# 功能详解 - Telegram 通知

## 概述

Fast Strm 支持通过 Telegram Bot 推送通知，包括任务状态、Emby 事件、删除同步等。

## Bot 配置

### 1. 创建 Bot

1. Telegram 搜索 `@BotFather`
2. 发送 `/newbot`
3. 按提示设置名称和用户名
4. 获得 **Bot Token**（如 `123456:ABC-DEF1234ghIkl-zyx57W2v1u123ew11`）

### 2. 获取 Chat ID

1. 先给你的 Bot 发一条消息
2. 浏览器访问：`https://api.telegram.org/bot<TOKEN>/getUpdates`
3. 在返回的 JSON 中找到 `chat.id`

> 群组通知：把 Bot 加入群组，Chat ID 通常为负数（如 `-1001234567890`）。

### 3. faststrm 配置

进入「设置」→「Telegram 通知」：

| 字段 | 说明 |
|------|------|
| Bot Token | 从 BotFather 获取 |
| Chat ID | 接收通知的会话 ID |
| 启用通知 | 总开关 |
| 允许的用户 | 允许通过 Bot 交互的用户 ID（可选） |

[📸 此处需截图：Telegram 配置卡片]

## 通知类型

### 任务通知

| 事件 | 消息内容 |
|------|----------|
| 任务开始 | 任务名 + 账号 + 开始时间 |
| 任务完成 | 任务名 + 生成数 + 删除数 + 耗时 |
| 任务失败 | 任务名 + 错误信息 |

### Emby 通知

| 事件 | 消息内容 |
|------|----------|
| 媒体入库 | 标题 + 类型 + 路径 + 海报（如有） |
| 媒体删除 | 标题 + 类型（生活监控触发） |
| 播放开始 | 标题 + 客户端 + 用户 |
| 播放结束 | 标题 + 播放进度 + 停止位置 |

### 删除同步通知

| 事件 | 消息内容 |
|------|----------|
| Emby 删除同步 | 标题 + 类型 + 删除文件数 + 清理目录数 |
| 试运行模式 | 带 `[试运行]` 标记 |

### 账户状态通知（v0.8.2 新增）

在「TG 通知」页面 → 「账户状态通知」卡片配置：

| 字段 | 说明 |
|------|------|
| 启用账户状态通知 | 总开关 |
| 异常通知 | 账号 Cookie 失效等异常时推送告警 |
| 恢复通知 | 账号恢复正常时推送通知 |
| 过期预警天数 | Cookie 过期前几天开始警告（默认 1 天） |

**闭环流程**：账号异常 → TG 推送告警 → 用户在「账号管理」点击「更新 Cookie」扫码刷新 → 后端异步重检状态 → 恢复正常后推送恢复通知

> 对应配置：`settings.json → telegram.accountAlerts`。

## 剧集缓冲合并

Emby 入库电视剧时，单集会逐个推送事件。faststrm 会缓冲合并：

- **窗口**：10 秒
- **合并条件**：同一剧集（SeriesId）的多集入库
- **合并后消息**：`《剧名》新增 S01E01-E10 共 10 集`

> 避免一季 24 集入库时刷屏 24 条消息。

## Webhook vs 轮询

faststrm 支持两种 TG 通知发送方式：

| 方式 | 说明 | 适用 |
|------|------|------|
| 轮询（默认） | 主动调 `sendMessage` API | 单向通知，简单 |
| Webhook | 设置 `webhookUrl`，TG 回调 | 需要双向交互 |

> 大多数场景用默认轮询即可。Webhook 模式用于需要用户回复 Bot 指令的场景。

## 交互指令（可选）

配置 `allowedUsers` 后，被允许的用户可以与 Bot 交互：

| 指令 | 功能 |
|------|------|
| `/status` | 查看任务状态 |
| `/tasks` | 列出所有任务 |
| `/run <任务名>` | 执行指定任务 |

> 交互功能依赖 Webhook 模式。

## 消息格式

通知使用 Markdown 格式，示例：

```
🎬 *媒体入库*
*标题*: 小王子
*类型*: 电影
*路径*: /电影/小王子 (2015).mkv

✅ *任务完成*
*任务*: 电影同步
*账号*: 我的115
*生成*: 12 个 STRM
*删除*: 3 个孤儿
*耗时*: 45 秒
```

## 故障排查

| 问题 | 原因 | 解决 |
|------|------|------|
| 收不到通知 | Chat ID 错误 | 重新获取 getUpdates |
| 401 Unauthorized | Token 错误 | 重新从 BotFather 获取 |
| 403 Forbidden | Bot 未加入群组 | 把 Bot 加入目标群组 |
| 429 Too Many Requests | 发送过频 | 剧集缓冲合并已处理，如仍频控调整窗口 |
