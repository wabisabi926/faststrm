# ADR 0002：跳过 BDMV/STREAM，不生成 m2ts STRM

- 状态：已接受
- 日期：2026-10-21

## 背景

蓝光原盘目录通常包含 `BDMV/STREAM/00000.m2ts` 等上百个视频流。逐文件生成 STRM 会让一部影片在 Emby 中出现上百个条目，且无法判断哪个是主片。

## 决策

扫描到 `BDMV/STREAM` 时跳过整棵子树，不生成任何 m2ts STRM。ISO 单文件不受影响，继续生成 `.iso.strm`。

## 后果

- 媒体库不会被原盘碎片污染。
- BDMV 目录不会出现在 Emby 中；需要播放时请转 ISO，或手动为主视频流建 STRM。
- 任务结果会统计跳过的 BDMV 数量，避免用户误以为漏扫。
- 不实现“自动挑选最大 m2ts 作为主片”，因为多版本/花絮场景容易误判。
