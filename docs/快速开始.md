# 快速开始

本指南带你完成首次配置，从零到能在 Emby 中播放 115 网盘的媒体。

## 第一步：添加 115 账号

1. 进入「账号管理」页面
2. 点击「添加账号」
3. 填写：
   - **账号名称**：随意（建议与 OpenList/CD2 中的命名一致，便于回源）
   - **账号类型**：选择 `115`
4. 选择登录方式：
   - **📱 扫码登录（推荐，v0.8.2 新增）**：用 115 手机 App 扫码自动获取 Cookie，无需手动抓包
   - **🍪 手动粘贴 Cookie**：从浏览器 F12 抓取后粘贴（传统方式）

[📸 此处需截图：添加账号对话框]

### 扫码登录（推荐）

在添加账号对话框中切换到「扫码登录」标签，选择客户端类型（默认「支付宝小程序」，兼容性最好），用 115 手机 App 扫描弹出的二维码，确认后 Cookie 自动回填并验证状态。

> 选「115 网页」会踢掉当前网页登录，非必要不选。

### 手动获取 Cookie

浏览器登录 115.com → F12 开发者工具 → Network 标签 → 刷新页面 → 点击任意请求 → 复制 Request Headers 中的 `Cookie` 值，粘贴到对话框。

> Cookie 有效期约 7-30 天，过期可通过账号管理页面的「更新 Cookie」按钮扫码刷新，无需删除重建账号。

## 第二步：配置全局 STRM 设置

进入「设置」页面：

### STRM 前缀

两种模式：

**模式 A：302 模式（推荐，需要部署设备能被播放器访问）**
```
strmPrefix: http://你的服务器IP:3000/api/strm
enable302: true
```
STRM 文件内容：`http://服务器:3000/api/strm?account=xxx&pickcode=xxx&file_name=xxx`
播放器请求 faststrm → faststrm 返回 302 直链 → 播放器直连 115 CDN

**模式 B：直链模式（无需 faststrm 在线，但需要 OpenList）**
```
strmPrefix: http://你的OpenList地址
enable302: false
```
STRM 文件内容：`http://OpenList/d/115/电影/xxx.mkv`

[📸 此处需截图：设置页 STRM 前缀配置]

### 扩展名

- **STRM 扩展名**：哪些后缀生成 `.strm`（默认 mp4/mkv/avi/mov 等 16 种）
- **下载扩展名**：哪些后缀直接下载原文件（默认 srt/ass/nfo/jpg/png）

## 第三步：创建同步任务

1. 进入「任务管理」页面
2. 点击「新建任务」
3. 配置：

| 字段 | 说明 | 示例 |
|------|------|------|
| 账号 | 选择 115 账号 | `我的115` |
| 云端目录 | 115 网盘源路径 | `/电影` |
| 本地目录 | STRM 保存子目录 | `电影` |
| STRM 前缀 | 任务级覆盖（留空用全局） | - |
| 定时任务 | cron 表达式 | `0 3 * * *`（每天凌晨 3 点） |
| 删除多余文件 | 远端不存在时删本地 STRM | 建议开启 |

4. 保存后点击「执行」
5. 等待任务完成，日志会显示生成数量

[📸 此处需截图：新建任务对话框]

## 第四步：配置 Emby

### 添加媒体库

1. Emby → 设置 → 媒体库 → 添加媒体库
2. 类型选择「电影」/「电视剧」
3. 路径指向容器内的 STRM 目录（如 `/data/strm/电影`）
4. 完成

### 配置 Webhook（可选，用于通知和删除同步）

1. Emby → 设置 → 高级 → 插件 → 安装「Webhooks」插件
2. 添加 Webhook：
   - URL：`http://你的faststrm地址:3000/api/emby/webhook`
   - 勾选：项目新增、项目删除、播放开始、播放结束
3. 在 faststrm 的「Emby 通知」页面配置：
   - 填写 Emby URL 和 API Key
   - 勾选需要的通知类型
   - （可选）启用删除同步

[📸 此处需截图：Emby Webhook 配置]

## 第五步：播放测试

1. 在 Emby 中找到刚入库的媒体
2. 点击播放
3. 如果是 302 模式，查看 faststrm 日志应显示：
   ```
   [STRM] account=xxx pickcode=xxxx…xxx decision=redirect reason=default_redirect
   ```
4. 播放器应直连 115 CDN，faststrm 不中转流量
