# 安装部署

## Docker 部署（推荐）

### docker-compose

```yaml
version: "3.9"
services:
  faststrm:
    image: wabisabi926/faststrm:latest
    container_name: faststrm
    ports:
      - "8090:8090"
    volumes:
      - ./config:/app/config
      - ./data:/app/data
      - /path/to/your/strm:/app/data/strm  # STRM 文件输出目录
    environment:
      - TZ=Asia/Shanghai
      - APP_ENV=prod
      - SERVER_HOST=0.0.0.0
      - SERVER_PORT=8090
    restart: unless-stopped
```

```bash
docker-compose up -d
```

### docker run

```bash
docker run -d \
  --name faststrm \
  -p 8090:8090 \
  -v ./config:/app/config \
  -v ./data:/app/data \
  -v /path/to/your/strm:/app/data/strm \
  -e TZ=Asia/Shanghai \
  -e APP_ENV=prod \
  -e SERVER_HOST=0.0.0.0 \
  -e SERVER_PORT=8090 \
  --restart unless-stopped \
  wabisabi926/faststrm:latest
```

---

## 端口说明

| 端口 | 用途 |
|------|------|
| 8090 | Web UI + API + STRM 路由（单端口，前端 SPA 和 API 同源） |

> 💡 仅需暴露 8090 端口。Go 单二进制直接托管前端和后端，无需额外端口。

---

## 目录挂载

| 目录 | 容器路径 | 用途 |
|------|---------|------|
| `./config` | `/app/config` | 配置文件（config.json, settings.json, account.json, tasks.json） |
| `./data` | `/app/data` | 数据文件（SQLite 数据库、删除历史、生活事件日志、运行日志） |
| STRM 目录 | `/app/data/strm` | STRM 文件输出路径 |

---

## 配置文件说明

| 文件 | 用途 | 敏感字段 |
|------|------|---------|
| `config.json` | 登录凭据 | 密码 salt+SHA-256 |
| `settings.json` | 全局设置 | apiKey/botToken AES-256-GCM |
| `account.json` | 115 账号信息 | cookie/token AES-256-GCM |
| `tasks.json` | 同步任务定义 | - |

> 首次启动会从内置默认模板（`.config/`）自动生成配置文件。默认账号 `admin/admin` 会在首次启动时自动哈希加密保存。

---

## 首次登录

1. 浏览器打开 `http://localhost:8090`
2. 默认账号 `admin` / 密码 `admin`
3. 登录后请立即在「设置」页面修改密码

## 反向代理（可选）

如需公网访问，建议在前面加 Nginx/Caddy：

```nginx
server {
    listen 443 ssl;
    server_name strm.yourdomain.com;

    location / {
        proxy_pass http://127.0.0.1:8090;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

> 💡 STRM 路由需要正确传递客户端 IP（用于局域网代理判断），务必配置 `X-Forwarded-For` 头。

## 构建架构

FastStrm v0.8.8 采用纯 Go 架构，**不再依赖 Node.js 和 Nginx**：

| 组件 | 技术栈 |
|------|--------|
| 后端 | Go + go-zero，单二进制运行 |
| 前端 | Vite + React SPA，通过 `go:embed` 嵌入二进制 |
| 数据库 | SQLite（本地嵌入式） |
| 配置存储 | JSON 文件加密存储 |
| 容器基础 | `alpine:3.19`，无 Node.js/Nginx |

GitHub Actions 自动构建以下平台：

- `linux/amd64`（x86_64）
- `linux/arm64`（Apple Silicon / 树莓派 4 / CoreELEC）
- `windows/amd64`（Windows 服务器）
- `darwin/arm64`（macOS Apple Silicon）
