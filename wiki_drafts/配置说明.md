# 配置参考

完整列出 `settings.json` 中所有配置字段。可通过 Web UI「设置」页面修改，或直接编辑文件（需重启容器）。

---

## 顶层结构

```json
{
  "user-agent": "",
  "strmExtensions": [],
  "downloadExtensions": [],
  "strmPrefix": "",
  "enablePathEncoding": true,
  "download": {},
  "strm": {},
  "rateLimit": {},
  "emby": {},
  "telegram": {},
  "lifeMonitor": {},
  "cleanup": {},
  "cookieInspect": {}
}
```

> **v1.2.3 变更**：`enable302` 字段已删除，所有 STRM 统一走 `/api/strm`（前端自动追加）。

## 全局设置

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `user-agent` | string | 内置 iOS UA | 115 API/后台任务的兜底 UA；播放时优先使用播放器自己的 UA。留空保存后仍为空，运行时用内置 UA 兜底 |
| `strmExtensions` | string[] | 内置 17 项 | 转换为 `.strm` 的扩展名数组，自动转小写。留空保存后仍为空，运行时用内置列表兜底 |
| `downloadExtensions` | string[] | `srt, ass, sub, nfo, jpg, png` | 附带下载的文件扩展名；**显式空数组 = 不下载**，旧配置字段缺失时才补默认 |
| `strmPrefix` | string | - | STRM 前缀（如 `http://localhost:8090`），不含 `/api/strm` 后缀，前端自动追加 |
| `enablePathEncoding` | boolean | `true` | 是否对 `account` / `file_name` 等 URL 参数做百分号编码。关闭后参数原样写入，文件名含 `#`/`&`/`?`/空格时会破坏 URL 解析 |

### STRM 扩展名默认值（v1.1.1 新增 iso 原盘格式）

```
mp4, mkv, avi, mov, rmvb, webm, flv, m3u8, mp3, flac, wav, aac, ogg, m4a, ts, m2ts, iso
```

### ISO 原盘 STRM 格式

对于 `.iso` 原盘文件，生成的 STRM 采用**双扩展名**（Emby/Jellyfin 识别原盘模式所必需）：

```
电影.iso  →  电影.iso.strm
```

### STRM 文件名规则

> **v1.5.5 起自定义 URL / 文件名模板已下线**：老配置首次读取会备份为 `settings.json.templates-v1.*` 后清空；手工把模板写回 `settings.json` 也会在读取/保存时被清空，不再生效。

文件名固定为 `{stem}.strm`（iso 自动变 `{stem}.iso.strm`），URL 固定为标准 query 拼接。

### 下载扩展名默认值

```
srt, ass, sub, nfo, jpg, png
```

## download 子项

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `linkMaxPerSecond` | number | - | 每秒最大 API 链接数（令牌桶） |
| `linkMaxConcurrent` | number | - | 最大并发 API 链接数 |
| `downloadMaxConcurrent` | number | - | 最大并发下载数 |
| `strmMaxConcurrent` | number | `20` | STRM 写入并发数 |
| `autoDownloadMetadata` | boolean | 由列表派生 | 兼容字段；`downloadExtensions` 非空时为 true，空列表时为 false |

| `overwriteMode` | string | `always` | STRM 覆盖模式：`always` / `never` |
| `fullSyncCleanupOrphans` | string | `auto_clean` | 孤儿清理策略：`off` / `mark_only` / `auto_clean`；自动清理也只处理托管 STRM，删除前做云端复核并移入回收站 |

> 💡 限流配置用于防止触发 115 API 频控。建议保持默认或根据账号等级调整。

## strm 子项（STRM 路由策略）

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `forceProxyUaTokens` | string[] | `Infuse, VidHub, SenPlayer, SenPlayerHD` | 强制走代理的 UA / Emby 客户端名关键字；清空=全部 302 直链 |
| `forceProxyFormats` | string[] | `iso, bdmv, bdav, dvd, bluray` | Emby 反代层和 `/api/strm` 端点层共用的按格式代理列表；填了才代理，**留空 = 全部 302**。旧版 `disableSeekFormatProxy` 开关会在升级时自动迁移，不再需要 |
| `disableRangeProxy` | bool | `false` | 关闭代理流分片并发（回退单连接 io.Copy） |
| `proxyChunkSizeMB` | number | `10` | 分片大小（1-64） |
| `proxyConcurrency` | number | `2` | 单次播放分片并发（1-4）；同时决定同账号共享 Range 池的默认上限 |
| `accountProxyConcurrencyLimit` | number | `8` | 单账号代理流上限；非原盘超限降级 redirect，原盘允许超限 2 路后排队 |
| `redirectCheckTimeoutMs` | number | `5000` | HEAD 可达性预检超时(ms) |
| `strmUrlTemplate` | string | 空 | 已下线：仅为兼容旧配置保留，读取/保存时强制清空 |
| `strmFilenameTemplate` | string | 空 | 已下线：仅为兼容旧配置保留，读取/保存时强制清空 |

### strm 配置示例

```json
{
  "strm": {
    "forceProxyUaTokens": ["Infuse", "VidHub", "SenPlayer", "SenPlayerHD"],
    "forceProxyFormats": ["iso", "bdmv", "bdav", "dvd", "bluray"],
    "proxyChunkSizeMB": 10,
    "proxyConcurrency": 2,
    "accountProxyConcurrencyLimit": 10,
    "redirectCheckTimeoutMs": 8000
  }
}
```

> 💡 这些配置在请求时实时读取，修改后无需重启容器。
> 详见 [STRM 路由策略](STRM-路由策略)。

## cleanup 子项（清理对账）

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `maxThreshold` | number | `1000` | 单次删除绝对上限，超过进入保护态 |
| `maxRatio` | number | `0.10` | 单次删除比例上限（占本地 STRM 总数），超过进入保护态 |
| `maxDirs` | number | `20` | 单次删除涉及目录数上限 |
| `stableThreshold` | number | `5` | 超过后进入二次确认/待删队列 |
| `confirmMode` | string | `none` | `none` / `plugin_ui` / `telegram` |
| `removeStrm` | boolean | `true` | 是否删除 STRM 文件本身 |
| `removeRelatedFiles` | boolean | `false` | 是否连带删除同名 nfo/海报/字幕（v1.5.0 起默认关闭） |
| `removeEmptyDirs` | boolean | `false` | 是否回收空目录（v1.5.0 起默认关闭） |

> v1.5.0 首次启动会通过 `CleanupDefaultsV3` 把旧版本自动打开过的 `removeRelatedFiles` / `removeEmptyDirs` 关闭一次；之后以用户设置为准。
> 清理只处理 `managed_strms` 中登记的 STRM，删除前会做指纹与云端复核，并移入 `.faststrm-trash` 回收站。详见 [STRM 清理对账](STRM-清理对账)。

## emby 子项

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `url` | string | - | Emby 服务器地址，如 `http://192.168.1.10:8096` |
| `apiKey` | string | - | Emby API Key（AES-256-GCM 加密存储） |
| `libraryId` | string | - | 媒体库 ID（可选，留空自动通过路径匹配） |
| `notifyMediaAdded` | boolean | **true**（v1.1.1+）/ false（老版本） | 入库通知（TG 推送） |
| `notifyMediaRemoved` | boolean | **true**（v1.1.1+）/ false（老版本） | 删除通知（TG 推送） |
| `notifyPlayback` | boolean | **true**（v1.1.1+）/ false（老版本） | 播放开始/停止通知 |
| `playbackShowProgress` | boolean | **true**（v1.1.1+）/ false（老版本） | 播放通知显示进度百分比 |
| `playbackShowOverview` | boolean | false | 播放通知显示媒体简介 |
| `webhookAuth` | string | - | Webhook 鉴权密钥（**必填**；未设置时 Webhook 返回 401） |
| `refreshOnCreate` | boolean | **true**（v1.1.1+）/ false（老版本） | STRM 创建后自动刷库 |
| `refreshOnDelete` | boolean | **true**（v1.1.1+）/ false（老版本） | STRM 删除后自动刷库 |
| `debounceSeconds` | number | 10 | 刷库防抖秒数（多次事件合并为一次） |
| `syncDeleteEnabled` | boolean | false | 启用删除同步（Emby → 清理 STRM） |
| `syncDeleteDryRun` | boolean | 见说明 | 试运行模式（只记日志不实际删除）。未显式配置且删除同步未启用时默认 true；已启用删除同步的老配置保持原值 |
| `syncDeleteNotify` | boolean | false | 删除同步时发送 TG 通知 |
| `syncDeletePathMappings` | array | - | 删除同步路径映射（见下方） |
| `proxyPort` | number | `0`（不启用） | Emby 反向代理监听端口（如 `8097`）。>0 时启动 embyproxy 拦截 PlaybackInfo 强制 STRM DirectPlay，解决 Emby for Kodi ISO/STRM 播放转码问题 |
| `externalPlayerEnabled` | boolean | false | 在 Emby 网页端详情页注入 PotPlayer / VLC / Infuse / MPV 起播按钮（v1.3.8+）。需先启用反向代理；保存后热更新生效，无需重启 |

### syncDeletePathMappings 格式

```json
[
  {
    "embyPath": "/app/data/strm/电影",
    "cloudPath": "/电影",
    "account": "我的115"
  }
]
```

| 字段 | 说明 | UI 控件 |
|------|------|---------|
| `embyPath` | Emby 中 STRM 文件的路径前缀 | 📁 本地文件夹选择器 |
| `cloudPath` | 115 网盘对应的路径 | 🗄️ 云盘目录选择器（需选定特定账号） |
| `account` | 指定清理 filePathDb 的账号；留空遍历所有 115 账号 | 下拉选择器（默认「遍历全部账号」） |

> 💡 **v0.8.1 增强**：路径映射三个字段均支持 UI 选择器，无需手动输入路径。云盘目录选择器仅在选定特定 115 账号时启用。

### Emby API 路由

| 路由 | 方法 | 说明 |
|------|------|------|
| `/api/emby/settings` | GET | 获取 Emby 配置 |
| `/api/emby/settings` | POST | 局部更新 Emby 配置（不覆盖其他字段） |
| `/api/emby/test-connection` | GET | 测试 Emby 连接（9 种错误分类） |
| `/api/emby/webhook` | POST | 接收 Emby Webhook 事件 |

> 💡 **v0.8.1 修复**：`POST /api/emby/settings` 采用局部 patch 模式，保存 Emby 设置时不会覆盖 302 重定向、监控账号、TG Bot 等其他配置。


## 配置文件结构

### 用户配置目录：`./config/`

容器启动后，**用户可编辑的配置文件**位于 `./config/` 目录：

| 文件 | 说明 | 敏感字段 |
|------|------|---------|
| `config.json` | 登录凭据 | 密码 salt+SHA-256 |
| `settings.json` | 全局设置 | apiKey/botToken AES-256-GCM |
| `account.json` | 115 账号信息 | cookie/token AES-256-GCM |
| `tasks.json` | 同步任务定义 | - |

> 💡 首次启动会从 `.config/` 模板目录自动复制到 `./config/`，无需手动创建。**已存在的文件不会被覆盖**，用户配置是安全的。

### 默认模板目录：`./.config/`（v0.8.2 起增强密码哈希）

这是「默认设置源目录」，存放带点前缀的默认模板文件：

| 文件 | 说明 |
|------|------|
| `.config/.settings.json` | 系统设置默认模板 |
| `.config/.tasks.json` | 任务列表默认模板 |
| `.config/.account.json` | 账号列表默认模板 |
| `.config/.config.json` | 登录凭据默认模板 |

**使用规则**：

1. **Docker 部署**：容器启动时由 [`docker-entrypoint.sh`](https://github.com/wabisabi926/faststrm/blob/main/docker-entrypoint.sh) L11-54 自动完成 `.config/` → `config/` 复制
2. **本地开发（非 Docker）**：`config.json` 不存在或密码为空时会进入首次初始化流程，由用户在 `/setup` 创建管理员
3. **绝不覆盖已有用户配置**——只有目标文件不存在时才复制，用户自定义设置不会被破坏
4. **v1.5.2 起**不再生成随机密码文件；无界面部署可用 `FASTSTRM_ADMIN_USERNAME` / `FASTSTRM_ADMIN_PASSWORD` 直接初始化
5. 开发者可以修改 `.config/` 作为新项目的默认值模板，不用硬编码在 TypeScript 里

> `Dockerfile` L44 负责把本地 `.config/` 目录 COPY 到镜像内的 `/app/.config`，再由 entrypoint 分发到 `/app/config` 用户目录。

## 数据目录说明

`./data/` 目录包含运行时数据：

| 文件/目录 | 说明 |
|-----------|------|
| `syncDelHistory.json` | Emby 删除同步历史记录（最多 200 条） |
| `filePathDb.sqlite` | **核心 SQLite 数据库**：含 `files`（文件路径映射）、`folders`（目录 CID 缓存）、`managed_strms`（STRM 托管所有权）、`cleanup_pending_batches`（待确认清理批次）、`strm_exec_history`（STRM 变更历史）、`task_history`（任务执行历史）、`schema_migrations` |
| `lifeMonitorState.json` | 生活监控断点状态 |
| `lifeIdPathCache.json` | cid → path 缓存 |

> 🧹 **清理回收站**：旧版 `data/.trash` 已移除。v1.5.0 起删除的 STRM/关联文件移动到对应映射根的 `.faststrm-trash/<时间戳>/`，保留 7 天，可在清理页恢复或等待自动清理。

## 修改密码

### 方法一：Web UI（推荐）

登录后进入「设置」→ 修改密码。

### 忘记密码

1. 停止 FastStrm
2. 将 `config/config.json` 的 `password` 改为空字符串 `""`
3. 重启服务，打开 Web 页面重新进入「创建管理员账号」向导
4. 原有账号、任务、媒体库数据不受影响

> 默认 `admin/admin` 或空口令登录后必须先修改密码；未修改前所有受保护接口会返回 `PASSWORD_CHANGE_REQUIRED`。
> 当前密码使用 salt+SHA-256 机制，不要直接填纯 SHA-256 值（如 `8c6976e5...`），无法通过验证。
