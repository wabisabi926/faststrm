# 配置参考

完整列出 `settings.json` 中所有配置字段。可通过 Web UI「设置」页面修改，或直接编辑文件（需重启容器）。

---

## 顶层结构

```json
{
  "user-agent": "",
  "strmExtensions": [],
  "downloadExtensions": [],
  "strmPrefix": "",
  "enablePathEncoding": false,
  "enable302": false,
  "removeExtraFiles": false,
  "download": {},
  "strm": {},
  "emby": {},
  "telegram": {},
  "lifeMonitor": {}
}
```

---

## 全局设置

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `user-agent` | string | - | 115 API 请求使用的 User-Agent 字符串 |
| `strmExtensions` | string[] | 见下方 | 转换为 `.strm` 的扩展名数组，自动转小写 |
| `downloadExtensions` | string[] | 见下方 | 直接下载的文件扩展名数组，自动转小写 |
| `strmPrefix` | string | - | STRM 前缀（如 `http://localhost:8090`），不含账号名 |
| `enable302` | boolean | false | 是否在 strmPrefix 后自动拼接 `/api/strm`（302 模式） |
| `enablePathEncoding` | boolean | false | 是否启用 URL 路径编码（解决 Kodi 中文路径乱码） |
| `removeExtraFiles` | boolean | false | 是否自动删除远端已不存在的本地 STRM 文件 |

### STRM 扩展名默认值

```
mp4, mkv, avi, mov, rmvb, webm, flv, m3u8, mp3, flac, wav, aac, ogg, m4a, ts, m2ts
```

### 下载扩展名默认值

```
srt, ass, sub, nfo, jpg, png
```

## download 子项

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `linkMaxPerSecond` | number | - | 每秒最大 API 链接数（令牌桶） |
| `linkMaxConcurrent` | number | - | 最大并发 API 链接数 |
| `downloadMaxConcurrent` | number | - | 最大并发下载数 |

> 💡 限流配置用于防止触发 115 API 频控。建议保持默认或根据账号等级调整。

## strm 子项（STRM 路由策略）

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `forceProxyUaTokens` | string[] | `["Infuse","VidHub","SenPlayer","SenPlayerHD"]` | 强制走代理的 UA 关键字列表（seek/302 兼容性差的客户端） |
| `accountProxyConcurrencyLimit` | number | `8` | 单账号并发代理上限，超阈值自动降级 redirect |
| `redirectCheckTimeoutMs` | number | `5000` | HEAD 可达性预检超时(ms) |

### strm 配置示例

```json
{
  "strm": {
    "forceProxyUaTokens": ["Infuse", "VidHub", "SenPlayer", "PotPlayer", "MPC-HC"],
    "accountProxyConcurrencyLimit": 10,
    "redirectCheckTimeoutMs": 8000
  }
}
```

> 💡 这些配置在请求时实时读取，修改后无需重启容器。
> 详见 [STRM 路由策略](STRM-路由策略)。

## emby 子项

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `url` | string | - | Emby 服务器地址，如 `http://192.168.1.10:8096` |
| `apiKey` | string | - | Emby API Key（AES-256-GCM 加密存储） |
| `libraryId` | string | - | 媒体库 ID（可选，留空自动通过路径匹配） |
| `notifyMediaAdded` | boolean | false | 入库通知（TG 推送） |
| `notifyMediaRemoved` | boolean | false | 删除通知（TG 推送） |
| `notifyPlayback` | boolean | false | 播放开始/停止通知 |
| `playbackShowProgress` | boolean | false | 播放通知显示进度百分比 |
| `playbackShowOverview` | boolean | false | 播放通知显示媒体简介 |
| `webhookAuth` | string | - | Webhook 鉴权令牌（可选） |
| `syncDeleteEnabled` | boolean | false | 启用删除同步（Emby → 清理 STRM） |
| `syncDeleteDryRun` | boolean | false | 试运行模式（只记日志不实际删除） |
| `syncDeleteNotify` | boolean | false | 删除同步时发送 TG 通知 |
| `syncDeletePathMappings` | array | - | 删除同步路径映射（见下方） |

### syncDeletePathMappings 格式

```json
[
  {
    "embyPath": "/app/data/strm/电影",
    "cloudPath": "/电影",
    "account": "我的115"
  }
]
```

| 字段 | 说明 | UI 控件 |
|------|------|---------|
| `embyPath` | Emby 中 STRM 文件的路径前缀 | 📁 本地文件夹选择器 |
| `cloudPath` | 115 网盘对应的路径 | 🗄️ 云盘目录选择器（需选定特定账号） |
| `account` | 指定清理 filePathDb 的账号；留空遍历所有 115 账号 | 下拉选择器（默认「遍历全部账号」） |

> 💡 **v0.8.1 增强**：路径映射三个字段均支持 UI 选择器，无需手动输入路径。云盘目录选择器仅在选定特定 115 账号时启用。

### Emby API 路由

| 路由 | 方法 | 说明 |
|------|------|------|
| `/api/emby/settings` | GET | 获取 Emby 配置 |
| `/api/emby/settings` | POST | 局部更新 Emby 配置（不覆盖其他字段） |
| `/api/emby/test-connection` | GET | 测试 Emby 连接（9 种错误分类） |
| `/api/emby/webhook` | POST | 接收 Emby Webhook 事件 |

> 💡 **v0.8.1 修复**：`POST /api/emby/settings` 采用局部 patch 模式，保存 Emby 设置时不会覆盖 302 重定向、监控账号、TG Bot 等其他配置。

## telegram 子项

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `botToken` | string | - | Telegram Bot Token（加密存储） |
| `chatId` | string | - | 接收通知的 Chat ID |
| `enabled` | boolean | false | 启用 TG 通知总开关 |
| `allowedUsers` | number[] | - | 允许通过 Bot 交互的用户 ID 列表 |
| `accountAlerts` | object | - | 账户状态通知配置（v0.8.2 新增，见下方） |

### accountAlerts 格式（v0.8.2 新增）

```json
{
  "enabled": true,
  "onError": true,
  "onRecover": true
}
```

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `enabled` | boolean | false | 启用账户状态通知 |
| `onError` | boolean | true | 账号异常（Cookie 失效等）时发送 TG 通知 |
| `onRecover` | boolean | true | 账号恢复正常时发送 TG 通知 |

> 💡 与「账号管理」页面的「更新 Cookie」按钮形成闭环：账号异常 → TG 推送 → 扫码更新 → 自动重检 → 恢复通知。

## lifeMonitor 子项

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `enabled` | boolean | false | 启用生活监控（实时同步） |
| `accounts` | string[] | - | 监控的 115 账号列表 |
| `pollInterval` | number | 30 | 轮询间隔（秒，最小 5） |
| `pathMappings` | array | - | 路径映射（见下方） |
| `eventTypes` | object | - | 各类事件开关（见下方） |
| `removeEmptyDirs` | boolean | true | 清理空目录 |
| `notifyOnlyOnError` | boolean | false | 仅错误时发 TG 通知（v1.0.5+）；true=正常操作不推送，仅错误（Cookie 失效/轮询异常/事件处理失败）时推送；false=每次操作都通知 |
| `firstPullMode` | string | `latest` | 首拉模式：`latest`/`all`/`last` |
| `moveMediaMode` | string | `recreate` | 移动模式：`recreate`（删旧重建）/`local_move`（本地移动） |

### pathMappings 格式

```json
[
  {
    "account": "我的115",
    "cloudPath": "/电影",
    "localPath": "/app/data/strm/电影"
  }
]
```

- `cloudPath`：115 网盘源路径
- `localPath`：本地 STRM 存储路径

### eventTypes 格式

```json
{
  "create": true,
  "remove": true,
  "rename": true,
  "move": true
}
```

| 事件 | 说明 |
|------|------|
| `create` | 新建/上传 → 生成 STRM |
| `remove` | 删除 → 清理 STRM |
| `rename` | 重命名 → 删除旧 STRM + 重建 |
| `move` | 移动 → 按移动类型处理 |

## 配置文件结构

### 用户配置目录：`./config/`

容器启动后，**用户可编辑的配置文件**位于 `./config/` 目录：

| 文件 | 说明 | 敏感字段 |
|------|------|---------|
| `config.json` | 登录凭据 | 密码 salt+SHA-256 |
| `settings.json` | 全局设置 | apiKey/botToken AES-256-GCM |
| `account.json` | 115 账号信息 | cookie/token AES-256-GCM |
| `tasks.json` | 同步任务定义 | - |

> 💡 首次启动会从 `.config/` 模板目录自动复制到 `./config/`，无需手动创建。**已存在的文件不会被覆盖**，用户配置是安全的。

### 默认模板目录：`./.config/`（v0.8.2 起增强密码哈希）

这是「默认设置源目录」，存放带点前缀的默认模板文件：

| 文件 | 说明 |
|------|------|
| `.config/.settings.json` | 系统设置默认模板 |
| `.config/.tasks.json` | 任务列表默认模板 |
| `.config/.account.json` | 账号列表默认模板 |
| `.config/.config.json` | 登录凭据默认模板 |

**使用规则**：

1. **Docker 部署**：容器启动时由 [`docker-entrypoint.sh`](https://github.com/wabisabi926/faststrm/blob/main/docker-entrypoint.sh) L11-54 自动完成 `.config/` → `config/` 复制
2. **本地开发（非 Docker）**：`readConfig()` 在文件不存在时会自动创建 `admin/admin`（已哈希），其他 3 个 JSON 不存在会返回 `[] / {}` 兜底，无需手动创建
3. **绝不覆盖已有用户配置**——只有目标文件不存在时才复制，用户自定义设置不会被破坏
4. **v0.8.2 修复**：复制 `config.json` 时若检测到 `username=admin` 且密码为空，会自动写入 `admin/admin` 的 SHA-256 + salt 哈希值，修复之前首次部署后 admin/admin 无法登录的漏洞（docker-entrypoint.sh L19-45）
5. 开发者可以修改 `.config/` 作为新项目的默认值模板，不用硬编码在 TypeScript 里

> `Dockerfile` L44 负责把本地 `.config/` 目录 COPY 到镜像内的 `/app/.config`，再由 entrypoint 分发到 `/app/config` 用户目录。

## 数据目录说明

`./data/` 目录包含运行时数据：

| 文件/目录 | 说明 |
|-----------|------|
| `syncDelHistory.json` | Emby 删除同步历史记录（最多 200 条） |
| `filePathDb.sqlite` | 文件路径数据库（SQLite） |
| `lifeMonitorState.json` | 生活监控断点状态 |
| `lifeIdPathCache.json` | cid → path 缓存 |

> 🧹 **v0.8.2 起移除 `.trash/`**：旧版本代码残留的 `data/.trash` 临时目录在代码中已无任何引用，相关清理逻辑已迁移到 `removeExtraFiles` + `deleteStrmDir(rootDirs)` 安全机制，目录已被整体删除。

## 修改密码

### 方法一：Web UI（推荐）

登录后进入「设置」→ 修改密码。

### 方法二：直接编辑文件

编辑 `config/config.json`，将 `password` 改为明文 `admin`（代码对旧格式有明文兼容），重启后用 `admin/admin` 登录，再进「设置」页面修改密码（自动写入 salt+SHA-256 哈希）。

> ⚠️ 当前密码使用 salt+SHA-256 机制，不要直接填纯 SHA-256 值（如 `8c6976e5...`），无法通过验证。明文密码仅作为重置过渡，登录后请立即在「设置」页面修改密码以生成哈希。
