## v0.9.7

**2026-08-21** · [与 v0.9.6 对比](https://github.com/wabisabi926/faststrm/compare/v0.9.6...v0.9.7)

### 修复

- 修复生活事件监控无法连接 115 服务器的问题（SSL 证书错误）
- 修复部分文件事件无法解析路径、导致监控中断的问题
- 修复扫码登录偶发失败的问题

### 新增

- 新增事件路径自动解析，即使接口不返回路径也能正确处理
- 新增 API 域名自动切换，遇到网络异常时自动切换备用线路
- 新增事件过滤，浏览、标星等操作不再触发通知

### 优化

- 事件轮询间隔默认从 30 秒缩短到 10 秒，事件更及时
- 整体请求失败率降低，监控更稳定

## v0.9.1

**2026-08-19** · [首个 Go 重构版本](https://github.com/wabisabi926/faststrm/tag/v0.9.1)

### 新增

- 完成 Go 语言重构，彻底移除 Node.js 和 Nginx 依赖
- 实现 115 扫码登录，手机扫一扫即可
- 实现生活事件监控，网盘增删改自动同步
- 实现 STRM 文件自动生成与清理
- 实现 Emby 主动刷库联动
- 实现 Telegram / Webhook 消息通知
- 实现 302 直连播放模式

### 优化

- UI 统一为简洁风格
- 前端升级为 Vite + React
- 后端升级为 Go 单二进制架构，部署更简单
