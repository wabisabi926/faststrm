# 快速开始

本指南带你完成首次配置，从零到能在 Emby 中播放 115 网盘的媒体。预计耗时 5-10 分钟。

***

## 步骤概览

1. **[部署服务](#步骤一部署服务)** — Docker 启动 faststrm
2. **[添加账号](#步骤二添加账号)** — 配置 115 网盘 Cookie
3. **[配置 STRM 设置](#步骤三配置-strm-设置)** — 设置 STRM 前缀和扩展名
4. **[创建同步任务](#步骤四创建同步任务)** — 扫描网盘生成 STRM 文件
5. **[配置 Emby](#步骤五配置-emby)** — 添加媒体库并测试播放

### 系统工作流程

```
┌──────────┐     ┌──────────────────┐     ┌──────────────┐
│ 115 网盘  │────▶│  FastStrm 处理引擎  │────▶│  本地 STRM   │
│ 变动事件  │     │ 轮询→分类→映射→处理  │     │  + 媒体服务器  │
└──────────┘     └──────────────────┘     └──────────────┘
```

* **被动模式**：手动创建扫描任务，按目录批量生成 STRM

* **主动模式**：启用「生活事件监控」，每 10 秒轮询网盘变动，自动同步

## 步骤一：部署服务

### Docker Compose（推荐）

```bash
git clone -b go https://github.com/wabisabi926/faststrm.git
cd faststrm
docker-compose up -d
```

### Docker 镜像

```bash
docker pull wabisabi926/faststrm:latest
docker run -d \
  --name faststrm \
  -p 8090:8090 \
  -v ./config:/app/config \
  -v ./data:/app/data \
  -v /path/to/your/strm:/app/data/strm \
  -e TZ=Asia/Shanghai \
  -e APP_ENV=prod \
  -e SERVER_HOST=0.0.0.0 \
  -e SERVER_PORT=8090 \
  --restart unless-stopped \
  wabisabi926/faststrm:latest
```

启动后访问 `http://localhost:8090`，使用默认账号登录：

```
用户名：admin
密码：admin
```

> ⚠️ **安全提示**：首次登录后请立即修改默认密码！

## 步骤二：添加账号

1. 进入「账号管理」页面
2. 点击「添加账号」
3. 填写信息：

   * **账号名称**：随意（建议与 OpenList/CD2 命名一致，便于回源）

   * **账号类型**：选择 `115`
4. 选择登录方式：

   * **📱 扫码登录（推荐）**：用 115 手机 App 扫码自动获取 Cookie，无需手动抓包

   * **🍪 手动粘贴 Cookie**：从浏览器 F12 抓取后粘贴（传统方式）

### 扫码登录（推荐）

1. 在添加账号对话框中切换到「扫码登录」标签
2. 选择客户端类型（默认「支付宝小程序」，兼容性最好；选「115 网页」会踢掉网页登录）
3. 用 115 手机 App 扫描弹出的二维码
4. 手机端确认后，Cookie 会自动回填并验证账号状态
5. 填写账号名称后保存即可

### 手动获取 Cookie

1. 浏览器打开 `https://115.com` 并登录
2. 按 F12 打开开发者工具
3. 切换到「Network」标签
4. 刷新页面，点击任意请求
5. 在右侧找到「Request Headers」中的 `Cookie` 值，完整复制
6. 粘贴到对话框的 Cookie 输入框

> 💡 Cookie 有效期约 7-30 天，过期可通过账号管理页面的「更新 Cookie」按钮扫码刷新，无需删除重建账号。

### Cookie 过期后怎么办

1. 账号状态变为「异常」，账号管理页面该行显示「更新 Cookie」按钮
2. 若启用了 TG 账户状态通知，会收到异常告警
3. 点击「更新 Cookie」→ 扫码刷新 → 系统自动重检状态 → 恢复正常后 TG 推送恢复通知

## 步骤三：配置 STRM 设置

进入「设置」页面，重点关注以下配置：

### STRM 前缀（v1.2.3+ 统一模式）

**只需填服务器地址，无需关心路径和开关**：

```
strmPrefix: http://你的服务器IP:8090
```

> **v1.2.3 架构变更**：`enable302` 开关已废弃，旧版「302 模式 / 直链模式」二选一已不存在。所有 STRM 统一生成 `/api/strm` URL，后端智能路由自动决策：
>
> * ISO / BDMV / M2TS 等原盘格式 → **强制 proxy**（支持 Range seek）
>
> * 普通 mkv / mp4 → **默认 redirect**（零服务器中转）
>
> * forceProxyUaTokens 命中的 UA → 强制 proxy
>
> * redirectCheck 探测失败 → 静默降级 proxy

* STRM 内容：`http://服务器:8090/api/strm?account=xxx&pickcode=xxx`

* 适用于 Emby Server / Emby for Kodi / Kodi / 浏览器 / Infuse 等所有客户端

* 旧 STRM 文件中 `/api/fs/get` 仍兼容（路由自动转发），可使用 `scripts/rebuild_strm.ps1` 批量重建

### 扩展名（可选）

* **STRM 扩展名**：哪些后缀生成 `.strm`（默认 mp4/mkv/avi/mov 等）

* **下载扩展名**：哪些后缀直接下载原文件（默认 srt/ass/nfo/jpg/png）

## 步骤四：创建同步任务

1. 进入「任务管理」页面
2. 点击「新建任务」
3. 配置任务：

| 字段      | 说明             | 示例                    |
| ------- | -------------- | --------------------- |
| 账号      | 选择 115 账号      | `我的115`               |
| 云端目录    | 115 网盘源路径      | `/电影`                 |
| 本地目录    | STRM 保存子目录     | `电影`                  |
| STRM 前缀 | 留空使用全局配置       | -                     |
| 定时任务    | cron 表达式       | `0 3 * * *`（每天凌晨 3 点） |
| 删除多余文件  | 远端不存在时删本地 STRM | 建议开启                  |

1. 保存后点击「执行」
2. 等待任务完成，查看生成数量

### 定时表达式速查

| 表达式           | 含义       |
| ------------- | -------- |
| `0 3 * * *`   | 每天凌晨 3 点 |
| `0 */6 * * *` | 每 6 小时   |
| `0 0 * * 0`   | 每周日凌晨    |
| 留空            | 仅手动执行    |

## 步骤五：配置 Emby

### 添加媒体库

1. Emby → 设置 → 媒体库 → 添加媒体库
2. 类型选择「电影」/「电视剧」
3. 路径指向容器内的 STRM 目录（如 `/app/data/strm/电影`）
4. 完成

### 配置 Webhook（可选，用于通知和删除同步）

1. Emby → 设置 → 高级 → 插件 → 安装「Webhooks」
2. 添加 Webhook：

   * URL：`http://你的faststrm地址:8090/api/emby/webhook`

   * 事件：勾选「项目新增」「项目删除」「播放开始」「播放结束」
3. 在 faststrm 的「Emby 通知」页面配置 Emby URL 和 API Key

### 启用 Emby 反向代理（推荐，解决 STRM/ISO 转码问题）

如果你使用 **Emby for Kodi / Emby for Android TV** 播放 STRM，**强烈建议开启**，否则 Emby 会强制转码导致 ISO 原盘无法使用 Libdvd 菜单：

1. 进入「Emby 通知」页面 → 「Emby 反向代理」卡片
2. 勾选启用，代理端口默认 `8097`
3. 在 Emby 客户端（如 Emby for Kodi）中，服务器地址改为：

   ```
   http://你的faststrm地址:8097
   ```

详细配置见 [Emby 集成 - 反向代理](Emby集成#emby-反向代理v118-推荐开启)。

### 播放测试

1. 在 Emby 中找到刚入库的媒体
2. 点击播放
3. 查看 faststrm 日志：

   ```
   [STRM] account=xxx pickcode=xxxx…xxx decision=redirect reason=default_redirect
   ```

   ISO / BDMV 等原盘文件会显示 `decision=proxy`（强制代理以支持 Range seek）。
