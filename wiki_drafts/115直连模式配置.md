# 操作指南 - STRM 统一路由策略（v1.2.3+）

## 📌 本页面已合并

v1.2.3 起，`enable302` 开关已废弃，所有 STRM 统一走 `/api/strm` 端点，智能路由自动决策 redirect（302 直连）或 proxy（代理中转）。

**完整路由策略、规则引擎、场景示例请查看：[STRM 路由策略](STRM-路由策略)**

---

## 旧版说明（仅供理解，已不适用）

v1.2.2 及之前版本提供「302 直连模式」和「代理模式」二选一：

| | 代理模式 (proxy) | 直连模式 (302) |
|---|---|---|
| STRM 路由 | `/api/strm` | `/api/fs/get` |
| 数据流向 | 播放器 → Go → CDN → Go → 播放器 | 播放器 → Go(302) → CDN → 播放器 |
| 本机带宽 | 全量占用 | **零占用** |

**v1.2.3 已废弃二选一设计**，所有 STRM 文件统一生成 `/api/strm` URL，后端根据**规则引擎**自动决策：

- **ISO / BDMV / M2TS** 等原盘格式 → **强制 proxy**（支持 Range seek）
- **Emby Server / Kodi / 浏览器** → 默认 **redirect**（零中转）
- **Infuse / VidHub**（forceProxyUaTokens 命中）→ 强制 proxy
- **302 HEAD 预检失败** → 静默降级 proxy
- **单账号并发 ≥ 8** → 超限自动切 redirect

详见 [STRM 路由策略](STRM-路由策略)。

---

## 升级指南

v1.2.2 升级到 v1.2.3 后：

1. **旧 STRM 文件仍兼容** — `/api/fs/get` 路由内部自动转发到 `/api/strm`
2. **建议重建 STRM** — 使用 `scripts/rebuild_strm.ps1`（Windows）或 `scripts/rebuild_strm.sh`（Linux）批量替换
3. **删除 `enable302` 配置** — 从 `settings.json` 和任务配置中移除（忽略不影响运行）
4. **无需额外配置** — 统一路由开箱即用，智能路由自动生效
