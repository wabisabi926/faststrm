# 开发指南

本指南面向开发者，介绍如何搭建本地开发环境、项目结构和构建流程。

---

## 技术栈

| 层级 | 技术选型 |
|------|---------|
| 后端 | Go + go-zero，RESTful API |
| 前端 | Vite + React + React Router |
| UI 组件 | shadcn/ui + Tailwind CSS + Radix UI |
| 数据库 | SQLite（本地嵌入式） |
| 115 协议 | 自研 SDK（Web + iOS API 双通道） |
| 前端托管 | Go `embed.FS`（SPA 嵌入二进制） |

## 本地开发环境

### 1. 克隆项目

```bash
git clone -b go https://github.com/wabisabi926/faststrm.git
cd faststrm
```

### 2. 后端开发

```bash
# Go 版本要求：1.23+
go version

# 安装依赖
go mod download

# 启动后端开发服务器
cd cmd/server
go run .
```

后端默认监听 `http://localhost:8090`。

### 3. 前端开发

```bash
cd frontend
npm install
npm run dev
```

前端开发服务器默认监听 `http://localhost:5173`（Vite dev server，HMR 热更新），API 请求会自动代理到 Go 后端 `http://localhost:8090`。**两个进程可同时启动互不占用同一端口。**

> 📌 **生产 vs 开发的端口差异**：
> - 开发模式（双进程）：浏览器访问 `5173` 拿页面 (HMR)，`/api/*` 通过 Vite 反向代理到 Go 的 `8090`
> - 生产模式（单二进制）：前端构建产物被 Go `embed` 进二进制，浏览器只访问 `8090`，SPA 页面和 API 同源提供（无代理也无跨域）

### 4. 构建前端并嵌入

```bash
cd frontend
npm run build
# 构建产物在 frontend/dist/，需手动拷贝到 internal/web/spa/ 或直接构建 Go 二进制
```

Go 二进制嵌入的是 `internal/web/spa/` 目录下的文件。前端构建后需要将产物复制过去：

```bash
# 从 frontend/dist 拷贝到 internal/web/spa
cp -r frontend/dist/* internal/web/spa/
```

### 5. 配置本地数据

开发环境首次启动会自动创建以下目录结构：

```bash
# 自动创建
./config/        # 配置文件目录
./data/          # 数据目录（SQLite、日志等）
```

默认配置从 `.config/` 模板目录拷贝，默认账号 `admin/admin` 自动哈希加密。

## Docker 构建

### 构建镜像

```bash
docker build -t faststrm:dev .
```

### 运行容器

```bash
docker run -d \
  --name faststrm-dev \
  -p 8090:8090 \
  -v ./config:/app/config \
  -v ./data:/app/data \
  -v /path/to/your/strm:/app/data/strm \
  -e TZ=Asia/Shanghai \
  -e APP_ENV=prod \
  --restart unless-stopped \
  faststrm:dev
```

### 多架构构建

```bash
# 交叉编译
CGO_ENABLED=0 GOOS=linux GOARCH=amd64 go build -o faststrm-linux-amd64 ./cmd/server/
CGO_ENABLED=0 GOOS=linux GOARCH=arm64 go build -o faststrm-linux-arm64 ./cmd/server/
CGO_ENABLED=0 GOOS=windows GOARCH=amd64 go build -o faststrm-windows-amd64.exe ./cmd/server/
```

## 版本注入

通过 `ldflags` 在编译时注入版本信息：

```bash
go build -ldflags="-s -w -X 'main.version=v0.9.1' -X 'main.BuildDate=$(date)'" -o faststrm ./cmd/server/
```

版本信息通过 `internal/handler` 包的 `appVersion` 变量暴露给前端。
