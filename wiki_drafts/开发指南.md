## 本地开发环境

### 1. 克隆项目

```bash
git clone https://github.com/wabisabi926/faststrm.git
cd faststrm
```

### 2. 安装依赖

```bash
cd frontend
npm install
```

> 💡 better-sqlite3 等原生模块需要编译工具。Windows 上建议使用 Visual Studio Build Tools。

### 3. 启动开发服务器

```bash
npm run dev
```

默认监听 `http://localhost:3000`。

### 4. 配置本地数据

开发环境需要创建以下目录结构：

```bash
mkdir -p ./data
mkdir -p ./config
```

首次启动会自动生成默认配置文件。

## Docker 构建

### 构建镜像

```bash
docker build -t faststrm:dev .
```

### 运行容器

```bash
docker run -d \
  --name faststrm-dev \
  -p 3000:3000 \
  -v ./config:/app/config \
  -v ./data:/app/data \
  -v ./logs:/app/logs \
  -v /path/to/your/strm:/app/data/strm \
  -e TZ=Asia/Shanghai \
  --restart unless-stopped \
  faststrm:dev
```

### 多架构构建

```bash
docker buildx build \
  --platform linux/amd64,linux/arm64 \
  -t wabisabi926/faststrm:latest \
  --push .
```

## 关键模块说明

### STRM 路由（`src/app/api/strm/route.ts`）

- 规则引擎决策逻辑
- 302 预检（redirectCheck）
- 并发限流
- 日志格式

### 生活事件（`src/lib/eventMonitor.ts`）

- 30 秒轮询循环
- 4 类事件处理（create/remove/rename/move）
- 熔断保护
- API 降级

### 任务执行（`src/lib/taskExecutor.ts`）

- 全量扫描流程
- 与生活监控的互斥控制
- Emby 刷新调度

### 文件数据库（`src/lib/filePathDb.ts`）

- SQLite CRUD 操作
- file_id 字符串绑定
- 路径索引

## Git 工作流

1. Fork 本仓库
2. 创建功能分支：`git checkout -b feature/amazing-feature`
3. 提交更改：`git commit -m 'feat: add amazing feature'`
4. 推送到分支：`git push origin feature/amazing-feature`
5. 提交 Pull Request

### 提交信息规范

遵循 Conventional Commits：

- `feat:` 新功能
- `fix:` Bug 修复
- `refactor:` 重构
- `docs:` 文档
- `style:` 格式调整
- `chore:` 构建/工具

## 测试

项目目前以手动测试为主。关键测试场景：

1. **STRM 生成**：创建任务 → 执行 → 检查生成的 STRM 文件
2. **路由策略**：
   - Infuse UA → 确认 proxy 模式
   - 浏览器 UA → 确认 redirect 模式
   - 115 CDN 不可达 → 确认降级 proxy
3. **删除同步**：在 Emby 删除媒体 → 确认 STRM 清理
4. **生活监控**：在 115 网盘增删文件 → 确认 STRM 同步
5. **并发限流**：多客户端同时播放 → 确认限流切换
