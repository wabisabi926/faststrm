# 分享链接转存

Fast Strm 支持解析 115 分享链接，浏览分享内容，一键转存到你的网盘并自动生成 STRM。

---

## 使用入口

在任意页面顶部有全局输入框：

1. 粘贴 115 分享链接
2. 点击「查看」或按回车
3. 弹出分享详情对话框

### 支持的链接格式

- 完整 URL：`https://115.com/s/swxxxxxx?password=yyyy`
- 短链接：`https://115cdn.com/s/swxxxxxx`
- 纯分享码：`swxxxxxx`
- 带提取码：`swxxxxxx-yyyy`

---

## 浏览分享内容

分享详情对话框支持：

- 表格展示当前层级文件/文件夹
- 点击文件夹进入子目录
- 面包屑导航可回跳上层
- 显示分享标题和创建时间

---

## 转存并生成 STRM

### 操作步骤

1. 勾选要转存的文件/文件夹（支持多选）
2. 点击底部「保存到我的网盘」
3. 在弹出的目录选择器中选择目标网盘目录
4. 确认后开始转存

### 自动 STRM 生成

转存成功后，faststrm 会：

1. 反查目标目录路径
2. 匹配已配置的任务（同账号 + 路径前缀匹配）
3. 扫描转存后的文件
4. 为视频文件生成 STRM
5. 显示生成数量

> ⚠️ **前提**：必须已配置对应的同步任务，且任务路径包含转存目标目录。否则只转存不生成 STRM。

---

## 转存流程

```
用户勾选文件 → 点击保存
  ↓
弹出目录选择器 → 用户选择目标目录
  ↓
POST /api/115/share { action: "receive", fileIds, toPid }
  ↓
115 API 转存到网盘
  ↓
反查目标目录路径 → 匹配 Task
  ↓
扫描目标目录的视频文件 → 生成 STRM
  ↓
Toast 提示：保存成功并生成了 N 个 STRM
```

---

## 当前限制

| 限制 | 说明 |
|------|------|
| 无分页 UI | 后端支持分页，前端默认 limit=32，无「加载更多」 |
| 无递归转存 | 勾选文件夹时，STRM 生成只扫描一层 |
| 无批量全选 | 需逐个勾选 |
| 路径反查 | `getPathByCid` 仅取当前层，无法向上回溯 |
| 不写入 filePathDb | 转存生成的 STRM 不记录到 DB |

> 这些限制将在后续版本优化。
