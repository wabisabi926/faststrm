# STRM 清理对账

随着时间推移，本地 STRM 文件可能与 115 网盘实际状态不一致（手动删除、移动、API 异常等）。STRM 清理对账功能帮助发现并修复这些不一致。

---

## 三种清理方式

### 1. 孤儿扫描

**场景**：本地有 STRM，但 115 网盘对应文件已不存在。

**操作步骤**：
1. 进入「设置」→「STRM 清理」
2. 选择账号和目录
3. 点击「扫描孤儿」
4. 扫描完成后显示孤儿列表
5. 确认后点击「执行清理」

**清理动作**：
- STRM 文件直接物理删除（`fs.unlinkSync`）
- 删除 filePathDb 中对应记录
- 清理空目录（保护映射根目录）

### 2. 全量对账（reconcile）

**场景**：本地 STRM 与 115 网盘双向对比，找出差异。

**操作步骤**：
1. 点击「全量对账」按钮
2. 系统自动：
   - 暂停生活监控（避免竞争）
   - 递归扫描 115 网盘
   - 对比本地 STRM + filePathDb
   - 列出差异：缺失的 STRM / 多余的 STRM / DB 幽灵记录
3. 确认后执行修复
4. 自动恢复生活监控

**DB 幽灵记录**：filePathDb 中有记录，但本地 STRM 和 115 网盘都不存在。通过 `removeGhostRecords` 清理。

### 3. 删除机制

所有 STRM 删除操作均为**直接物理删除**（`fs.unlinkSync` / `fs.rmSync`），不经过回收站。涉及场景：
- 手动删除事件触发的 STRM
- 孤儿扫描清理的 STRM
- 任务执行时删除的多余 STRM

**安全保护**：
- **熔断保护**：单次删除超过 100 条或占比超过 50% 时触发熔断，停止删除
- **试运行模式**：Emby 删除同步支持试运行，只记日志不删除
- **空目录保护**：`removeEmptyParents` 通过 `rootDirs` 参数保护映射根目录

> 误删后可在 115 网盘恢复文件后重新执行全量扫描生成 STRM。

## 清理流程

```
触发清理（手动/定时）
  ↓
suspendMonitorForFullScan(account)  暂停生活监控
  ↓
递归扫描 115 网盘目录
  ↓
对比本地 STRM：
  网盘有 + 本地无 → 需生成
  网盘无 + 本地有 → 孤儿，直接物理删除
  网盘有 + 本地有 → 检查路径是否一致
  ↓
removeGhostRecords  清理 DB 幽灵记录
  ↓
removeEmptyParents  清理空目录（保护映射根目录）
  ↓
clearMonitorSuspend(account)  恢复生活监控（finally）
  ↓
TG 通知清理结果
```

---

## 防误删机制

| 机制 | 说明 |
|------|------|
| 熔断保护 | 单次删除 >100 条或占比 >50% 时触发熔断，停止删除 |
| 空目录保护 | `removeEmptyParents` 通过 `rootDirs` 参数保护映射根目录 |
| 监控暂停 | 清理期间暂停生活监控，避免竞争 |
| 超时恢复 | `FULLSCAN_TIMEOUT_MS = 10分钟`，超时自动恢复监控 |
| 三层保护 | 清理函数 + 路由层 finally + 超时兜底 |

## 定时清理

可在任务配置中设置 cron 定时执行清理：

```json
{
  "type": "cleanup",
  "cron": "0 4 * * 0",
  "account": "我的115",
  "path": "/电影"
}
```

> 💡 建议每周执行一次全量对账，频率不要太高（消耗 115 API 配额）。

## 性能参考

| 目录规模 | 扫描耗时 | API 调用次数 |
|----------|----------|-------------|
| 100 文件 | < 10 秒 | ~10 |
| 1000 文件 | 1 分钟 | ~50 |
| 10000 文件 | 10 分钟 | ~500 |

> API 调用受令牌桶限流保护，不会触发 115 频控。

## 任务执行时的自动清理（与手动清理共用同一套判定）

全量任务跑完会顺手做一次对账，**只认 STRM 内容里的 pickcode**，不会按路径删文件：

| 情况 | 处理 |
|---|---|
| 云端已删除该影片 | 本地 STRM 判为孤儿，按「设置 → 孤儿 STRM 清理」的模式处理 |
| 云端改名/移动（监控未开） | pickcode 仍有效但本地路径与云端不一致 → 判为残留并清理 |
| 仅 DB 快照里有的 pickcode | 一律保留（路径未知，防误删） |
| 你自己放的海报/字幕/手写 STRM | 不碰（非 faststrm 生成的 STRM 直接跳过） |

两个可选动作（设置页勾选）：

- **同时删除同名的 nfo / 海报 / 字幕**：只删 `.nfo/.jpg/.png/.srt/.ass/.ssa/.sub/.vtt/.sup`，**绝不删 `.mkv/.mp4` 等视频文件**（避免误删你本地下载的同一部影片）。
- **删完后清理空目录**：从被删文件所在目录向上删空目录，到任务目标目录为止。

保护阈值仍然生效：单次删除超过 10%、超过 1000 个、或涉及超过 20 个目录，会进入保护态不执行。
