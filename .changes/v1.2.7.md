# v1.2.7 - 2026-09-04

修复设置保存与任务历史日志两个小 bug，页面宽度进一步调优的一版。

## 亮点速览

* 修复「强制代理 UA 标识」清空后保存不生效的问题
* 修复任务历史 → 查看日志显示「历史记录不存在」的 bug
* 全站 PC 端页面宽度统一收敛到 `max-w-5xl`，更紧凑耐看
* 登录页副标题改为「更快、更强、更硬」

## ✨ 新增

* **任务历史日志独立接口**：新增 `GET /api/taskHistory/:executionId/logs`，按执行记录 ID 精确拉取日志，不再依赖聚合接口

## ⚡ 优化

* 全站 PC 端页面宽度从 `max-w-6xl` 收敛到 `max-w-5xl`（1024px），表单页和列表页都更紧凑
* STRM 清理统计卡片响应式降级：窄容器下少列显示，避免卡片过挤

## 🐛 修复

* 修复「强制代理 UA 标识」清空后保存仍显示旧值的问题
* 修复任务历史 → 查看日志显示「历史记录不存在」且文件数量为 0 的问题
* 修复无 UA 信息时 Emby 反代播放策略偶发判断错误的问题

## 🧪 测试

* 新增 `internal/handler/task_history_test.go`，覆盖任务历史日志接口
* 新增 `internal/handler/emby_settings_test.go`，覆盖 UA 标识保存与清空场景

## ⚙️ 配置提示

* `强制代理 UA 标识` 清空后保存即可生效，无需手动改配置文件
* 任务历史日志已支持任意历史执行记录单独查看
