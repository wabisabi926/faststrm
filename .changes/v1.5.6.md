# v1.5.6 - 2026-10-23

> 2026-10-26 补充：外部 STRM 认证头、路径前缀匹配、SSE 并发、刷库合并与优雅退出修复。

## 亮点速览

* 播放反代缓存按认证身份隔离，匿名或其他令牌无法复用已缓存的 CDN 直链
* 首次管理员初始化改为原子操作，并发请求不再覆盖已创建的管理员
* 目录/文件改名或移动后自动迁移托管索引，后续清理不再把新路径当未托管
* 账号读取改为快照，页面、巡检与生活监控并发访问更安全
* 已下线的 STRM URL/文件名模板彻底失效，手工写回配置也会被清理

## 🔒 安全

* Emby 反代播放缓存（URL / STRM 源 / 用户关联）纳入请求头与查询参数认证身份；无认证请求不再读写受保护缓存
* 首次初始化管理员在写锁内完成「未初始化检查 + 落盘 + 内存替换」，并发 setup 仅一个成功

## 🐛 修复

* 目录/文件 rename、move 成功后同步迁移 `managed_strms` 本地与云端路径；新路径冲突整体回滚，避免托管 STRM 被当成未托管而漏删
* `AccountStore` 的 Get/List/Upsert 返回深拷贝快照（含 `CookieValid`），消除巡检、页面与监控并发读写的数据竞争
* 设置读取、Update、保存三处强制清空已下线的 STRM 模板字段，修复手工写回 `settings.json` 后「生成用模板、改名/清理用默认名」造成的重复 STRM 或旧文件残留
* 账号更新接口在写入后重新读取快照，返回最新 Cookie 与三态状态

## ⚡ 优化

* 新增并发初始化、缓存隔离、目录生命周期、账号快照与模板下线回归测试
* 同步配置说明、STRM 生成、播放链路与迁移工具文档

## 2026-10-26 补充修复

### 🔒 安全

* 外部 STRM 重定向解析仅发送 `User-Agent` / `Accept`，不再把 `X-Emby-Token`、`Authorization`、`Cookie` 与用户身份头带出到第三方媒体源；跨主机重定向额外兜底清除凭据

### 🐛 修复

* 路径前缀更新、删除、计数与快照查询统一按字面量匹配（`ESCAPE '\'`），目录名含 `_`、`%`、`\` 时不再误改或误删相邻子树索引
* SSE 订阅表长度改为持锁读取，消除多客户端并发连接/断开时的数据竞争
* 全量任务刷库按目录合并并限制并发，避免首次建库把 Emby 打进数万次 API
* 进程退出（Docker 重启、信号、托盘）先停止调度/监控/反代，取消并等待运行中任务（最长 20s）；启动时回收上次异常退出遗留的 `running` 执行记录
* 播放代理补 10s 连接/TLS 握手超时与单主机连接上限，避免 CDN 黑洞节点长时间占用并发额度
* 执行记录收尾失败时重试并记录错误，降低记录永久停在 `running`
* STRM 写盘在 rename 前 `fsync`，启动纳管时清理超过 24h 的 `.strm.tmp-*`
* 托管索引迁移失败写入生活事件日志，提示下次启动纳管自动修复

### ⚡ 优化

* 新增 `FASTSTRM_LOG_LEVEL` 环境变量，可按需开启 debug 日志
* `/api/health` 未注入版本时返回 `dev`，避免源码兜底版本漂移
* 新增认证头边界、字面路径、SSE 并发、刷库合并、代理超时与临时文件清理回归测试；完成隔离配置下的真机反代、SSE 并发与优雅退出验证

## 升级说明

* 直接覆盖升级即可，无数据库结构变更
* 若曾手工把 `strmUrlTemplate` / `strmFilenameTemplate` 写回 `settings.json`，升级后会被清空；旧配置首次迁移仍备份为 `settings.json.templates-v1.*`
* 管理员初始化、账号读取与清理行为均向后兼容，无需修改现有任务或 STRM 文件
* 外部 STRM 源若依赖 Emby 认证头鉴权，升级后将不再收到这些头，需在源侧配置独立鉴权；内置 `/api/strm` 与常规播放不受影响
* 全量任务结束时的 Emby 刷库请求会按目录合并；退出服务会等待运行中任务取消或完成（最长约 20s）
