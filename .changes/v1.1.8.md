# v1.1.8 - 2026-08-31

Emby 反向代理（PlaybackInfo STRM 强制 DirectPlay）+ CI 超时修复。

## ✨ 新增

### Emby 反向代理（方案 B）
* 新增 `internal/service/embyproxy` 包，精简移植 MoviePilot embyreverseproxy 核心逻辑
* 拦截 `/Items/{id}/PlaybackInfo` 请求，识别 STRM 源（MediaSource.IsRemote + Protocol=Http 或 Path 为 HTTP URL）
* 强制修改 MediaSource：SupportsDirectPlay=true、SupportsDirectStream=true、SupportsTranscoding=false，移除 TranscodingUrl
* 设置 DirectStreamUrl 为代理内的相对流路由（/videos/{id}/stream、/audio/{id}/stream）
* PlaybackInfo 阶段缓存 STRM MediaSourceId → HTTP URL 映射，媒体流请求返回 302 直链到 CDN
* EmbySettings 新增 ProxyPort 配置字段，设为 > 0 时自动启动反代 server
* 用户将 Emby 客户端（Emby for Kodi gen）连接到反代端口即可生效，无需修改 STRM 生成逻辑

### CI 稳定性加固
* go test 加 `-timeout=15m` + `-race` 防止 `-coverpkg` 模式下超时

## 🐛 修复

* pkg/logger + pkg/strmutil 覆盖率测试修复（os.WriteFile 权限 0644→0600）
* CI goimports 格式修复（strm_cache.go import 三段分组）
