# v0.9.6 - 2026-08-21

飞牛 fNOS 路径权限与 qmediasync 完全对齐，修复应用目录选择、任务日志查看、监控状态显示等关键场景。

## ✨ 新增

- 新增 fNOS 安装向导自定义端口功能（默认 8090），端口号持久化在用户数据区，升级不丢失
- 新增本地目录选择器「空列表友好提示」，未授权时明确引导用户在飞牛应用设置中勾选「存储卷」权限

## 🔥 删除

- 移除「选择远程路径后自动填写本地路径」的错误弹窗（之前会把本地路径填成无效的同名目录）
- 精简 fNOS 应用图标尺寸，仅保留官方规范要求的 64×64 和 256×256 两种

## ⚡ 优化

- fNOS 目录权限与 qmediasync 行为一致：只返回用户实际授权的路径，不再列出 20+ 无关的系统挂载点
- 监控状态显示优先级：有错误 → 红色异常；运行中 → 绿色；待保存 → 黄色；已停止 → 灰色，之前"运行中但有错误仍显示绿色"的误导已修复
- fNOS 默认管理员密码统一为 `admin`（与参考项目一致）

## 🐛 修复

- 修复任务日志查看完全失效的问题（前后端契约不匹配）
- 修复生活事件监控 API 返回 404 导致无法拉取事件的问题（修正域名 + 路径 + 请求方式）
- 修复 fNOS 安装向导泄露默认密码的问题
- 修复监控停止、系统关闭时被误记为错误的问题
