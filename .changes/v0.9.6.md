v0.9.6 - 2026-08-21

## 飞牛 fNOS 路径权限、任务日志 & 监控状态修复

### 后端 directory.go — fNOS 路径权限对齐 qmediasync

- **`defaultRoots` fNOS 分支改为仅返回白名单**：之前会枚举 `/proc/mounts` 系统挂载点（`/boot`、`/fs`、`/vol00/RemovableDisk` 等）+ 硬编码 NAS 卷根，导致用户看到 20+ 个无关路径。现在只返回 `TRIM_DATA_ACCESSIBLE_PATHS` + `TRIM_DATA_SHARE_PATHS`，和 qmediasync 行为一致
- **未授权时返回友好提示**：fNOS 环境下无授权路径时返回提示信息，引导用户在飞牛应用设置中勾选存储卷权限
- 用户只需在飞牛应用设置中勾选「存储卷」权限（无需管「应用文件」权限），系统会自动注入到 `TRIM_DATA_SHARE_PATHS`

### 前端 LocalDirectoryTreeDialog.tsx — 空列表友好提示

- 新增 `rootMessage` state 保存后端返回的提示信息
- 空列表时显示后端消息 + 引导用户通过输入框粘贴路径跳转

### 前端 DirectoryTreeDialog.tsx — 删除错误的自动填写功能

- 删除选择远程路径后的「自动填写本地路径」弹窗
- 之前选择远程路径 "电影" 后，本地路径也被填为 "电影"（无效路径），导致任务在应用工作目录下创建 `./电影/` 而非用户期望的媒体目录
- 用户现在需要通过本地路径选择器独立选择有效的本地绝对路径

### 前端 task/index.tsx — 修复任务日志查看

- **修复判断逻辑错误**：后端 `HandleTaskLog` 返回 `text/plain` 纯文本，前端之前用 `logRes.data.taskId`（JSON 字段）判断，导致日志查看功能完全失效
- 改为直接判断响应内容是否为空：有日志跳转日志页，无日志提示「任务尚未执行，暂无日志」
- 未执行任务不再报错（`toast.info` 而非 `toast.error`）

### 监控状态显示修复

- **后端 `handlePollError` 排除 `context.Canceled` / `context.DeadlineExceeded`**：这些是正常的停止行为（用户点击停止、系统关闭），不应记录为错误
- **前端状态显示优先级**：有错误 → 红色「异常」；运行中 → 绿色；待保存 → 黄色；已停止 → 灰色
- 之前状态标签逻辑只看 `running` 字段，运行中但有错误时仍显示绿色「运行中」

### 生活事件监控 API 修复（115 域名/路径变更）

- **LifeClient.doRequest 增加 HTTP 状态码检查**：非 2xx 状态码返回带状态码和响应片段的清晰错误（之前 404 HTML 被直接送进 JSON 解析导致 `invalid character 'P'` 报错）
- **PullEvents API 域名+路径+请求方式修正**：`life.115.com/.../live/listhistory` (POST) → `web.api.115.com/.../life/listhistory` (GET query params)，修复 `Page not found.` 404
- **LifeShow API 域名+路径修正**：`life.115.com/.../calendar/setoption` → `web.api.115.com/.../life/setoption`
