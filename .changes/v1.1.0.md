# v1.1.0 - 2026-08-26

代码质量全面加固、前端类型安全上线、时间常量标准化、Windows 默认登录地址修复、监控状态按钮语义修正。

## ✨ 新增

### Handler 层单元测试
- 新增 `internal/handler/account_test.go`：共 15 个用例，覆盖 ListAccounts / CreateAccount / UpdateAccount / DeleteAccount / GetAccountStatus 的参数校验、账号存在性、改名逻辑（originalName 查找）、字段同步
- 新增 `internal/handler/strm_test.go`：共 9 个用例，覆盖 STRM 端点前置校验——缺失 account / pickcode、非法 pickcode（中文 / 空格 / 路径穿越 / URL / 过短 / 纯点号）、合法格式、账号不存在、HEAD 方法参数校验链路
- 测试基础设施：`newTestAccountStore` 临时 JSON Store、`url.Values` 安全编码特殊字符（空格等）
- 测试期间顺带修复了 UpdateAccount 改名分支字段不同步的回归 Bug

### 前端类型系统
- 新增 `frontend/src/types/api.ts`：4 个接口——`TaskApiResponse`、`TaskRuntimeApi`、`TaskScheduleApi`、`DirectoryNodeApi`

## ⚡ 优化

### 前端类型安全
- 任务列表 / 目录树 / 新增账户等 5 处 `any` 类型替换为强类型接口
- 错误处理由 `any` 改为 `unknown` + AxiosError 类型守卫，精准提取后端错误原文
- 为 7 处纯初始化 `useEffect` 空依赖添加 eslint disable 注释并说明原因
- 导出 lib/axios.ts 的 AxiosError 供组件复用

### 时间常量标准化
- 超时 / TTL 常量统一使用 `time.Duration`（如 `10*time.Minute` 代替 `600000`），消除魔法数字
- Settings JSON 字段保持 int（毫秒）协议不变，通过 getter 返回 `time.Duration`，兼容现有数据

### Windows 地址显示（托盘 + 启动日志）
- `displayURL()` 函数将监听的 `0.0.0.0` / `[::]` 在显示层替换为 `localhost`，实际 Host 不变
- 托盘菜单「打开 Web 界面」与启动日志都走 displayURL，解决 Windows 下默认打开 `0.0.0.0` 无法访问的问题
- 非 Windows 端（飞牛 fNOS / Docker / Linux / ARM64）不受影响

### 监控状态按钮语义分化
- 新增 `handleRemoveFromMonitor`：从 LifeMonitor 配置列表中移除指定账号并持久化
- 按钮按 5 场景分化：pending 灰 disabled / 账号不存在红「从监控列表移除」/ 异常双按钮 / 运行中「停止」/ 已停止「启动」

## 🐛 修复
- 修复 Handler UpdateAccount 改名时 Cookie / AccountType / Account / Password / URL 更新被丢弃的回归 Bug
- 修复 Windows 版本 exe 默认打开 `http://0.0.0.0:8090/` 无法访问 → 改为 `http://localhost:8090/`
- 修复监控配置引用已删除账号时按钮语义错误（原"停止"→改为「从监控列表移除」）
- 修复前端 `STATUS_MAP[undefined]` TS2538 编译错误，添加字符串兜底
