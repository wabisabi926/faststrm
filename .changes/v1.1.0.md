# v1.1.0 - 2026-08-26

代码质量加固、前端类型规范、时间配置标准化、Windows 默认访问地址修复、监控状态按钮语义修正。

## ✨ 新增

### Handler 层单元测试
- 新增账户 CRUD 与 STRM 参数校验测试，共 24 个用例覆盖参数校验、改名查找、字段同步、非法 pickcode 过滤等关键路径
- 测试使用临时 Store，不污染真实数据；特殊字符通过 `url.Values` 安全编码

### 前端类型系统
- 新增 `TaskApiResponse`、`DirectoryNodeApi` 等接口类型，明确任务数据与目录节点结构

## ⚡ 优化

### 前端类型规范
- 任务列表、目录选择器、新增账户等 5 处 `any` 类型替换为强类型接口
- 错误处理统一为类型守卫，精准提取后端错误原文
- 纯初始化 `useEffect` 空依赖添加注释说明，避免误改

### 时间配置标准化
- 超时、缓存 TTL 等时间常量统一使用 `time.Duration`（如 `10 * time.Minute`），消除魔法数字
- Settings JSON 字段保持毫秒协议不变，通过 getter 转换为 `time.Duration`，兼容性零影响

### Windows 默认访问地址
- 托盘菜单「打开 Web 界面」与启动日志显示的地址，监听 `0.0.0.0` / `[::]` 时统一替换为 `localhost`
- 实际监听 Host 保持不变，局域网、远程访问不受影响；飞牛 fNOS、Docker、Linux/ARM64 等其他端行为不变

### 监控状态按钮分化
- 设置页「生活事件监控」按钮按真实场景分化：待保存显示灰色 `待保存`；账号不存在显示红色 `从监控列表移除`；账号异常提供启动/停止+移除双按钮；运行/停止显示对应按钮
- 新增从监控列表移除功能，直接清理无效配置并持久化

## 🐛 修复
- 修复编辑账号同时改名称与 Cookie/密码时，非名称字段未同步保存的问题
- 修复 Windows 版本默认打开 `http://0.0.0.0:8090/` 无法访问的问题，统一显示为 `http://localhost:8090/`
- 修复监控配置引用已删除账号时按钮仍显示「停止」的语义错误，改为「从监控列表移除」
- 修复任务列表状态为空时前端类型索引报错导致白屏的问题
