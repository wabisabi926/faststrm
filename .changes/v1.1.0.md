# v1.1.0 - 2026-08-26

本版本主要围绕日常使用稳定性和操作易懂性做了升级：Windows 版本点托盘就能直接打开、监控按钮会按真实状态显示不同的文字、编辑账号不会再丢信息、整体更少出问题。

## ⚡ 体验优化

### Windows 打开更顺手
- 双击 exe 启动后，控制台显示的访问地址、以及右下角托盘菜单里的"打开 Web 界面"，默认都会打开 `http://localhost:8090`，直接点就能进，不再出现"此网页无法访问"
- 实际服务仍然监听所有网络地址，局域网、远程访问都不受影响

### 监控列表按钮更聪明
「设置 → 生活事件监控」按钮会按真实情况变化：
- 刚加还没保存的账号 → 灰色「待保存」
- 账号已经被删除了（监控里有但账户管理里找不到）→ 红色「从监控列表移除」（之前显示"停止"点了必败）
- 账号异常但还在 → 启动/停止 + 移除双按钮
- 正常运行中 → 停止；已停止 → 启动

### 改账号更稳妥
编辑账号时如果同时改了账号名称 + Cookie/密码/网盘地址之类的信息，所有内容都会一起保存好，不会再出现"只改了名字，别的内容没保存"的情况

### 整体更稳定
- 后台对账号管理、STRM 生成等 24 项关键操作增加了自动检查
- 时间相关配置统一用更清晰的方式管理，避免弄错"到底是几秒还是几分钟"
- 页面操作提示和错误消息更准确、更直白

## 🐛 问题修复

- **Windows 默认访问地址**：之前双击 exe 后控制台/托盘显示 `http://0.0.0.0:8090/`，Windows 点这个打不开。现在统一显示 `http://localhost:8090/`，点了就能用
- **监控按钮点不动**：之前监控列表引用了已删除账号时，按钮还是"停止"，点击必然报错。现在按钮直接显示「从监控列表移除」，点一下就清掉无效配置
- **编辑账号信息丢失**：改账号名称时同时改 Cookie / 密码 / 账户类型等信息，非名称字段会悄悄丢失。现在全部一起保存，不再丢内容
- **任务列表偶发白屏**：任务状态未加载完成时页面偶尔白屏或报错。现在加载过程更稳定，不会因为状态没出来就报错
