# v0.9.2 - 2026-08-20

## ✨ 新增

- 新增 STRM 写入并发数可配置，可根据服务器性能调整
- 新增自动下载元数据（nfo/jpg/png 等）开关
- 新增生活事件监控去重配置，避免重复处理
- 新增监控 API 冷却与重试配置，提高稳定性

## ⚡ 优化

- 任务执行时的资源释放更彻底，避免内存泄漏
- 读取配置、序列化等出错时自动回退默认值，不再直接中断

## 🐛 修复

- 修复任务执行过程中 cancel 函数未调用导致的资源泄漏
- 修复多处错误被静默忽略（读取设置、JSON 编解码、目录遍历、Emby 请求等）
- 修复本地目录浏览存在路径穿越的安全风险
