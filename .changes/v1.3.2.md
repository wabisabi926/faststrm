# v1.3.2 - 2026-09-15

Emby 反代端口支持播放 ISO 原盘、生活监控更稳、启动更快的一版。

## 亮点速览

* Emby 通过反代端口也能正常播放 ISO 原盘 / BDMV 等原盘格式（之前会转圈打不开，现在走代理流、可正常拖动进度）
* 生活监控整体加固：同一文件重复事件不再重复处理，事件漏拉、文件换位置后 STRM 补不上的问题一并修复
* 图片形式的 ISO / 原盘在反代下不再触发浏览器跨域拦截，播放更顺滑
* 启动速度提升：Telegram 机器人和生活监控自动启动不再拖慢 Web 服务打开（http://localhost:8090 更快可访问）
* 生活监控移动文件默认使用本地移动（更快），路径映射的「添加/删除」按钮位置更清晰

## ✨ 新增

* Emby 反向代理：STRM 源文件名以 STRM 文件内容为准解析，ISO / BDMV / M2TS / TS 等原盘与直播格式在反代端口走代理流播放（支持 Range 拖动），普通 MKV / MP4 仍保持高速 302 直连
* 反代端口缓存未命中时自动实时查询 PlaybackInfo，减少「打不开 / 转码失败」的兜底路径

## ⚡ 优化

* 启动速度：Telegram 机器人自动轮询改为异步启动并缩短拨号超时，不再因网络拨号拖住 Web 服务首次打开
* 生活监控：事件游标改为「ID + 时间」成对推进，断点续传更准确，重启后不易丢事件
* 生活监控：事件分页按数量正确终止，账号验证只拉取必要范围，减少无效请求
* 生活监控：移动文件默认模式改为本地移动（`local_move`），移动效率更高
* 生活监控：路径映射的「添加 / 删除」按钮移到本地路径输入框之后，操作更直观

## 🐛 修复

* Emby 反代端口无法播放 ISO 原盘的问题：之前因文件名判断不到扩展名而走错路径，现在可从 STRM 文件正确识别并走代理流
* 浏览器（Emby Web）播放原盘时的跨域问题：反代自动拦截 crossorigin 并修补播放器脚本，避免 CORS 导致黑屏或失败
* 生活监控：同一文件出现重复事件时重复生成 / 重复删除的问题，改为按 file_id 去重
* 生活监控：新文件事件偶发拿不到下载标识导致 STRM 未生成的问题，增加兜底反查
* 生活监控：资源刷新 / 转存等旧事件导致的重复处理，已通过事件去重修复
