# v1.0.2 - 2026-08-24

修复生活事件监控生成 STRM 完全不生效的致命问题，并新增「错误主动推送 + 仅错误模式」，运行更安心。

## ✨ 新增

- 新增监控错误主动推送 Telegram：Cookie 失效 / 轮询异常 / 批量事件处理失败，出错必达，不再"静默失败"
- 新增「仅错误时发 TG 通知」开关：开启后正常的创建 / 删除 / 移动 / 重命名不刷屏，只在异常时推送
- 新增 Emby webhook 入口诊断日志：入库通知不生效时可以看日志确认 webhook 是否真的到达

## ⚡ 优化

- 媒体路径查询独立固定走官方稳定通道，不再被生活事件 API 的备用线路切换影响，避免回归

## 🐛 修复

- 修复生活事件监控生成 STRM 完全不生效的致命问题（旧接口返回事件缺少 pick_code，导致所有创建事件被跳过），现改为优先走字段完整的 iOS 端接口，失败时回退 web 接口
- 修复 STRM 删除时默认生成 `.deleted.bak` 备份占磁盘的问题：默认改为硬删除，并提供配置开关；旧配置自动迁移
- 修复对账清理 auto_clean 模式仍生成 .bak 残留的问题
- 修复 Emby webhook URL 在 HTTP 环境下点击复制报错的问题（降级为兼容方式）
