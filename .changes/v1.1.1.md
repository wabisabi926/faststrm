# v1.1.1 - 2026-08-28

STRM URL 签名、SQLite Schema 迁移、Emby 通知刮削等待、前端测试覆盖、三大页面模块化拆分、默认值对齐。

## ✨ 新增

### STRM URL 签名（T9）

* 新增 HMAC-SHA256 签名 token：STRM 代理 URL 自动追加签名，防 URL 被盗链滥用

* 签名 token 默认关闭，开启后首次启动自动生成 32-byte secret，无需手动配置

* 后端代理 `/api/strm` 与 `/api/fs/get` 校验签名，非法或过期返回 401

* 未开启签名时完全向后兼容（老用户无感知）

### SQLite Schema 版本化迁移（T10）

* 自研轻量 migration 框架：`schema_migrations` 表记录已执行迁移，幂等不重复

* 每条迁移在事务中执行，失败即回滚，不会出现半迁移状态

* `DefaultSettings()` 自动兜底：settings.json 缺失字段时不会变成零值

### 前端 Vitest 组件测试

* 新增 MonitorSettingsTab 测试（12 用例）、AddAccountDialog 测试（10 用例）、MobileTaskCard 测试（18 用例）

* 补齐 jsdom 缺的 Radix UI 必需 API（hasPointerCapture / scrollIntoView 等）

* 新增测试 fixtures（accounts / embySettings）与 mocks（axios）

### Emby client115 单元测试

* 新增 client115 package 21 个单元测试，用 `http.RoundTripper` mock 覆盖核心 API 路径

* 覆盖扫码登录、文件列表、下载链接、文件夹遍历等关键方法

### Emby 通知刮削等待

* 新增 `waitForMetadata` 轮询逻辑：webhook 到达后等 3s 一次、最多 60s，等 Emby 刮削元数据落库

* 超时或详情获取失败时降级使用 webhook 自带字段，不丢通知

### mergeDetail 辅助函数

* 抽取出 detail→webhookDetail 非零覆盖逻辑为单一函数 `mergeDetail(base, override)`

* 消除 `handleMovieAdded` 和 `handlePlaybackEvent` 里两处 7 行 copy-paste

## ⚡ 优化

### 前端三大页面拆分

* `emby-notify.tsx`：906 行 → 176 行，拆成 ConnectionSection / NotifySettingsSection / RefreshSettingsSection / SyncDeleteSection / WebhookInfoCard + useEmbySettings hook + types

* `task/index.tsx`：922 行 → 142 行，拆成 StatusCell / ActionsCell / ClearDirectoryCell / ScheduleCell / TaskPageHeader + TaskColumns + useTasks hook

* `StrmCleanupCard.tsx`：913 行 → 201 行，拆成 StatCard / CleanupToolbar / CleanupLogPanel / StaleStrmDialog / MissingStrmDialog + useStrmCleanup hook

* 拆分后代码职责单一、可单独测试、diff 更小

### Emby 通知默认值对齐

* 后端 `DefaultSettings()` 补齐 6 个 EmbySettings 字段默认 true：入库通知 / 删除通知 / 播放通知 / 播放进度 / 创建刷库 / 删除刷库

* 前端 `DEFAULT_NOTIFY_SETTINGS` 把 `refreshOnCreate/Delete` 从 `false` 改为 `true`（之前前后端不一致）

### STRM 核心开关默认开启

* 后端 `DefaultSettings()` 新增顶层字段默认 true：Enable302（302 重定向）/ EnablePathEncoding（路径编码）/ RemoveExtraFiles（删除多余 STRM）

* 前端 `BasicSettingsTab` 直接 `!!data.xxx` 透传，无需前端额外改动

* 老用户升级不受影响（已有 settings.json 存了这些字段值）

### Emby 轮询参数调优

* 刮削轮询间隔从 5s 降到 3s，更快响应

* 刮削超时从 5min 收紧到 60s（超过 60s 基本是刮削真挂了，早点降级 webhook 字段）

### 前端 SPA embed diff 静默

* `.gitattributes` 中 `internal/web/spa/**` 标记 `-diff -merge -text`，避免 `git diff` 被构建产物噪声淹没

## 🐛 修复

* 修复 Emby 入库通知经常"空壳"（webhook 到达时刮削还没完成，详情 API 返回空 Overview/Genres/People）

*- 修复 STRM .iso 扩展名不在 DefaultStrmExtensions 默认列表（现已添加）

* 修复前端 jsdom 缺 Radix UI 必需 API 导致 Select / Dialog 组件测试崩溃（setup.ts polyfill hasPointerCapture 等）

* 修复前后端 Emby settings 6 个字段默认值不一致（入库/删除/播放通知后端 false 前端 true；刷库后端 true 前端 false）
