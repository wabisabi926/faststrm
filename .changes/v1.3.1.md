# v1.3.1 - 2026-09-05

入库通知更快、播放停止通知更简洁、设置保存更安全的一版。

## 亮点速览

* 入库通知速度大幅提升：刮削等待从最慢 43s 降到 25s，海报卡住不再拖 5 分钟
* 播放停止通知移除冗余的「观看时长」，播放进度已有时间不再重复
* Emby 设置保存时不再把脱敏 API Key 写回配置，避免真实 Key 被覆盖
* 新增 `--no-tray` 启动参数，无桌面环境也能跑

## ✨ 新增

* 新增 `--no-tray` 启动参数，跳过系统托盘初始化，方便在远程服务器、Docker 等无桌面环境下运行和调试

## ⚡ 优化

* 入库通知详情重试退避改为前密后疏（0.5/1/1.5/2/3/4/5/8s，总等待 43s→25s），刮削几秒完成即可几秒后发通知
* 海报下载超时从 300s 压缩到 8s（重定向 60s→8s），失败快速降级纯文本，不再因一张图片卡住整条通知
* Episode 防抖窗口从 15s 缩短到 8s，批量入库时通知更快发出
* 播放停止通知移除「观看时长」字段，播放进度已含时间（如 40:24 / 43:35）不再重复显示

## 🐛 修复

* 修复 Emby 设置页保存时脱敏 API Key（含星号占位符）被写回 settings.json 的问题，真实 Key 不再被覆盖
* 修复 monitor 刷库时 Series 类型入库事件被丢弃的问题，整剧入库现在也能正常发通知
