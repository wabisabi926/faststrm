# v1.0.5 - 2026-08-24

生活事件监控可靠性增强：删除事件增加熔断保护、移动/重命名 fallback、关联文件删除安全校验等。

## ✨ 新增

- 新增删除事件熔断保护：单次轮询删除事件超过 100 条或占比超过 50% 时，自动跳过本次所有删除操作，防止 API 异常返回大量删除事件导致大规模误删
- 新增「仅错误通知」开关：LifeMonitor 设置页开启后，正常的创建 / 删除 / 移动 / 重命名不推 Telegram，仅异常时推送

## 🔥 删除

- 彻底移除「硬删除」配置与 UI 开关：所有删除操作统一为物理删除（直接 os.Remove），不再生成 `.deleted.bak` 备份文件，统一行为避免混淆

## ⚡ 优化

- Emby 入库通知新增自动重试逻辑，应对 Emby 异步写入延迟导致详情获取 404 的情况
- Emby webhook URL 复制支持 HTTP 环境降级处理
- 前后端硬删除配置统一，UI 与后端配置项一致

## 🐛 修复

- 修复新建空文件夹事件被误判为媒体文件、错误生成 STRM 的问题
- 修复移动 / 重命名事件目标路径已存在时被跳过、STRM 不更新的问题，现 fallback 到 recreate 模式（清理旧的 + 重新生成）
- 修复关联文件删除可能误删非关联文件的问题（例如之前 `movie` 可能误删 `movie_trailer.mp4`，现已加扩展名与 remainder 双重校验）
