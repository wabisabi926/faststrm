## 115 生活事件监控可靠性增强

### 新增

- **删除事件熔断保护**：当单次轮询中删除事件超过 100 条或占比超过 50% 时，自动跳过所有删除操作并记录日志，防止 API 异常返回大量删除事件导致大规模误删
- **仅错误通知模式**：LifeMonitor 设置页新增「仅错误通知」开关，开启后正常操作（创建/删除/移动/重命名）不推送 Telegram 通知，仅在异常时推送

### 修复

- **修复 type=17 (new_folder) 事件错误生成 STRM**：空文件夹事件不再生成 STRM 文件，仅写入数据库记录文件夹路径
- **修复软删除/.bak 备份残留**：彻底移除 EnableHardDelete 配置，所有删除操作直接 os.Remove，不再生成 .deleted.bak 备份文件
- **修复移动/重命名事件目标路径已存在时被跳过**：当目标路径已存在时 fallback 到 recreate 模式（清理旧 STRM + 重新生成），确保 STRM 正确同步
- **修复关联文件删除可能误删非关联文件**：deleteRelatedFiles 添加扩展名验证，匹配后检查 remainder 必须为空或以 . 开头

### 优化

- Emby 入库通知链路完善，添加 GetItemDetailWithRetry 重试逻辑应对 Emby 异步写入延迟
- Emby webhook URL 复制支持 HTTP 环境降级处理
- 前后端硬删除配置统一：移除前端硬删除复选框 UI 及相关状态管理
