## 115 生活事件监控全面修复与优化

### 核心问题修复

- **修复 SSL 证书验证失败**：115 生活事件 API 域名从 `web.api.115.com` 修正为正确的 `webapi.115.com`（事件拉取）和 `life.115.com`（开关设置）
- **修复 API 路径错误**：`/life/setoption` -> `/calendar/setoption`，`/life/listhistory` -> `/behavior/detail`
- **修复响应字段解析**：LifeEventItem 字段对齐 p115client 规范（Category -> FileCategory，Size -> FileSize，OpTime -> UpdateTime）
- **修复 Cookie 认证流程**：扫码登录 GetQrcodeResult 请求体从 JSON 改为 application/x-www-form-urlencoded 格式
- **修复动态 clientType**：GetQrcodeToken 支持多 app 类型切换

### 路径解析优化（关键功能）

- **新增三级路径解析降级机制**：
  - 一级：内存缓存查询 parentID -> 路径映射（TTL 5 分钟）
  - 二级：调用 fs_files_media API 获取祖先目录链
  - 三级：降级为 /unknown/{fileName} 保证不中断
- **新增 ResolvePath 方法**：通过 parent_id + file_name 构建完整云端路径
- **新增 FsFilesMediaAncestors API**：对齐 p115client fs_files_media 接口

### 风控规避

- **新增 API 域名轮换**：主域名 webapi.115.com <-> 备用域名 proapi.115.com 自动切换
- 首次请求失败时自动切换到备用域名重试

### 事件处理优化

- **新增事件类型过滤**：忽略浏览/标星等无操作事件（类型 3, 4, 7, 8, 9, 10, 19）
- **新增 IgnoreBehaviorTypes 常量**：对齐 p115client IGNORE_BEHAVIOR_TYPES
- **默认轮询间隔调整**：30 秒 -> 10 秒（对齐 MoviePilot-Plugins，减少事件延迟）

### 参考实现

- 对齐 MoviePilot-Plugins (p115strmhelper) 和 p115client 库的 115 API 调用规范
- 确保与 115 官方 API 最新域名和路径一致
