# v1.1.7 - 2026-08-31

Emby/Kodi STRM 播放修复 + CI 稳定性加固 + 测试补全。

## ✨ 新增

### Emby STRM 兼容性增强

* EmbyServer 加入强制代理 UA 默认列表，Emby 服务器请求自动走代理模式（绕过 CDN UA 绑定限制）

* 新增 CDN 直链缓存清理 API（`POST /api/strm/cache/clear?ua=xxx`）

* 新增 UA 诊断日志，STRM/FS 请求行输出请求方 UA，便于排查播放失败根因

### CI 覆盖率补全

* pkg/strmutil 新增 safedelete\_test.go（8 用例，覆盖率 93.8%）

* pkg/logger 新增 logger\_test.go（5 用例，覆盖率 100%）

## ⚡ 优化

* Telegram webhook handler：secret 校验提前到 token 检查之前（安全加固 + 避免未授权请求浪费后续流程）

* 测试隔离：telegram\_webhook\_secret\_mismatch 子测试空 BotToken，避免 initPhase6Deps 同步调用 Telegram getMe API 导致 CI 偶发 3-4s 超时

* .gitignore 新增 scripts/fnpack.exe、\*.fpk、飞牛交叉编译二进制

## 🐛 修复

* CI goimports 格式：strm\_cache.go import 从两段改为三段分组（标准库/第三方/项目内部）

* gosec G306：测试文件 os.WriteFile 权限 0644→0600
