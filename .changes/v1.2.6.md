# v1.2.6 - 2026-09-03

Emby 播放更省心，任务状态更可靠，STRM 清理更好用的一版。

## 亮点速览

* Emby 反代播放策略重构：强播放器默认直链，浏览器/Web 客户端保留转码兜底
* 任务日志详情页不再看飘忽的「总进度 %」，改为统一的步骤状态 + 精确计数
* STRM 清理收尾：组合操作按钮层级更清晰，操作日志不再换行/挤占
* 全站 PC 端页面宽度统一为 `max-w-6xl`，视觉更整齐

## ✨ 新增

* **Emby 反代智能路由**：Infuse、VidHub、SenPlayer、Kodi、Emby 客户端、PotPlayer、VLC 等强播放器走 8087 反代时，默认获得 STRM 直链；浏览器 / Web 客户端保持原 Emby 转码能力，避免 H.265/DTS 等格式报错
* **原盘格式继续走代理**：ISO / BDMV / M2TS / TS / VOB 等需要精确 seek 的格式仍由 FastStrm 代理，避免直链后 Range 失败

## ⚡ 优化

* `强制代理 UA 标识` 回归为 STRM 端点层的高级选项，默认值清空，一般情况下无需填写
* 任务日志详情页移除不可靠的「总进度 %」，改为「开始 / 已完成 / 失败 / 已取消」状态徽章 + 精确的 completed X/Y files 计数
* STRM 清理「清理失效 + 补生成漏项」主操作按钮改为黑底白字，危险操作使用 outline 警告样式，层级更清晰
* 操作日志面板详情区域加宽，长文本不再换行；「清空」按钮改为更轻量的 ghost 样式
* 全站 PC 端页面宽度统一为 `max-w-6xl`，账户、任务、设置、通知等页面视觉对齐

## 🐛 修复

* 修复「清理全部失效」后统计不刷新：文件已不存在时视为清理成功，并强制复扫校准
* 修复「清理全部失效」UI 计数延迟：依据后端返回的真实删除数立即移除失效项
* 修复默认配置下 STRM 迁移测试对「强制代理 UA 标识」的空值断言错误
* 修复无 UA 信息时被误判为浏览器导致播放策略错误的问题

## ⚙️ 配置提示

* 已启用 Emby 反代的用户，请将播放器 / 客户端指向 `http://<faststrm-host>:8087`，而非 Emby 原生端口
* 浏览器 / Web 客户端访问 8087 时保持原 Emby 行为，可正常转码
* `强制代理 UA 标识` 留空即可；仅在特殊场景下需要 STRM 端点强制代理时填写
