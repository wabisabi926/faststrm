# v1.3.7 - 2026-09-29

路径解析更靠谱、跳过原因看得见的一版。

## 亮点速览

* 生活事件路径解析不再「丢失父目录」：改为优先读取 /files 顶层 path，非媒体目录不再被 medialist 的 type=6 过滤剔除，STRM 能落到正确的目录层级
* 生活监控跳过事件时，日志里直接带上 file_id / parent_id，遇到「不生效」不用再靠猜
* 目录路径库有回归测试兜底，全量扫描维护 folders 表的链路被锁定

## 🐛 修复

* 生活事件路径解析丢失父目录（no_path_mapping）：medialist 带 type=6 媒体过滤会把祖先链中的非媒体目录从 path 剔除，改为首选 /files 列目录响应的顶层 path（不受媒体过滤影响），medialist 作为兜底
* 祖先链为空时路径解析误判：/files 顶层 path 缺失时不再直接当成「父目录是根目录」，改为语义优先降级——先尝试按目录语义解析，再核对根目录，最后才做受限的一级子目录浅扫
* 生活监控跳过事件的日志补全关键定位信息：跳过原因日志带上 file_id / parent_id，用户可在界面直接看到是哪个目录映射缺失导致跳过

## 🔧 优化

* FsFilesMediaAncestors 失败或返回空结果时补齐 raw response 日志，便于快速判定 medialist 是否可靠
* 全量扫描维护 folders 表的链路补回归测试（覆盖根目录与多级子目录），确保 file_id / path / file_name / parent_id 正确落库
* 清理 SPA 写头日志噪音：根治 net/http「superfluous response.WriteHeader call」告警
