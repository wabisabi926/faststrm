v1.0.0 - 2026-08-22

## 生活事件监控完全对齐参考项目

### 修复

- 修复 STRM 路径映射丢失子目录（4 处 filepath.Dir(mapping.localPath) 误用，改为直接使用 mapping.localPath）
- 修复 DB 提前覆盖旧路径（删除 handleMoveRenameQuadrant 提前写 DB 调用，handler 内部反查旧路径后才同步 DB）
- 修复 recreate 模式不生成新 STRM（强制创建，不被 moveMediaCreateNewStrm 配置挡住）
- 修复 OTHER_TO_MEDIA 象限旧 STRM 未清理（新增 cleanupOldStrmForOtherToMedia，创建新 STRM 前按 file_id 反查并删除旧 STRM）
- 修复 rename/move fallback 导致新旧 STRM 并存（移除所有 fallback，失败直接返回错误，对齐参考项目 shutil_move 行为）

### 新增

- 新增四象限决策矩阵（OTHER_TO_MEDIA / MEDIA_TO_MEDIA / MEDIA_TO_OTHER / OTHER_TO_OTHER），对齐参考项目 p115strmhelper
- 新增事件类型严格路由（type∈{1,2,14,18,23}→create, type∈{5,6}→move, type∈{20,24}→rename, type==22→remove）
- 新增 phase1.go 事件预处理 + 路径映射决策
- 新增 STRM 清理交互确认 API（cleanup_interaction.go）
- 新增 STRM 操作历史记录 API + DB 仓库（strm_history.go + strm_history_repo.go）
- 新增 60 秒通知合并器（notification_batcher.go）
- 新增 pkg/concurrency（AC 自动机 + workerpool）
- 新增 pkg/strmutil/safedelete.go 安全删除工具

### 优化

- 115 API：Use-Agent 轮换池（Windows/Mac/iOS/Android）+ 429 自动切换 + 域名修正（proapi.115.com）+ 分级超时（普通 30s / 慢操作 300s）
- 302 路由：405 fallback + 二次 pickcode 检索 + 并发请求锁定
- STRM 清理：双阈值（max=10 拒绝 / stable=5 二次确认）+ UI 确认
- Emby 刷库：防抖 10 秒，避免频繁扫描
- SQLite：WAL 模式 + busy_timeout=5000 + MaxOpenConns=1
- STRM 生成：黑名单/白名单 glob 过滤（*-trailer.* / sample.* / *.cd2.mkv）
- STRM 删除：可选关联文件清理（.nfo/.jpg/.srt/.ass/.sub）
- 数据库清理：分页扫描孤儿记录 + 操作后立即触发清理
