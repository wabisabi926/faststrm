# v0.9.5 - 2026-08-20

飞牛 fNOS / Docker / Linux / Windows 跨平台目录浏览体验大修。

## ✨ 新增

- 新增本地目录选择器顶部「手动路径输入」+「跳转」按钮，目录树看不到时也能手动粘贴路径定位
- 新增三路状态反馈：✅ 成功 / ❌ 错误（显示后端原因）/ 💡 输入提示，用户一眼知道当前状态
- 新增环境变量 `FASTSTRM_LOCAL_DIR_ROOTS`，可显式覆盖本地根目录列表

## ⚡ 优化

- 本地根目录识别改为 4 级优先策略（显式覆盖 → 真实挂载点 → fNOS 共享卷 → 兜底），飞牛、Docker、Linux、Windows 下都能看到正确的可用目录
- fNOS 默认目录权限由「严白名单」改为「宽松放行 + warning 日志」，用户已授权的目录不会再被 403 拒绝
- CI 流程升级到 Node 24 native，消除构建告警

## 🐛 修复

- 修复飞牛 fNOS 沙箱下只能看到一个目录、无法选择媒体文件夹的 P0 问题
- 修复 fNOS 共享目录未声明导致沙箱里真正访问不到的问题（manifest 已补齐 share_dirs 规范声明）
