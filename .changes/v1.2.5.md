# v1.2.5 - 2026-09-02

STRM 清理对账真正能用的一版，顺手修了一堆小细节。

## 亮点速览

- 清理对账 4 个按钮全部修通，不再点了没反应
- 扫描 / 对账两套结果合并成统一视图，多了一张「数据库记录数」统计卡
- 失效 STRM 直接预览内容，不用再点文件管理器翻
- 重复扫描自动走 1 分钟缓存，不再反复请求云端
- 账号状态总览卡片拉宽 + 改成纵向堆叠，信息更不挤
- 新增端到端测试覆盖，后续再改不容易回退

## ✨ 新功能

- **STRM 失效预览**：失效列表里点一下文件，弹窗里直接看 STRM 内容，长内容可展开全文
- **扫描缓存**：刚扫完 1 分钟内再扫自动走缓存，工具栏会提示当前用了缓存
- **数据库记录数**：对账明细新增「DB 记录」列，统计表头也多了一张卡
- **账号状态页 UI 优化**：账号状态卡片拉宽，信息改为纵向堆叠，一眼看全更舒服

## ⚡ 体验优化

- **清理后数据更准**：删完 / 补生完会重新扫一遍本地，显示的 STRM 数量不再越用越偏
- **统计不掺水**：本地 STRM 数量只算 .strm 文件，.nfo、封面图、字幕单独统计，不再混在一起
- **组合按钮提示更准**：「清理失效 + 补生成漏项」确认弹窗按实际选中条目计数，没选中不让点

## 🐛 修好了

- 修复「清理全部失效」按钮点了没实际删除
- 修复「补生成全部漏项」按钮没实现、点了没反应
- 修复「清理失效 + 补生成漏项」会删全量失效，而不是只删勾上的
- 修复补生完漏项后，列表没同步刷新的问题
- 修复「全量对账」数据库记录列一直是 0
