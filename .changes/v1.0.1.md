# v1.0.1 - 2026-08-24

大库首次生成时「目录扫描看起来卡死、0% 一直不动」的感知焦虑彻底解决。同时对齐参考项目 qmediasync 的 Telegram 与 Emby 通知模板，通知美观度与信息完整度大幅提升。

## ✨ 新增

- 新增任务面板 9 阶段徽章：🔍 扫描目录 / 📊 增量比对 / 🧹 清理文件 / 💾 写数据库 / ⚡ 生成 STRM / 🔧 收尾等，一眼知道在做什么
- 新增任务「已用时间」计时器（每秒刷新），大库运行时一眼判断任务"还活着"
- 新增扫描阶段骨架动画进度条 + 每 3 秒「已扫描 N 目录 / M 文件 / 命中 K 个媒体」心跳广播，目录多的时候 UI 不再静止 0%

## ⚡ 优化

- Emby 通知模板对齐参考项目：清晰度 / 设备信息 / 播放格式 / 封面图尺寸全部升级
- Emby 入库 / 播放 / 暂停 / 停止四类通知排版对齐 qmediasync 风格
- 图片发送链路统一：下载临时文件再上传，彻底解决内网 Emby 无法被 TG 服务器访问导致无封面的问题
- 任务执行所有 9 个阶段均实时同步到前端，失败时同步错误原文

## 🐛 修复

- 修复 Emby 播放 / 入库等通知完全不发送的问题
- 修复 STRM 任务启动 / 完成 / 失败时 Telegram 通知不触发的问题
- 修复 Telegram Bot 按钮点击无响应的问题
- 修复开机自动轮询不启动的问题
- 修复 Telegram 通知中文与 Emoji 排版错位的问题
- 修复生活监控通知重复发送的问题
- 修复 Emby 通知缺少封面图的问题（大小写不匹配 + 内网不可达）
- 修复 Emby 播放暂停 / 停止通知缺少「⌛ 观看时长」的问题
