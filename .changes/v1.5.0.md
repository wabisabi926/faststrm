# v1.5.0 - 2026-10-20

## 亮点速览

* 清理更安全：只删本工具生成的 STRM，删除先进回收站，可一键恢复
* 扫描更快：大库扫描速度提升一个数量级，跑过一次后更明显
* 删前复核：执行清理只处理本次扫描确认的文件，删除前再核对云端
* 限流分离：扫描、播放、生活事件分开限流，后台扫描不再抢占播放
* 播放修复：ISO / 原盘文件名含 `/` 时不再无法起播

## ✨ 新增

* 删除先进回收站，7 天内可一键恢复
* 可勾选连带删除同名 nfo、海报、字幕，并回收空目录
* 文件移出监控目录时，自动清理旧位置的 STRM
* 任务详情页实时刷新进度和日志，无需手动刷新
* 支持更多 STRM 模板变量，兼容 p115strmhelper 写法
* Telegram 增加命令别名、返回按钮、任务进度推送
* 生活事件页可一键清理无用的轮询日志

## ⚡ 优化

* 只清理本工具生成的 STRM，手写或第三方文件不会被误删
* 清理只处理本次扫描确认过的文件，放置过久需重新扫描
* 删除前再核对一次云端，文件确实不存在才动手
* 大库扫描速度提升一个数量级，跑过一次后更明显
* 扫描、播放、生活事件分开限流，后台扫描不再抢占播放
* 单个目录读取失败不再拖垮整个任务，结束后自动重试
* 直链过期导致播放中断时自动刷新
* 文件内容没变就不重写，也不触发 Emby 整库重扫
* 任务名改为「账户-目录名」，一眼看清是哪个任务

## 🐛 修复

* 未配置前缀时生成 0.0.0.0 / 127.0.0.1 导致无法播放
* ISO 文件名含 `/` 时部分播放器无法起播
* 含冒号、问号、emoji 的片名无法生成 STRM 或显示乱码
* 清理补建的 STRM 与正常生成格式不一致
* 多个设置页同时保存会互相覆盖

## 🔥 删除 / 行为变更

* 下线增量同步模式，已被写盘去重和下载幂等替代
* 移除「删除多余文件」开关，改用更安全的按文件对账清理
* 默认 admin/admin 登录后必须先修改密码
* 管理接口仅允许同源访问
