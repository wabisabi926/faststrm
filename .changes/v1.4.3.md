# v1.4.3 - 2026-10-19

大库扫描更快、清理更安全的一版。

## 亮点速览

* 全量扫描改用 115 目录递归清单：调用次数从「每个目录 1 次」降到「每 1000 个文件 1 次」，大库热启动快一个数量级
* 清理只按 STRM 内容里的 pickcode 对账，不再按路径删除，你手动放的海报 / 字幕 / 手写 STRM 不会被误删
* 删除影片时可以选择连带清理同名 nfo / 海报 / 字幕，也可以顺手收掉空目录
* 扫描、播放取直链、生活事件分别限流，后台扫描不再挤占播放配额
* 生活事件更可靠：移出监控目录可自动清理旧 STRM；文件名含 `/`、emoji 等特殊字符也能正确落盘与回读

## ✨ 新增

* 全量扫描走 115 目录递归清单（`cur=0`）：一次请求返回 1000 个文件并自带父目录 id，本地用目录缓存还原路径；缓存缺失时用列目录响应的祖先链补齐并回填。清单不完整、路径还原失败、空清单等异常自动回退旧扫描，生成结果不受影响
* 清理新增两个可选动作：连带删除同名 `.nfo/.jpg/.png/.srt/.ass` 等元数据与字幕（扩展名白名单，不含任何视频格式）、删完后向上回收空目录（到任务目标目录为止）
* 关联文件下载幂等：本地已存在且大小一致时跳过，不再每轮重下全部字幕 / 海报
* 代理流直链过期自动刷新：上游返回 401/403/404/408/429/5xx 时自动失效缓存并重取一次直链，外网播放中途不再因 CDN 签名过期中断
* 单文件生活事件的 pickcode 延迟可用时自动重试（2s / 5s），覆盖「整理刚完成、pickcode 还没生成」导致的漏生成
* 移出监控目录时可自动删除本地旧 STRM（默认开启，可在设置页关闭）：文件移到非媒体目录后，旧位置的 STRM、关联文件与空目录一并清理；关闭时保留旧 STRM 并记录日志
* STRM URL 模板变量扩展：新增 `{file_path}`、`{file_path_raw}`、`{file_id}`、`{file_name}`、`{file_stem}`、`{file_suffix}`、`{base_url}`，与 p115strmhelper 的模板写法兼容；原有 `{prefix}`、`{account}`、`{pickcode}`、`{filename}`、`{ext}`、`{stem}` 保持不变
* 前端任务页接入 SSE 实时事件：任务进度与日志边跑边刷新，无需手动刷新页面；日志详情页 SSE 优先（服务端重放最近 500 帧 + 增量推送），4 秒未连通自动降级为一次性拉取
* 账号改名 / 删除级联：改名同步任务、设置、数据库与监控引用；删除时展示被引用详情，支持强制删除
* Telegram 交互增强：命令别名、返回按钮、批次过期提示、任务进度回执；全量同步改为选择任务、孤儿清理改为独立对账；`/status` 显示最近 3 条生活事件；任务 / 映射选择超过 8 个按钮时折叠并提示到 Web UI 操作；按钮映射改为 LRU（容量 1024、TTL 7 天，使用中的按钮不会被淘汰）
* 任务 ID 可读化：新建任务 ID 从时间戳改为「账户-目录名」，特殊字符清洗、UTF-8 安全截断、重名追加序号；旧任务 ID 保持不变
* 生活事件类型汉化补全：轮询 / 移出 / 重建 / 新建文件夹 / 卡住超时等类型均有中文标签与颜色，未知类型兜底显示原文

## ⚡ 优化

* 限流按「账号 + 用途」分桶：扫描 60、播放取直链 120、生活事件 60 QPM，互不抢占
* STRM 写入去重：内容未变时跳过写盘，也不触发 Emby 刷库，避免媒体库假重扫
* 目录级失败容忍：单个目录列目录失败不再让整个任务作废，扫描结束统一重试一轮；仍失败的目录记入任务日志，其下存量 STRM 本次跳过清理
* 清理三重保护：单次删除超过 10%、超过 1000 个、或涉及超过 20 个目录时进入保护态，任务日志明确说明原因
* 清理默认改为按 pickcode 对账（原来默认是「按路径删除多余文件」）
* 改名 / 移动残留识别：pickcode 仍在云端但本地路径与云端不一致的 STRM，按残留清理
* 文件名非法字符清理规则补全：冒号转全角；`/`、`\` 转 `_`（避免文件名里的 `/` 被当成目录分隔符，把单个文件拆成多级目录）；其余特殊字符转下划线；`.iso.strm` 双扩展名保持不变
* 115 字符引用解码：115 返回的 `\x02<码点>` 编码（emoji 等特殊字符）在任务扫描、生活事件、下载直链、CDN 文件名等处统一还原为真实字符，STRM 文件名不再出现 `_128074]` 之类的乱码
* URL 参数编码统一：空格编码为 `%20` 而非 `+`（避免回读文件名带加号），全量生成、生活事件、模板渲染、清理补建四处规则完全一致
* 清理对账键与生成侧落盘规则对齐，同一个文件不再出现两套路径
* Emby 反代缓存 TTL 按 115 直链签名剩余时间收敛，避免缓存比签名活得久
* 强制代理格式可配置，可以把 `.ts` 等非原盘格式移出列表，改走 302 直连
* 跳过 BDMV 原盘视频流时在任务日志显式提示数量与原因
* 任务启动不再调用 115 目录导出接口：省掉最多 30 秒的启动等待，也不再在 115 侧创建无用的 zip 导出任务
* 扫描日志降噪：逐文件日志从 Info 降到 Debug，大库不再刷出十万行日志
* 扩展名归一化去重：去空白、去点、转小写并去重，`.iso` 与 `iso` 不再并存
* 账号页交互：新增账户不再自动生成时间戳名（重名返回 409 并引导更新已有账户）；「更新 Cookie」按钮常显；删除被引用账户时展示引用详情
* 失效 STRM 列表新增「账号失效」徽标，并透传 115 错误码
* 任务管理页列宽调整，浅色主题下徽章对比度优化

## 🐛 修复

* 未配置 STRM 前缀时可能生成 `http://0.0.0.0:8090` / `127.0.0.1` 这类不可播放地址：现在按「任务 > 全局 > 对外地址 > 内网 IP」逐级兜底，彻底不可用时任务直接失败并提示
* 生活事件监控的 STRM 扩展名硬编码，不跟随设置里的扩展名列表
* 含特殊字符（冒号、问号、星号等）的片名在 Windows / SMB 上无法生成 STRM
* 清理可能误删用户自己放的文件：路径级「删除多余文件」下线
* 增量对账在云端清单不完整时可能误删本地 STRM：增量模式下线，统一走带 DB 快照兜底的全量对账
* 生活事件回退查找（DB 无旧路径时按文件名匹配本地目录）未清理特殊字符，含 `/` 的名字永远匹配不到
* 清理补建的 STRM 默认 URL 缺少 `file_name`，与生成侧格式不一致
* 删除同步还原云端路径时未处理全角冒号，导致路径对不上
* 账号失效检出覆盖扫描的全部失败路径（正常 / 缓存 / 云端失败），不再只在部分路径生效
* 监控保存时校验引用的账户是否存在，缺失返回 400 并列出账户名
* 账号改名与已有账户重名时返回 409，避免静默覆盖
* 前后端字段不对应、文案与交互细节修复
* Telegram 按钮失效、动作空实现、回调鉴权等交互缺陷

## 🔥 删除

* 增量同步模式（`incrementalSync` / `incrementalCleanupMode`）：它并不减少扫描，只省写盘与下载；写盘去重与下载幂等已覆盖其收益，且它的清理路径不并 DB 快照
* 任务级「删除多余文件」开关与全局 `removeExtraFiles` 配置（后者执行器从未读取）
* 任务启动时的 115 目录导出调用（`ExportDirParse`）

## ⚙️ 配置提示

* 升级后首次启动会自动迁移一次：孤儿 STRM 清理默认开启（`auto_clean`），并打开「连带删除同名 nfo / 海报 / 字幕」；之后你在设置页的手动开关不会被覆盖
* 旧任务配置里的 `removeExtraFiles` 字段会被忽略，不需要手动清理
* 冷启动（目录缓存为空）第一次扫描速度与旧版持平，跑完一次后明显变快
* URL 编码开关（默认开启）：关闭后账号、文件名等参数原样写入 URL，文件名含 `#` / `&` / `?` / 空格 时会破坏 URL 解析
* 移出映射删除开关（默认开启）：关闭后文件移出监控目录时只记录日志，不删除本地旧 STRM
