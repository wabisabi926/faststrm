# v1.4.1 - 2026-10-09

这版主要针对飞牛（fnOS）安装包和 Docker 镜像的稳定性与体验做了改进。

## 飞牛（fnOS）安装包

- 服务端口统一固定为 8090：安装时不再需要手动填写端口，直接默认使用 8090，配置更简单，也更不容易因端口不一致导致打不开界面。
- 修复了应用安装后找不到默认配置目录的问题，首次启动配置会正确就位。
- 清理了残留的过时配置文件，避免旧配置误导设置。

## Docker 镜像

- 加固了镜像架构自检：确保 arm64 镜像里实际运行的就是 arm64 版本的程序。此前有用户反馈下载的 arm64 镜像启动时报错，本版从构建和运行两个环节双重保障，不会再出现「镜像标注 arm64、程序却是 x86」导致无法启动的情况。
