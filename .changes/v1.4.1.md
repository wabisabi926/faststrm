# v1.4.1 - 2026-10-09

飞牛（fnOS）打包链路加固的一版，明确固定服务端口并对齐参考项目 qmediasync 的死端口方案，同时修正默认配置模板路径推导、清理陈旧残留、并让前端构建产物缺失从「静默出包」改为硬性阻断。

## 🔧 优化

* fNOS 服务端口固定为 8090：`cmd/main` 不再读向导 `port.env`，统一收敛到固定端口，与桌面快捷方式、`manifest service_port`、Go 后端默认端口保持一致；向导移除端口输入步骤，改为「服务端口固定 8090」提示（对齐参考项目 qmediasync 的死端口方案，避免「改了端口但桌面图标/历史 strm 不跟随」的割裂体验）
* 默认配置模板路径从二进制目录推导：二进制定位优先 `app/faststrm`，`DEFAULT_CONFIG_DIR` 由二进制所在目录推导，修正此前配置模板复制层级错位导致的配置目录找不到问题

## 🧹 清理

* 删除陈旧的 `config.yml`（旧 YAML 时代死文件，现后端只认 JSON，且 `adminPassword: admin` 有误导性）
* 清理 `install_callback` / `upgrade_callback` 中失效的 `port.env` 相关注释

## 🛡️ 健壮性

* `build-fnos.sh` 前端构建产物缺失从 WARN 升级为 `exit 1` 硬阻断：`internal/web/spa/` 是 git 跟踪的构建产物，正常 checkout 必然存在；缺失时产出的 `.fpk` 会没有 Web UI，此前仅警告会静默出包，现改为直接报错，并提示 `cd frontend && npm ci && npm run build`
