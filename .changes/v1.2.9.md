# v1.2.9 - 2026-09-04

通知内容更丰富、保存设置更顺手、手机端布局更清爽的一版。

## 亮点速览

* Emby 入库 / 删除通知新增海报、评分、类型、演员、季集时间，剧情简介不再截断
* Telegram 设置保存不再误报「机器人令牌无效」，错误原因直接说清楚
* 任务编辑页「删除多余本地文件」等勾选框保存后不再自动取消
* 路径映射、删除同步手机端改上下排列，输入框不再被挤出屏幕

## ✨ 新增

* Emby 入库 / 删除通知新增：海报、评分、类型、演员、季集时间字段

## ⚡ 优化

* Emby 通知剧情简介不再截断，能看到完整内容
* 没有演员信息的电影不再显示空白行
* Telegram 设置保存失败时直接说明原因（令牌错 / 需要代理 / 网络不通），不再一刀切说令牌无效
* Telegram 设置页标签改成中文，按钮不再挡住输入框
* 路径映射和删除同步页面手机端改成上下排列，不再横向出界
* 账号选择框加宽，「遍历全部账号」几个字显示完整
* 海报图片下载到本地再发送，通知里能正常显示
* Emby 通知标题统一格式，更整齐

## 🐛 修复

* 修复 Telegram 设置明明机器人能用却提示「令牌无效」、保存失败的问题
* 修复任务编辑页勾选框（如「删除多余本地文件」）保存后被自动取消的问题
