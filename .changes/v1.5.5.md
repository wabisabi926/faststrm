# v1.5.5 - 2026-10-23

## 亮点速览

* 删除/清理安全边界收紧：默认回收站、只删当前任务托管文件、硬删二次确认
* 设置与任务持久化改为 fail-closed，写入/下载失败不再显示完成
* Emby/Telegram 配置精简，自定义 STRM 模板下线并自动备份
* 多设备登出互不影响；设置多标签保存不再互相覆盖
* 概览新增新手配置引导；folders 缓存与清理补建地址更可靠

## ✨ 新增

* 概览底部「新手配置」引导：添加账号 → 配置 STRM 前缀 → 新建任务；可选项直达生活事件 / Telegram / Emby
* 常规设置支持脏字段保存：只提交相对页面加载快照发生变化的字段
* 登出支持按会话吊销（jti 持久化到配置目录），其他设备保持登录
* folders 目录路径缓存增加 7 天 TTL
* 清理补建 STRM 前缀在全局为空时回退 `PublicBaseURL`

## ⚡ 优化

* 删除任务清理 STRM 默认移入 `.faststrm-trash`；只清理当前任务托管且内容未变的文件，删前取消并等待执行器退出
* 新建/编辑任务拒绝文件系统根目录和重复 `TargetPath`
* 清理确认队列入队失败或未配置时 fail-closed；云端分页改为 Count 优先，短页不再当作完整目录
* 设置/任务读取或解析失败返回错误；账号 Cookie 三态与检查信息原子持久化
* 任务取消贯穿扫描/清理；写 STRM/下载失败最终为 failed，进度分母不再包含关闭下载的条目
* 115 HTTP 错误类型化：429/430/599 归为限流，401/403 归为认证；599 不再自动重试
* 扫描遇到认证/限流/重试耗尽立即中止；生活事件毒事件 3 次后转死信并推进游标，分页失败不再静默丢事件
* 修复 LifeClient 把 Cookie 当 User-Agent；移动/改名文件名清理，多版本删除增加边界匹配
* Emby Webhook 密钥/URL/配置指引合并为一个区块，生成密钥后局部保存；测试连接不把已保存 API Key 发到变更后的地址，错误中的 key 脱敏
* JWT 改密仍使全部会话失效；登出只吊销当前 jti
* 概览新手配置条在账号和任务都完成后自动隐藏

## 🐛 修复

* 删除任务「清理 STRM」从直接删除改为默认回收站，硬删需二次确认
* 清理确认队列不可用时退化为立即删除；短页被当作完整目录带来误删风险
* 设置/任务文件损坏时静默用默认值覆盖原文件
* 任务写入/下载失败仍显示 completed；`totalFiles` 误算关闭下载的条目
* 扫描遇到认证/限流/重试耗尽仍继续；599 被自动重试
* 生活事件毒事件导致游标卡死、分页失败静默丢事件
* 非认证错误被误标为 Cookie invalid
* Emby 测试连接可能把已保存 API Key 发到新主机
* 登出递增全局 TokenVersion 导致所有设备会话失效
* 限流器 `lastCall` 预占与全局桶顺序、IPv6 公网误判为私网
* 新建/编辑任务允许把文件系统根目录设为 `TargetPath`

## 🔥 删除 / 行为变更

* 下线自定义 STRM URL/文件名模板：设置入口移除，老配置首次读取备份为 `settings.json.templates-v1.*` 后清空
* 删除任务清理 STRM 默认进回收站；永久删除需要显式二次确认
* 登出只吊销当前会话；改密仍会使全部旧 JWT 与 SSE Cookie 失效
* 旧配置的孤儿清理从 `auto_clean` 迁移为 `mark_only`，需要自动清理时请重新开启
* 任务目标路径必须是绝对目录，不能是文件系统根或与其他任务重复

## 升级说明

* **STRM 模板**：已有自定义 URL/文件名模板会备份到 `settings.json.templates-v1.*` 后清空，新生成的 STRM 使用默认拼接与命名
* **删除任务**：清理 STRM 默认进回收站，永久删除需在弹窗中勾选硬删
* **孤儿清理**：老配置升级后降为 `mark_only`，需要自动清理请在清理策略重新选择 `auto_clean`
* **多设备登录**：登出仅影响当前设备；改密会使全部旧 token/SSE Cookie 失效，需要重新登录
* **任务状态**：写入/下载失败的任务现在显示 failed，不再显示 completed
* **任务目标路径**：文件系统根目录、与其他任务重复的 `TargetPath` 会被拒绝
* **folders 缓存**：超过 7 天的目录缓存会被每日维护淘汰，首次访问可能回退到 115 接口解析
* **清理补建**：全局 STRM 前缀为空时使用 `PublicBaseURL`，不再固定 8090
