# v1.3.3 - 2026-09-16

生活监控路径更准、日志更省心的一版。

## 亮点速览

* 生活监控：一次性上传整个文件夹时，每个文件只生成一次 STRM，不再因文件夹递归与文件级事件各处理一遍而重复生成
* 生活监控：文件类型与文件夹类型分开判断路径，文件不再被错误当成文件夹去查询，路径匹配更稳
* 生活监控：文件丢失「父目录」信息但本地已有记录时，直接取回完整路径，不再退回裸文件名导致映射目录里的文件被跳过
* 日志文件改为自动滚动：单个日志达到一定大小自动归档压缩并清理旧档，磁盘不会无限增长

## ✨ 新增

* 日志：文件日志接入按大小自动滚动（单文件到 50MB 触发、保留最近 5 份、超 7 天清理），滚动后自动 gzip 压缩归档

## ⚡ 优化

* 生活监控：路径解析改为按「文件 / 文件夹」类型区分，文件夹递归与文件级事件各走各的正确逻辑，减少错配导致的映射落空
* 生活监控：文件事件缺失父目录信息时，先查本地已有的路径记录（之前处理过就能找回），找不到才退回最终兜底

## 🐛 修复

* 生活监控：上传整个文件夹时，同一文件因「文件夹递归」与「文件级 create 事件」各自处理一遍而重复生成 STRM 的问题，改为互斥去重
* 日志文件无限增大、长期占用磁盘的问题，改为按大小自动滚动且过期自动清理
