# v1.3.6 - 2026-09-28

反代更完整、原盘不再拆碎、生活监控更可靠的一版。

## 亮点速览

* Emby 反代补齐 WebSocket 与端口改写：经反代访问的客户端恢复播放进度回传、实时通知与远程控制，也不再绕过反代直连 Emby 原端口
* 蓝光原盘不再被拆碎：BDMV/STREAM 下的 m2ts 视频流整棵子树跳过，一个原盘只留一个 STRM，不再是上百个碎片文件
* 生活监控「新增 / 删除不生效」的多个根因一并修复，关键跳过原因在界面上可见

## ✨ 新增

* Emby 反向代理：新增 WebSocket 透明代理，双向转发 /embywebsocket，恢复实时通知、播放进度回传、会话同步与远程控制
* Emby 反向代理：/emby/system/info 中的 WebSocket 端口等字段改写为代理自身端口，客户端不再绕过反代直连 Emby 原端口

## 🐛 修复

* 生活监控新增事件不生成 STRM：文件夹事件不再被提前消化，改为记录后继续递归生成
* 生活监控旧配置缺「事件类型」开关时自动补默认开启，不再因四个开关全为 false 而静默跳过
* 生活监控删除事件不生效：本地 STRM 确实不存在时不再谎报成功，改为如实记录
* 生活监控删除事件在数据库无 file_id 记录时，改为按文件名在映射目录兜底查找
* 生活监控单文件被云端误标为目录时按单文件回退处理，避免整条事件被丢弃
* 全量任务写文件表时跳过单条无效记录，不再因一条坏数据导致整批任务失败
* 蓝光原盘目录被逐个生成 STRM：BDMV/STREAM 下的视频流统一跳过，独立的 .m2ts / .ts 与 ISO 原盘链路不受影响
