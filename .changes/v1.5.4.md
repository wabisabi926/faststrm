# v1.5.4 - 2026-10-22

## 亮点速览

* 强制代理 UA 默认值不再被「误清空」：老配置缺字段时自动补回 4 个播放器
* 后台每日维护：过期回收站与执行记录不再依赖「你正好跑了清理」
* 未托管 STRM 可以看到明细，不再只有一个数字
* 外部 STRM 可以原地迁移到 FastStrm，不需要重新扫描云端
* 新增「系统状态」页：服务、反代、账号和最近系统事件一眼可见
* 设置留空不再被回填默认值，且保存后即时生效，无需重启
* Emby Webhook 必须配置鉴权密钥，Telegram Webhook 与轮询不再冲突

## ✨ 新增

* 设置页「强制代理 UA 标识」增加「填入默认值」：一键填回 `Infuse, VidHub, SenPlayer, SenPlayerHD`
* 每日维护任务：启动后 1 分钟跑一次、之后每 24 小时一次，清理超过 7 天的回收站批次并裁剪执行记录
* 清理页未托管 STRM 支持「查看明细」：只读列出路径映射、相对路径与原始原因（云端已删 / 账号失效）
* **STRM 迁移工具** `faststrm-migrate`：支持 p115strmhelper、LitePan file_id URL、旧 FastStrm `/api/fs/get`；默认 dry-run，可备份并可选登记托管
* **系统状态页**：展示版本、运行时长、反代监听状态与账号健康，系统事件可按任务/清理/账号/通知/限流等分类筛选
* 播放诊断页新增「清除直链缓存」按钮，实时返回清理条数
* 设置 → 生活事件新增「旧 STRM 扩展搜索目录」：路径映射之外的历史目录也会参与旧 STRM 查找（`mediaMountPath`）
* 任务记录新增服务端全量统计接口 `GET /api/taskHistory/stats`，统计卡片不再只算「已加载的那一页」

## ⚡ 优化

* 强制代理 UA 的 placeholder 改为完整默认值，不再只提示前两个
* 回收站与执行记录的清理从「机会式触发」改为「定时兜底」，长期不操作也不会越攒越多
* 反代状态分开显示「监听地址」和「客户端连接地址」，不再把 `0.0.0.0:8097` 当成客户端地址
* 系统事件覆盖任务开始/完成、清理结果、账号巡检、Telegram 轮询与 115 限流；不记录每次播放，避免日志膨胀
* 代理流遇到连接拒绝/超时也会换链一次；430 计入可刷新状态，分片客户端增加 60 秒响应头超时
* 播放日志中的 CDN 直链只保留 host/path，签名参数不再落日志
* 分片请求增加同账号共享的 CDN Range 并发池（默认跟随分片并发数，上限 8），避免多路原盘叠加触发 115 风控
* Emby 反代对自身 `/api/strm` 改为进程内调用，域名/NAT/HTTPS 回环不再影响原盘播放；外部 STRM 与自定义模板保留 HTTP fallback
* 强制代理格式旧默认 10 项自动收敛为 5 项（iso/bdmv/bdav/dvd/bluray），m2ts/ts/vob/ifo/bup 恢复 302
* 侧边栏「设置」改为分组菜单：常规、生活事件、通知中心、账号安全；旧通知/账号安全链接保留跳转
* 日志区收敛为四块：系统状态、任务记录、生活事件、播放诊断；移除任务页重复的「事件处理」页签和状态页任务总数
* 移除任务记录中重复的「STRM 操作」页签；STRM 变更明细继续由生活事件日志与任务日志覆盖，旧 `/history?tab=strm` 链接自动跳到生活事件
* STRM 清理页默认只显示扫描、3 个关键数字和两个主操作；高级策略、扫描详情、空回收站/待确认队列默认折叠或隐藏
* 附带下载扩展名改为唯一开关：留空 = 不下载；旧版关闭开关的配置自动迁移为空列表
* 设置页列表统一逗号分隔，并提供「填入默认值」；清理策略只保留外层「高级清理策略」一次折叠，展开后直接编辑阈值与动作；移除过期的「增量同步」文案
* 强制代理标识同时匹配 User-Agent 与 Emby 客户端名（`X-Emby-Client` / `Authorization Client=`）
* 按格式强制代理改为单一格式列表：列表为空 = 全部 302，去掉重复的独立开关；点「填入默认值」恢复推荐 5 项
* UA、STRM 扩展名、强制代理格式显式留空后保持为空，播放/扫描/清理在运行时使用内置默认兜底；删除前端的默认值回填和「已恢复默认」提示
* 设置保存即时生效：STRM 播放/诊断读取最新设置快照，115 UA、API 限流桶和账号 Range 并发池按新配置重建，无需重启
* 常规设置只提交常规/STRM/下载/限流字段，清理页只提交清理配置与自动清理模式；Emby/Telegram 仅由各自专用接口写入，避免旧快照覆盖通知配置
* 生活监控统一走 `/api/lifeMonitor` 保存并应用，账号下拉只显示 115；移除账号时同步清理对应路径映射
* 路径映射两侧统一归一化前导斜杠，`/电影` 与 `电影` 都能命中；本地目录树保留 `C:\` 盘符根，文件和云目录选择器只允许选中目录
* 任务启动等待真实账号锁后再返回，同账号已有任务时返回 409；取消在扫描、写 STRM 和完成前生效，最终状态保持「已取消」
* 历史日志按 `executionId` 精确查询，旧记录不再误报不存在；历史列表支持游标「加载更多」
* Telegram Webhook 与自动轮询互斥：填 Webhook 自动关闭轮询，勾选轮询自动清空 Webhook；保存 Webhook 必须配置 secret，删除 Bot 时停止轮询
* Emby Webhook 鉴权密钥改为必填，支持 `?auth=`、`X-Webhook-Auth` 和 Bearer；删除通知统一由「同步删除通知」开关控制；四个保存按钮收敛为底部一个
* 账号深度检测改为有界并发（3），单个账号刷新不再清空其他账号状态
* 清理扫描透传未托管 STRM 明细，缺失项补齐 `mediaExtension`，前端不再从文件名猜扩展名
* 账号告警在「网盘账号」健康面板与「通知中心 › 账号告警」共用同一套配置读取/保存逻辑，各自只提交本页字段，保存一处不会把另一处的开关覆盖回旧值

## 🐛 修复

* 老配置缺少 `forceProxyUaTokens` 字段时被当成「用户主动清空」：读出来是空、随手保存一次就永久固化成 `[]`，再也回不到默认 4 项
* 代理并发上限被第一次请求固化：普通流和原盘流共用同一个 bottleneck，原盘可能拿不到 +2 软上限，设置页改上限也要重启才生效
* CDN 直链剩余不足 5 分钟时仍被缓存默认 TTL，302 客户端可能拿到已过期链接：现在按签名剩余时间裁剪，剩余不足 1 分钟不缓存
* Range 分片只校验响应头、未限制 body 长度：异常 CDN 多写的内容会挤进下一片，导致错位；现在按期望长度复制并检测超长
* 路径映射写 `/电影` 时事件全部跳过：监控侧与映射侧的前导斜杠归一化不一致，现已统一
* 只开启「同步删除通知」时剧集/整季删除漏发：删除通知改由统一开关判定
* 任务启动假成功、取消后又被写成完成/失败：启动回调与取消检查点已补齐
* 旧执行记录点「日志」误报不存在：只在前 100 条里查找，现改为按 `executionId` 精确查询
* 登出后旧 HttpOnly Cookie 仍可连接 SSE：现在同时下发过期 Cookie
* Telegram 未配置时「测试发送」假成功、409 冲突无提示：现在返回明确错误并记录系统事件
* Emby 设置加载失败时默认值覆盖真实配置：加载成功前禁用保存
* 目录选择器允许选中文件、盘符根被裁成 `C:`：现在只接受目录并保留完整盘符根
* 任务记录「加载更多」用 `startedAt` 当分页游标，但后端按 `createdAt` 排序：可能出现重复或漏记录，现改为按 `createdAt` 游标
* 新建/编辑任务允许把文件系统根目录设为 `TargetPath`：现在直接拒绝，避免任务把 STRM 写满系统盘
* 删除任务清理 STRM 默认移入回收站；只清理当前任务托管且内容未变的文件，硬删需显式二次确认
* 清理确认队列未配置或入队失败时不再退化为立即删除；云端分页短页不再当作完整目录
* 设置/任务文件损坏时不再静默用默认值覆盖原文件；任务写入/下载失败不再显示完成
* JWT 登出/改密后旧 token 与 SSE Cookie 立即失效

## 🔥 删除 / 行为变更

* 删除 `/api/fs/get` 兼容路由：旧 STRM 不再由服务端转发，需运行 `faststrm-migrate` 或重建 STRM
* 删除媒体挂载路径功能及 `/api/mediaMountSync` 路由；顶层 `Settings.MediaMountPath` 一并移除，`LifeMonitor.MediaMountPath` 保留为「旧 STRM 扩展搜索目录」并新增设置入口
* 通用 `/api/settings` 不再接收 Emby/Telegram 字段，避免清理页/设置页旧快照回滚通知配置
* Telegram `WebhookURL` 仅表示 Telegram 回调本服务的地址，不再作为通用出站 Webhook
* 下线自定义 STRM URL/文件名模板：设置入口移除，老配置首次读取备份为 `settings.json.templates-v1.*` 后清空，避免生活事件与全量任务路径分叉

## 升级说明

* **已有安装**：`settings.json` 里**没有** `forceProxyUaTokens` 键的，升级后会自动补默认 4 项并写回
* 如果你之前**主动清空**过这个列表（`"forceProxyUaTokens": []`），升级后仍保持为空——语义不变：留空 = 所有播放器走 302 直连（按格式强制代理等其它规则不受影响）
* 想恢复默认：点字段右侧的「填入默认值」再保存
* 每日维护只删**超过 7 天**的回收站批次，保留期内的文件不会被动
* 执行记录仍只保留最近 200 条（含日志）
* **迁移工具**：先 dry-run 预览；LitePan URL 需要 `-account-map` 或 `-account`，p115 需要目标账号；路径路由/分享链接/直接 CDN URL 不会被自动迁移
* **系统状态**：系统事件只保留当前进程最近 500 条，重启后清空；任务明细仍在「任务记录」
* **设置入口**：通知中心、账号安全已并入设置页；旧 `/notify`、`/account-security` 链接会自动跳转
* **附带下载**：旧版「自动下载媒体元数据」开关关闭的用户，升级后扩展名列表为空 = 不下载；需要恢复请点「填入默认值」
* **旧 STRM**：先运行 `faststrm-migrate -from faststrm -root <STRM目录> -write`（默认 dry-run），或运行全量任务重建；不要把旧 `/api/fs/get` 地址继续留在媒体库
* **留空语义**：UA、STRM 扩展名、强制代理格式保存为空后不再自动回填；需要默认值请点「填入默认值」。附带下载扩展名为例外：留空 = 不下载
* **Emby Webhook**：升级后必须配置鉴权密钥，否则回调返回 401；Emby 侧 URL 改为 `?auth=你的密钥`（旧 `?token=` 仍兼容）
* **同步删除**：未显式配置过试运行且未启用删除同步时默认 `true`；已启用删除同步的老配置保持原值，避免升级后突然停止删除
* **Telegram**：保存 Webhook 会自动关闭自动轮询，两者只能选一种；Webhook 必须配置 secret
* **账号告警**：默认关闭。依赖 Cookie 失效/恢复通知的用户请在「设置 → 通知中心 → 账号告警」开启
* **媒体挂载路径**：入口与 API 已移除，原顶层配置字段会被忽略；「旧 STRM 扩展搜索目录」已移到设置 → 生活事件 → 高级，需要时在那里填写
* **按格式代理**：旧 `disableSeekFormatProxy` 开关会自动迁移——关闭的转为空列表，开启且列表为空的补默认 5 项；迁移后列表为空即关闭
* **STRM 模板**：已配置的自定义 URL/文件名模板会备份到 `settings.json.templates-v1.*` 后清空，新生成的 STRM 使用程序默认拼接与命名
* **删除任务**：清理 STRM 默认进回收站；永久删除需要二次确认
