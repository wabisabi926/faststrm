# v1.2.4 - 2026-09-02

Emby 反代热重启版本 —— ProxyPort 和 EmbyURL 修改后即时生效，再也不用重启主程序了。

## ✨ 新增

* Emby 反向代理**热重启**：保存「代理端口」或「Emby 地址」后，反代服务自动优雅切换（旧连接放完、新服务启动），不中断主程序。关闭反代即时停止
* Emby 反代完整单元测试（27 个），覆盖 ISO 原盘 / Audio 类型 / 缓存 TTL / LRU 淘汰 / 并发安全 / 端口热切换 / Stop 超时 / 端口冲突 等全部场景

## ⚡ 优化

* 前端「Emby 反向代理」UI 重设计：checkbox 移到标题左侧对齐，标签整块可点、移动端 hit area 扩大到 36px+
* 移动端布局优化：反代端口下方的 URL 预览自动换行（之前长地址会溢出）、「保存配置 / 测试连接」按钮竖排各占整行
* Webhook 配置指引底部提示语从灰底卡片改成单行浅色文字，和页面其他说明语风格统一
* 事件类型标签（媒体入库/删除/播放开始等）从灰字灰底改成黑字白底 + 细边框 + 微阴影，更醒目
* Docker 用户：docker-compose.yml 自动带上 `8097:8097` 端口映射
* Wiki / Readme 修正轮询间隔描述：默认 10 秒（之前多处误写 30 秒，v0.9.7 就从 30 秒缩短到 10 秒了）

## 🐛 修复

* 修复「Emby 反向代理」配置**保存后刷新丢失**：proxyPort 字段之前没进后端白名单，POST 被静默忽略；现在保存后数据库里正常持久化
* 修复「Emby 反向代理」UI **初始化不回显**：checkbox 用 `useState(initialValue)` 只在首次挂载执行一次，此时 settings 还在异步加载，导致永远 false；改成直接从 props 派生
* 修复 `Manager.Start` **端口冲突静默成功**：`ListenAndServe` 在 goroutine 里异步启动，端口被占要等运行时才报错，但 Start 已返回 nil；现在加了同步 `net.Listen` 预检测，冲突立即返回错误
* 修复 `Manager.Stop` **ctx 过期时状态不一致**：ctx 已过期时 Shutdown 会关 listener 但跳过内部状态清理，导致 Status 显示 Running 但实际 HTTP 连不上；现在 ctx 过期直接短路，Shutdown 返回后无论成败都强制清理状态
* 修复 `embyproxy.New()` 对缺 scheme 的 URL（如 `emby.local:8096`）不报错，现在加了 http/https 校验
