# v1.0.9 - 2026-08-25

Windows 系统托盘、移动端 UI 全面优化、Emby 通知配置热更新、默认路由调整。

## ✨ 新增

### Windows 系统托盘
- 新增 Windows 系统托盘图标支持：使用 `github.com/getlantern/systray` 实现，exe 启动后自动在右下角托盘显示 FastStrm 图标
- 托盘菜单：打开 Web 界面、查看运行状态、服务器连接状态、关于、退出
- 实时状态更新：每 2 秒检测服务器健康状态并更新托盘提示
- 优雅关闭：通过托盘菜单退出时正确关闭 HTTP 服务

### 账号安全独立页面
- 新增「账号安全」独立页面（`/account-security`），从设置页拆分为独立侧边栏菜单项
- 账号安全与设置风格一致，包含密码修改、会话管理等功能

## 🔥 删除

### Emby 通知页面
- 删除「注意」提示区块，简化页面

## ⚡ 优化

### 移动端 UI 全面优化
- Tab 栏：添加 `shrink-0` 和 `whitespace-nowrap` 防止移动端换行
- 卡片内边距：从 `p-4 sm:p-5` 调整为 `p-3 sm:p-5`，移动端更紧凑
- 保存按钮：固定底部位置（`sticky bottom-0`），方便操作
- 响应式按钮：操作按钮添加 `w-full sm:w-auto`，移动端全宽
- 路径映射：移动端改为垂直排列（`flex-col sm:flex-row`）
- 任务管理页面：全新移动端卡片布局，与账户管理页面风格一致
- STRM 清理页面：统计改为 `grid grid-cols-2 sm:grid-cols-4` 响应式网格

### 默认路由
- 首页默认路由从 `/task` 改为 `/account`，首次访问进入账户管理页面
- 侧边栏 Logo 链接指向 `/account`

### 前端缓存
- `index.html` 改为永不缓存策略（`no-cache, no-store, must-revalidate`），确保版本更新后浏览器总能获取最新 SPA 入口
- JS/CSS 资源保持 24 小时缓存（文件名含内容哈希，安全）

### Emby 通知系统
- Notifier 改为动态创建 Client：移除启动时缓存的 Client 实例，每次从当前配置创建，用户修改 Emby URL/APIKey 后立即生效
- 用户 ID 跨 Client 缓存：在 Notifier 级别缓存 Emby 用户 ID，避免每次通知重复请求 `/emby/Users`
- `SyncDelete`、`MediaServerRefresh` 均改为动态 Client 创建

### Windows 打包
- 图标文件 `favicon.ico` 嵌入 exe 作为应用图标
- 构建配置中添加 `rsrc` 工具调用，自动生成 Windows 资源文件

## 🐛 修复

- 修复 Emby 通知使用缓存 Client 导致用户修改配置后通知仍使用旧配置的问题
- 修复用户 ID 在每次创建新 Client 时丢失、重复请求 Emby 用户列表的问题
- 修复首页默认路由跳转到 `/task` 而非 `/account` 的问题
- 修复 `index.html` 被浏览器缓存 24 小时导致版本更新后前端不生效的问题
- 修复 Windows 版本缺少系统托盘图标和菜单的问题
- 修复 `systray.ShowMessage` 函数不存在导致编译失败的问题（改为日志输出 + 托盘提示）
