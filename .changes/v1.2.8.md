# v1.2.8 - 2026-09-04

界面进一步打磨 + Emby 网页播放修复的一版。

## 亮点速览

* 修复 Emby 反代网页端播放失败：STRM 源一律强制 DirectPlay，不再走转码
* 任务列表表格列宽优化，窄容器下不再横向滚动
* 路径映射 / 删除同步输入框拉长、账号选择列前移，布局更整齐
* Telegram 通知配置更清爽，Bot 状态栏长名字不再截断

## ✨ 新增

* **历史日志详情页单元测试**：覆盖数字 id 与字符串 executionId 匹配、找不到执行记录、加载失败三个场景

## ⚡ 优化

* 任务列表表格 7 列分配合理宽度（80~220px），总宽约 810px，在 `max-w-5xl` 容器内正常显示，无需横向滚动
* 路径映射（115 网盘 → 本地）与删除同步（Emby → 115 网盘）路径输入框拉长占满空白
* 删除同步账号选择列从最右移到最左，与路径映射布局保持一致
* Telegram 通知两个复选框水平对齐，移除「启动时自动轮询」下方的冗余说明文字
* Telegram Bot 状态栏用户名 / 昵称加 `truncate`，长名字不再挤压布局
* 任务执行历史任务标题字号调小调轻（`text-lg` → `text-base font-medium`）
* 精简监控页「全量同步」提示文案，操作步骤更简洁

## 🐛 修复

* 修复 Emby 反代网页端播放失败：STRM 源（带签名/防盗链的 115 CDN 直链）走转码时 ffmpeg 拉流因 UA 不匹配失败，改为 STRM 源一律强制 DirectPlay，与 Emby App 行为一致

## 🧪 测试

* 新增 `log-detail` 前端单元测试
* 更新 embyproxy 策略日志与相关测试断言
