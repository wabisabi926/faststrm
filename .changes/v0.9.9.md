v0.9.9 - 2026-08-21

## 前后端契约对齐与功能完善

### 修复

- 修复前后端契约冲突：前端调用不存在的后端路由（新增 /api/directory/local/listChildren）
- 修复前后端 Task 状态值不匹配（running→processing, completed→success, cancelled→cancelled）
- 修复前端 strmType 字段后端未定义（全链路打通 Task/Upsert/toTask）
- 修复任务启动/取消请求字段名不一致（id → taskId）
- 修复 Telegram 通知 info 类型 data 为空时解析失败

### 新增

- 新增 /api/directory/local/listChildren 路由，支持前端目录选择器功能
- 新增 Task 结构体 StrmType 字段，支持多种 STRM 类型
- 新增 Emby 媒体库刷库配置 UI（创建/删除后刷库、防抖秒数）
- 新增 Account 类型 lastCookieCheck 和 cookieValid 字段

### 优化

- 重构 Account 页面状态管理，cookie 检查时序优化
- 清理孤立组件 DirectoryPickerDialog（调用不存在的 /api/115/files 接口）
- 统一前端 Task 类型定义，移除冗余 path 字段
- 优化 STRM 清理扫描结果兜底处理，避免 undefined 显示
