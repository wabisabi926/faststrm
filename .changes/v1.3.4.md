# v1.3.4 - 2026-09-17

原盘播放更省心的一版。

## 亮点速览

* ISO / BDMV 原盘不再占用服务器带宽：改成 302 直连网盘播放，流量直接走网盘，Kodi/next-gen 免转码直接看
* 网络扫描修复：带子目录的资源不再被整批误判为失效

## ⚡ 优化

* ISO / BDMV / M2TS 等原盘格式由「服务器中转」改为「302 直连网盘」：播放器拿到直链后直连网盘拉流，服务器不参与传输，流畅看 4K 原盘也不吃 NAS 带宽

## 🐛 修复

* 网络扫描时按子目录递归比对云端目录，修复带子目录的资源被全部误判为失效的问题
