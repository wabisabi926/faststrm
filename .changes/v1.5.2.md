# v1.5.2 - 2026-10-21

## 亮点速览

* 首次启动更简单：打开 Web 页面创建管理员账号，不再找随机密码文件
* 清理更安全：扫描结果只能执行一次，未托管/手改 STRM 不再被生活事件误删
* 删除可恢复：生活事件单文件删除统一进回收站，并校验托管归属与文件指纹
* 播放更稳：Range 分片严格校验、断连回收连接，分片刷新只换一次直链
* 生活事件更可靠：字幕异步同步并保留 `.bak`，失败事件不再跳过游标

## ✨ 新增

* **首次启动 Setup Wizard**：新安装打开 Web 页面创建管理员账号；已有安装继续使用原密码
* 支持无界面初始化：`FASTSTRM_ADMIN_USERNAME` / `FASTSTRM_ADMIN_PASSWORD` 环境变量可跳过向导
* 设置中心新增「生活事件监控」页签；生活事件页只保留事件日志，并提供监控设置入口
* 字幕/元数据同步覆盖已有文件前自动保留 `.bak`

## ⚡ 优化

* 首次启动不再生成 `initial-admin-password.txt`；打开 Web 即进入初始化页面
* 旧版随机密码安装升级后保持原密码；完成初始化/改密后自动清理遗留明文密码文件
* 生活事件页只保留事件日志；监控开关、轮询、路径映射统一移到「设置中心 → 生活事件监控」
* 生活事件单文件删除只处理已托管且内容未变的 STRM，移入回收站并登记删除
* 字幕/元数据同步改为有界异步队列，不再阻塞账号轮询
* 生活事件请求接入按账号的 QPM 限流，与扫描、播放配额分离
* Range 分片校验 `Content-Range`/`Content-Length`，首片不完整立即中止
* 分片换链增加 singleflight，所有失败/断连路径关闭响应体
* 清理、补建、回收站恢复、清空目录统一拒绝符号链接父目录
* 清理对账键先清理文件名再换扩展名，尾点文件名不再出现两套路径
* 回收站过期清理按映射根每小时最多一次
* 115 请求返回 429/430 时直接进入冷却，不再当场重试
* 请求层重试耗尽后，生活事件轮询不再叠加外层重试
* 清理目录允许结尾分隔符，只拒绝真实 `..` 路径段
* 设置保存区分字段未提供与显式关闭，旧前端不会重置代理开关

## 🐛 修复

* 新建 STRM 时先 upsert 新路径，导致旧 STRM 永远清不掉
* 生活事件删除未托管/手改 STRM，绕过回收站直接硬删
* 云端目录返回 `state=false` 被当成空目录，可能误删本地 STRM
* 全量清单缺少 count 或分页不足仍进入清理对账
* 分片请求忽略 `Content-Range`，CDN 返回错位区间可能导致花屏/seek 黑屏
* 分片中断后未关闭已取到的响应体，长时间播放可能耗尽连接
* 字幕下载长度不一致仍会落盘，可能保存成错误页/截断文件
* 令牌桶等待者可能丢失唤醒，导致请求一直等到超时
* 清空目录误拒绝带结尾分隔符的合法路径

## 🔥 删除 / 行为变更

* 新安装首次启动不再生成随机密码文件，必须先在 `/setup` 创建管理员账号
* 生活事件监控设置从「生活事件 → 监控设置」迁移到「设置中心 → 生活事件监控」；旧链接自动跳转
* `scanId` 只允许真实执行一次；重复执行返回 `SCAN_TOKEN_USED`，需要重新扫描
* 生活事件删除默认只处理托管 STRM；手写/第三方 STRM 保留，可在清理页手动处理
* `state=false` 的云端目录一律按失败处理；全量清单异常时回退逐目录扫描
* 原盘代理并发超过软上限后排队，不再为防止排队而无限放行
* `ForceProxyUaTokens` 新默认值仅对全新安装生效，老配置清空仍表示全部直连

## 升级说明

* **全新安装**：启动后打开 Web 页面，按提示创建管理员账号；不再需要去配置目录找随机密码文件
* **已有安装**：继续使用原密码登录，不需要重新初始化；旧版明文密码文件会在完成初始化/改密后自动清理
* **Docker / 飞牛 / 无界面部署**：可设置 `FASTSTRM_ADMIN_USERNAME`、`FASTSTRM_ADMIN_PASSWORD` 直接初始化，跳过 Web 向导
* 监控设置入口改为「设置中心 → 生活事件监控」；旧书签 `/life-events?tab=config` 会自动跳转
* 升级后首次清理建议先扫描确认；扫描结果放置超过 30 分钟或已执行过需重新扫描
* 字幕同步生成的 `.bak` 不会自动删除，确认内容后可手动清理
* 分片并发会额外占用 CDN 连接，不严格等于「单账号代理并发上限」的槽位数
* `.ts` 不在原盘强制代理列表；需要时可在设置页手动加入
