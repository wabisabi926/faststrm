# v1.3.8 - 2026-10-07

Cookie 状态更可信、失效早发现、STRM 生成更可控的一版。

## 亮点速览

* 账号 Cookie 状态升级为 valid / invalid / unknown 三态：风控、网络等临时不可用不再被误判为「失效」，只有确实需要重新登录才标红
* 新增账号 Cookie 主动巡检：默认每 6 小时用权威探测接口验活，未开启生活监控的账号过期也能第一时间发现
* 全局 STRM 生成更可控：新增「增量同步」开关、全局文件过滤（最小文件大小 / 文件名黑名单）与「覆盖模式」（总是覆盖 / 跳过已存在）

## ✨ 新增

* 账号 Cookie 三态状态与权威探测接口 ProbeAccount：状态由「有效 / 无效」二态升级为 valid / invalid / unknown 三态，unknown 表示临时不可用或尚未判定，界面不再据此误报「失效」；账号状态页 verify / verify-all 改为真实调用权威探测接口判定
* 账号 Cookie 主动巡检：新增后台定时巡检（默认每 6 小时一次），覆盖未被生活事件监控的账号，Cookie 过期不再等到点播失败才暴露；可在「账户状态」页开关并调整巡检间隔
* 全局 STRM 生成设置新增三项：增量同步开关（默认开启，首轮仍为全量）、全局文件过滤（最小文件大小 MB + 文件名黑名单关键词）、STRM 覆盖模式（总是覆盖 / 跳过已存在）

## 🐛 修复

* 任务列表分页漏文件：改为按接口返回的 count 驱动翻页，不再因单页截断而遗漏网盘条目
* 115 下载接口业务失败未识别：修复 HTTP 200 但 state=false 被当成成功的问题，失败如实上报
* 过期 Cookie 被误标为有效：统一 Cookie 状态写入入口，消除「仅格式校验通过就判为有效」的假阳性
* STRM 直链获取遇 Cookie 失效：明确提示需要重新登录，并联动回写账号状态，不再只给一句笼统的失败
* Emby 反代直链解析失败时回退自身 URL：解析不到上游直链时不再把请求打回代理自身，避免形成自环
* Emby 反代长时间播放被写超时截断：流式响应（ISO / 原盘等大文件连续播放）解除写截止时间，播放超过 120 秒不再中途断开
* Emby 反代 HTML 壳判定大小写敏感：路径判断统一转小写，`.HTML`、`/Web/` 等混合大小写不再漏注入 crossOrigin 拦截脚本
* 生活事件配置被零值清空：改为字段级合并，未随表单提交的字段保留原值，保存不再意外重置其他项

## 🔧 优化

* 115 错误判定改为结构化 errno 类型化错误（ErrCookieExpired / ErrRateLimited / ErrTransient），不再依赖关键词匹配文案，文案一变不再失效；风控 / 限流类错误不误伤账号状态
* 生活事件监控改用类型化错误判定并回写成功状态，账号状态更及时准确
* STRM 任务执行前先做前置权威探测，Cookie 失效立即快速失败，不再空跑整轮扫描
* Emby for Kodi Next Gen 相关文案统一
* Emby 反代媒体流透传响应头过滤 hop-by-hop 与 Set-Cookie，避免错误透传连接头或泄漏 Emby 会话 cookie
* 补齐回归测试：115 errno 类型化判定、Cookie 三态与巡检默认值、账号三态写入与 verify 无网络分支、Emby 反代 STRM 端点不回退自身 URL
