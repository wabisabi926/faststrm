# v1.5.1 - 2026-10-21

## 亮点速览

* 原盘播放优化：代理流 Range 分片并发，大 ISO 不再卡顿；seek 格式不降级 302
* 字幕自动同步：网盘后续补的字幕/nfo/海报自动下载到本地，无需重跑任务
* 界面重排：概览、清理、生活事件、通知与诊断入口集中，配置更好找
* 历史统一：任务执行与 STRM 记录使用同一套统计卡和紧凑表格
* 安全加固：清理目录限制在任务/监控目录内，危险删除增加复核

## ✨ 新增

* 全新概览页：账号、任务、清理、服务状态与告警一屏查看
* 独立 STRM 清理页：清理策略、扫描、待确认批次、回收站集中管理
* 待确认删除批次列表：支持在 Web UI 直接确认/取消（含 24h 过期倒计时）
* 播放诊断页：按账号、pickcode、UA 查看 redirect / proxy 决策；新增 seek 格式、
  分片参数、代理占用/上限、强制代理 UA 等上下文
* 通知中心：Telegram、Emby、账号告警统一入口
* 生活事件中心：事件日志与监控设置合并
* **生活事件自动同步字幕/nfo/海报**：命中 DownloadExtensions 的新文件直接下载到本地
* 执行历史新增 STRM 记录，可查看生成 / 删除明细
* Emby 反代状态诊断；反代未运行时提示「mkv 可播、ISO/BDMV 必失败」
* 可读任务 ID：新建任务使用「账户-目录名」（如 `aliyun-电影`），旧任务 ID 不受影响
* 任务页 SSE 实时刷新：任务完成/取消自动更新列表，进度阶段实时合并
* Telegram `/status` 展示最近 3 条生活事件；选择页按钮超过 8 个时折叠
* Telegram Webhook 密钥可配置（留空保持、`-` 清除）

## ⚡ 优化

* **代理流 Range 分片并发**：10MB/片、2 路并发、首片直写、按序输出，大原盘带宽不足问题显著改善
* **原盘 seek 格式不降级 302**：并发超限允许软溢出 2 路，超过后排队，绝不降级到易失败的 302
* 生活事件类型全量汉化（轮询 / 移出 / 移动重建 / 新建文件夹 / 轮询超时）
* 客户端必须连反代端口的引导（含「端口互换」部署说明）
* 网络错误中文兜底（断网/超时映射），后端错误消息统一中文
* 任务页说明「启动 = 完整扫描，未变化的 STRM 不重写」
* 执行历史两个 tab 统一为统计卡 + 紧凑表格，切换不再跳变
* 任务列表、日志详情正文统一 12px，信息密度更紧凑
* 日志详情改用 Tailwind，深色模式正常
* 页面标题、空状态、说明文字字号统一，移除 11/12px 零散字号
* 清理扫描合并「全量对账」，一个扫描按钮返回全部统计
* 设置中心移除重复配置索引，只保留播放诊断快捷入口
* 侧栏通知中心并入设置分组，减少分组层级
* 账号、任务、清理、生活事件等过期文案纠正
* 清理目录接口拆分，修复 CI 圈复杂度告警
* 前后端设置 / 清理契约对齐：清理阈值、确认模式、任务前缀、扫描缓存参数等
* 移除前端 P2 / P3 内部里程碑标签泄漏

## 🔥 删除 / 行为变更

* 新增账号只支持 115；历史 OpenList 账号仍可查看和编辑
* 移除「全量对账」按钮，扫描结果同时包含 DB 统计
* 移除设置中心的配置索引卡片
* 移除清理页不可靠的缓存命中徽标
* 移除前端 P2 / P3 内部里程碑标签
* 通知中心并入设置分组；旧 tg-notify、emby-notify、account-alerts 链接自动跳转
* **强制代理 UA 默认预置**：Infuse / VidHub / SenPlayer / SenPlayerHD（这些客户端直连 302 常因 UA/签名绑定被拒）；清空该项可让所有格式走直链
* **代理分片并发默认启用**（设置页可关）

## 升级说明

* 无需手动迁移配置；历史 OpenList 账号保留
* 清理页统一使用「扫描路径映射」，扫描后按提示删除失效项或补生成漏项
* 建议升级后检查一次 STRM 清理策略和通知入口
* **ISO / 原盘播放**：客户端必须连 Emby 反代端口（默认 8097），或把 Emby 端口与反代端口互换；
  播放器需支持 ISO 直读（Infuse / VLC / Kodi / MPV）
* 希望 mkv 全部走直链（不占 NAS 带宽）：清空「强制代理 UA 标识」；个别客户端播不了再加回
* 大原盘卡顿：确认设置页「代理流分片并发」为开启状态（默认 10MB × 2）
