# v1.0.8 - 2026-08-25

Emby API 认证修复、详情获取三级回退策略、TG Bot 命令补齐。

## ⚡ 优化

### Emby API 客户端
- 移除所有 API 请求中对 `API Key` 和 `ID` 的 `url.QueryEscape` / `url.PathEscape` 编码，直接拼接字符串，与 qmediasync 保持一致
- `GetItemDetail` 重构为三级回退策略：①优先使用缓存的有权限用户 → ②尝试所有可用用户（新增 `GetAllUsers` 方法）→ ③无用户上下文降级
- `GetItemDetailWithRetry` 重试次数从 4 增至 5，移除仅 404 重试限制（所有错误均触发重试），增加详细日志

### Telegram Bot
- `BotCommandList` 添加 `/start` 命令

## 🐛 修复

- 修复 Emby API 因 URL 编码导致认证失败的问题（`API Key` 中的特殊字符被转义后无法通过认证）
- 修复 Emby 实例无 `EnableAllFolders=true` 用户时入库通知详情获取失败的问题
- 修复 TG Bot 缺少 `/start` 命令的问题
