# v1.3.0 - 2026-09-05

Emby 通知更稳定、任务历史能删除、默认配置更省心的一版。

## 亮点速览

* Emby 入库通知偶尔收不到、评分主演缺失的问题一起修好了，现在都能正常送达
* 「任务执行历史」页面单条删除和清空全部都能正常使用
* 首次启动自动生成标准默认配置，清理和路径编码等默认功能都正确开启

## ✨ 新增

* 任务执行历史支持单条删除与清空全部（之前点删除会提示失败）

* Emby 播放通知对齐参考项目：设备信息更清楚、中文冒号图标统一、观看时长等字段更完整
* Emby 入库 / 播放通知海报改为本地化处理，内网 Emby 也能正常显示封面
* 首次启动自动生成标准默认配置，不再受旧配置残留影响，清理和路径编码等默认功能都处于正确开启状态

## 🐛 修复

* 修复 Emby 入库通知有时完全收不到的问题，现在都能正常送达
* 修复入库通知评分、主演等信息取不到、内容不完整的问题（没有演员时不再显示空白行）
