# v1.3.0 - 2026-09-05

Emby 通知更稳定、任务历史能删除、默认配置更省心的一版。

## 这次更新了什么

### 📺 Emby 通知更稳定

* 修复入库通知有时完全收不到的问题，现在都能正常送达

* 修复入库通知评分、主演等信息取不到、内容不完整的问题（有演员信息时正常显示，没有时不显示空白行）

* 播放通知进一步对齐参考项目：设备信息更清楚、中文冒号带图标统一、观看时长等信息更完整

* 播放和入库通知的海报改为本地化处理，内网 Emby 也能正常显示封面

### 🗑️ 任务执行历史能删除了

* 「任务执行历史」页面之前点删除会提示失败，现在单条删除和清空全部都能正常使用

### ⚙️ 默认配置更省心

* 首次启动自动生成标准默认配置，不再受旧配置残留影响，清理和路径编码等默认功能都处于正确开启状态
