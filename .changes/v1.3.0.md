# v1.3.0 - 2026-09-05

Emby 通知更可靠、任务历史能删除、默认配置更省心的一版。

## 这次更新了什么

### 📺 Emby 通知更稳定

* 入库通知有时完全收不到的问题修好了，现在都能正常送达

* 评分、主演等信息取不到的补齐了，通知内容更完整

* 播放通知的排版和文案进一步对齐参考项目，设备和观看时长等信息更清楚

### 🗑️ 任务执行历史能删除了

* 「任务执行历史」页面之前点删除会提示失败，现在单条删除和清空全部都能正常使用

### ⚙️ 默认配置更省心

* 首次启动时自动生成一套标准默认配置，不再受旧配置残留影响，清理和路径编码等默认功能都处于正确开启状态
